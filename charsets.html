HTML Charset (Pengkodean Karakter)

Untuk menampilkan halaman HTML dengan benar, browser harus mengetahui charset (character set / kumpulan karakter) yang digunakan. Charset menentukan bagaimana karakter-karakter dikodekan dalam format biner oleh komputer.

💡 Definisi: Charset adalah sekumpulan karakter yang telah dipetakan ke kode numerik. Character Encoding adalah cara karakter-karakter tersebut disimpan dan direpresentasikan dalam format biner (bit/byte) di komputer.

1. Apa Itu Charset dan Encoding?

Komputer tidak memahami huruf atau simbol secara langsung. Komputer hanya memahami angka biner (0 dan 1). Oleh karena itu, setiap karakter — huruf, angka, simbol, emoji — harus dikodekan sebagai angka.

Proses encoding karakter:

  1. Kita mengetik huruf A
  2. Sistem mengubah A menjadi kode numerik, misalnya 65 (dalam ASCII)
  3. Komputer menyimpannya dalam biner: 01000001
  4. Saat dibaca, proses dibalik: 01000001 → 65 → A
ℹ️ Jika pengirim dan penerima menggunakan charset yang berbeda, karakter akan ditampilkan salah. Inilah mengapa charset yang konsisten sangat penting!

2. ASCII — Standar Pertama (1963)

ASCII — American Standard Code for Information Interchange

ASCII adalah standar pengkodean karakter pertama yang banyak digunakan. ASCII hanya mendukung karakter bahasa Inggris dan beberapa simbol dasar.

  • Jumlah karakter: 128 karakter (0–127)
  • Ukuran: 7-bit (1 byte)
  • Isi: Huruf Latin (A-Z, a-z), angka (0-9), simbol (!@#$%^&), karakter kontrol

3. ANSI (Windows-1252)

ANSI — American National Standards Institute

ANSI (juga dikenal sebagai Windows-1252) adalah perluasan ASCII yang dikembangkan Microsoft untuk sistem operasi Windows.

  • Jumlah karakter: 256 karakter (0–255)
  • Ukuran: 8-bit (1 byte)
  • Karakter 0–127: Sama dengan ASCII
  • Karakter 128–255: Karakter Eropa Barat tambahan (é, ñ, ü, dll.)

ANSI adalah charset default untuk Windows dan banyak program lama. Namun ANSI masih tidak mendukung karakter dari bahasa-bahasa di luar Eropa Barat.

4. ISO-8859-1 (Latin-1)

ISO-8859-1 — International Organization for Standardization

ISO-8859-1 adalah charset standar internasional untuk bahasa-bahasa Eropa Barat. Ini adalah charset default untuk HTML 4.01.

  • Jumlah karakter: 256 karakter
  • Ukuran: 8-bit (1 byte)
  • Alias: Latin-1
  • Karakter 0–127: Sama dengan ASCII
  • Karakter 160–255: Karakter Latin tambahan untuk bahasa Eropa

5. UTF-8 — Standar Modern (Direkomendasikan!)

UTF-8 — Unicode Transformation Format (8-bit)

UTF-8 adalah pengkodean karakter paling populer di dunia saat ini. UTF-8 mampu mewakili semua karakter dari semua bahasa di dunia, termasuk emoji!

  • Jumlah karakter: Lebih dari 1.114.112 karakter (seluruh Unicode)
  • Ukuran: Variabel 1–4 byte per karakter
  • Kompatibel dengan ASCII: ✅ Ya, karakter ASCII 0–127 tetap sama
  • Bahasa yang didukung: Semua bahasa di dunia + emoji + simbol matematika + dll.
  • Digunakan oleh: >95% situs web di seluruh dunia

Cara Kerja UTF-8 (Multi-byte Encoding):

Selain UTF-8, ada juga UTF-16 dan UTF-32 yang merupakan bagian dari standar Unicode:

8. Mendeklarasikan Charset di HTML

Untuk memberitahu browser charset yang digunakan, tambahkan tag <meta charset> di dalam <head>. Ini harus menjadi baris pertama dalam <head>, sebelum tag lainnya:

✅ HTML5 (Cara Modern — Gunakan Ini):

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Judul Halaman</title> </head> <body> <p>Teks dengan berbagai bahasa: こんにちは, 안녕하세요, مرحبا, 😀</p> </body> </html>

❌ HTML 4.01 (Cara Lama — Jangan Digunakan):

<!-- Cara lama HTML 4 - JANGAN GUNAKAN --> <meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
⚠️ Perhatian: Jika kamu tidak mendeklarasikan charset, browser akan mencoba menebak charset yang digunakan. Ini bisa menyebabkan karakter ditampilkan salah, terutama untuk bahasa non-Latin seperti bahasa Arab, Jepang, Korea, atau China.

9. Charset di HTTP Header

Selain di dalam HTML, charset juga bisa dideklarasikan melalui HTTP Response Header yang dikirim server:

Content-Type: text/html; charset=utf-8

Jika ada konflik antara charset di HTTP header dan charset di meta tag HTML, browser akan menggunakan yang ada di HTTP header. Oleh karena itu, pastikan keduanya konsisten.

10. Kenapa UTF-8 Harus Digunakan?

Berikut adalah alasan mengapa UTF-8 adalah pilihan terbaik:

  • 🌍 Universal: Mendukung semua bahasa di dunia dalam satu charset
  • 🔄 Kompatibel: Karakter ASCII 0–127 identik, sehingga tidak merusak teks lama
  • 💾 Efisien: Karakter umum (A-Z, 0-9) hanya membutuhkan 1 byte
  • 🌐 Standar Web: Digunakan oleh >95% situs web modern
  • 😀 Emoji: Mendukung semua karakter emoji
  • 🔒 Keamanan: Menghindari bug encoding yang bisa dieksploitasi
  • 📋 Standar HTML5: HTML5 merekomendasikan UTF-8 secara resmi
