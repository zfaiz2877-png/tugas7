HTML Styles

Atribut style di HTML digunakan untuk menambahkan gaya (style) langsung ke elemen HTML. Ini merupakan cara paling langsung untuk mengatur tampilan elemen, meskipun untuk proyek besar lebih disarankan menggunakan CSS eksternal.

1. Atribut Style HTML

Atribut style digunakan untuk menentukan gaya (warna, font, ukuran, dll.) untuk sebuah elemen HTML. Atribut ini menggunakan sintaks properti CSS.

Sintaks Dasar:

<tagname style="property: value;">

Di mana:

  • property — adalah properti CSS (misalnya color, font-size)
  • value — adalah nilai CSS (misalnya red, 16px)
📌 Catatan: Atribut style ini disebut Inline CSS karena ditulis langsung di dalam tag HTML. Properti CSS dipisahkan menggunakan titik koma (;).

2. Background Color — Warna Latar Belakang

Properti CSS background-color mendefinisikan warna latar belakang untuk elemen HTML.

Contoh — Warna latar halaman (body):

<body style="background-color: powderblue;"> <h1>Ini adalah Judul</h1> <p>Ini adalah paragraf.</p> </body>
Hasil:

Ini adalah Judul

Ini adalah paragraf.

Contoh — Warna latar untuk elemen tertentu:

<h1 style="background-color: powderblue;">Ini adalah Judul</h1> <p style="background-color: tomato;">Ini adalah paragraf.</p>
Hasil:

Ini adalah Judul

Ini adalah paragraf.

3. Color — Warna Teks

Properti CSS color mendefinisikan warna teks untuk elemen HTML.

<h1 style="color: blue;">Ini adalah Judul Biru</h1> <p style="color: red;">Ini adalah paragraf berwarna merah.</p> <p style="color: green;">Ini adalah paragraf berwarna hijau.</p>
Hasil:

Ini adalah Judul Biru

Ini adalah paragraf berwarna merah.

Ini adalah paragraf berwarna hijau.

4. Font-Family — Jenis Huruf

Properti CSS font-family mendefinisikan jenis font yang digunakan untuk elemen HTML.

<h1 style="font-family: verdana;">Judul dengan Verdana</h1> <p style="font-family: courier;">Paragraf dengan Courier.</p> <p style="font-family: 'Times New Roman';">Paragraf dengan Times New Roman.</p> <p style="font-family: Georgia;">Paragraf dengan Georgia.</p>
Hasil:

Judul dengan Verdana

Paragraf dengan Courier.

Paragraf dengan Times New Roman.

Paragraf dengan Georgia.

5. Font-Size — Ukuran Huruf

Properti CSS font-size mendefinisikan ukuran teks untuk elemen HTML. Nilai dapat diberikan dalam px (pixel), em, rem, atau persen (%).

<h1 style="font-size: 300%;">Judul Sangat Besar</h1> <p style="font-size: 24px;">Teks ukuran 24 pixel.</p> <p style="font-size: 16px;">Teks ukuran 16 pixel (normal).</p> <p style="font-size: 12px;">Teks ukuran 12 pixel (kecil).</p>
Hasil:

Judul Sangat Besar

Teks ukuran 24 pixel.

Teks ukuran 16 pixel (normal).

Teks ukuran 12 pixel (kecil).

6. Text-Align — Perataan Teks

Properti CSS text-align mendefinisikan perataan teks secara horizontal untuk sebuah elemen HTML.

<h1 style="text-align: center;">Judul Rata Tengah</h1> <p style="text-align: left;">Paragraf ini rata kiri (default).</p> <p style="text-align: right;">Paragraf ini rata kanan.</p> <p style="text-align: justify;">Paragraf ini rata kiri dan kanan (justify). Teks akan diregangkan agar memenuhi lebar elemen.</p>
Hasil:

Judul Rata Tengah

Paragraf ini rata kiri (default).

Paragraf ini rata kanan.

Paragraf ini rata kiri dan kanan (justify). Teks akan diregangkan agar memenuhi lebar elemen penuh dari kiri ke kanan.

7. Menggabungkan Beberapa Properti Style

Kamu bisa menggabungkan beberapa properti CSS dalam satu atribut style dengan memisahkannya menggunakan titik koma (;):

<p style="color: white; background-color: #04AA6D; font-size: 20px; font-family: Arial; text-align: center; padding: 15px;"> Paragraf dengan banyak style sekaligus! </p>
Hasil:

Paragraf dengan banyak style sekaligus!

8. Ringkasan Properti CSS untuk Style

Properti CSS Fungsi Contoh Nilai
background-color Mengatur warna latar belakang elemen red, #FF0000, rgb(255,0,0)
color Mengatur warna teks elemen blue, #0000FF, rgb(0,0,255)
font-family Mengatur jenis/keluarga font Arial, Verdana, Courier
font-size Mengatur ukuran font 16px, 1em, 100%, 2rem
text-align Mengatur perataan teks horizontal left, center, right, justify
font-weight Mengatur ketebalan huruf bold, normal, 700
font-style Mengatur gaya huruf (miring, dll.) italic, normal, oblique
padding Mengatur jarak dalam elemen 10px, 5px 10px

9. Contoh Lengkap — Kartu Profil

<!DOCTYPE html> <html> <body style="background-color: #f0f0f0; font-family: Arial;"> <div style="background-color: white; max-width: 400px; margin: 50px auto; padding: 30px; border-radius: 10px;"> <h2 style="color: #04AA6D; text-align: center;"> Profil Saya </h2> <p style="font-size: 18px; color: #333;"> <strong>Nama:</strong> Budi Santoso </p> <p style="font-size: 16px; color: #666;"> <strong>Kota:</strong> Jakarta, Indonesia </p> <p style="font-size: 14px; color: #999; text-align: center; font-style: italic;"> "Belajar HTML itu menyenangkan!" </p> </div> </body> </html>
Hasil:

Profil Saya

Nama: Budi Santoso

Kota: Jakarta, Indonesia

"Belajar HTML itu menyenangkan!"

💡 Tips Praktis:
  • Inline style (atribut style) berguna untuk styling cepat dan spesifik.
  • Untuk styling yang lebih terstruktur, gunakan Internal CSS (tag <style>) atau External CSS (file .css terpisah).
  • Properti CSS dalam atribut style dipisahkan dengan ; (titik koma).
  • Nama properti CSS dan nilainya dipisahkan dengan : (titik dua).
