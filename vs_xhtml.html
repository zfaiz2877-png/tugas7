HTML vs XHTML

XHTML adalah versi HTML yang lebih ketat dan bersih, yang ditulis berdasarkan standar XML. Memahami perbedaan antara HTML dan XHTML penting untuk menulis kode yang valid dan kompatibel di berbagai platform.

1. Sejarah Singkat

1991
HTML 1.0 — Tim Berners-Lee menciptakan HTML. Sangat sederhana dan permisif (tidak ketat).
1997
HTML 4.0 / 4.01 — HTML berkembang pesat namun masih sangat toleran terhadap kode yang tidak valid (tag tidak ditutup, atribut tanpa tanda kutip, dll.).
2000
XHTML 1.0 — W3C merilis XHTML sebagai reformulasi HTML berdasarkan XML. Lebih ketat, lebih konsisten, dan lebih mudah diproses mesin.
2001
XHTML 1.1 — Versi XHTML yang lebih modular.
2014
HTML5 — W3C dan WHATWG merilis HTML5 yang menggabungkan keunggulan HTML dan XHTML, namun tetap kompatibel ke belakang. HTML5 menjadi standar modern.

2. Apa Itu XHTML?

XHTML (eXtensible HyperText Markup Language) adalah bahasa markup yang menggabungkan HTML dengan aturan ketat XML (eXtensible Markup Language).

🌐 HTML

  • Berbasis SGML (Standard Generalized Markup Language)
  • Parser HTML sangat toleran terhadap kesalahan
  • Aturan penulisan fleksibel
  • Browser tetap menampilkan halaman meski ada kesalahan kode

📐 XHTML

  • Berbasis XML (eXtensible Markup Language)
  • Parser XML sangat ketat — satu kesalahan bisa membuat halaman gagal dimuat
  • Aturan penulisan sangat ketat
  • Harus 100% valid dan well-formed
ℹ️ Analogi: HTML seperti percakapan santai — boleh ada sedikit kesalahan tata bahasa dan lawan bicara masih mengerti. XHTML seperti dokumen resmi — satu tanda baca salah bisa membuat dokumen ditolak.

3. Deklarasi DOCTYPE

Perbedaan pertama yang terlihat adalah cara mendeklarasikan DOCTYPE:

HTML HTML5 DOCTYPE (Sederhana):

<!DOCTYPE html>

XHTML XHTML 1.0 Strict DOCTYPE (Panjang):

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">

XHTML XHTML 1.0 Transitional DOCTYPE:

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">

XHTML XHTML 1.0 Frameset DOCTYPE:

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Frameset//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-frameset.dtd">

XHTML juga memerlukan deklarasi namespace XML pada tag <html>:

<html xmlns="http://www.w3.org/1999/xhtml">

4. Aturan-Aturan Wajib XHTML

XHTML memiliki aturan yang jauh lebih ketat dibanding HTML. Berikut adalah aturan-aturan utamanya:

📌 Aturan 1: Semua Tag Harus Huruf Kecil (Lowercase)

Dalam XHTML, semua nama tag dan atribut harus ditulis dalam huruf kecil.

❌ Salah (HTML memperbolehkan, XHTML tidak):

<BODY> <P>Ini adalah paragraf.</P> <IMG SRC="foto.jpg" ALT="Foto"> </BODY>

✅ Benar (XHTML):

<body> <p>Ini adalah paragraf.</p> <img src="foto.jpg" alt="Foto" /> </body>

📌 Aturan 2: Semua Tag Harus Ditutup

Dalam HTML, beberapa tag bisa tidak ditutup (seperti <br>, <img>, <p>). Dalam XHTML, semua tag harus ditutup.

❌ Salah (XHTML):

<p>Paragraf pertama. <p>Paragraf kedua. <br> <img src="foto.jpg" alt="Foto"> <hr> <input type="text">

✅ Benar (XHTML) — Tag kosong ditutup dengan " /":

<p>Paragraf pertama.</p> <p>Paragraf kedua.</p> <br /> <img src="foto.jpg" alt="Foto" /> <hr /> <input type="text" />

📌 Aturan 3: Tag Harus Ditumpuk dengan Benar (Proper Nesting)

Dalam XHTML, tag harus dibuka dan ditutup dalam urutan yang benar (LIFO — Last In, First Out). Tag yang dibuka terakhir harus ditutup pertama.

❌ Salah — Tumpukan tag salah:

<b><i>Teks tebal dan miring</b></i> <p><span>Teks</p></span>

✅ Benar — Tumpukan tag benar:

<b><i>Teks tebal dan miring</i></b> <p><span>Teks</span></p>
💡 Bayangkan seperti kurung dalam matematika: ([ ]) benar, ([)] salah. Tag HTML/XHTML bekerja sama persis.

📌 Aturan 4: Nilai Atribut Harus Menggunakan Tanda Kutip

Semua nilai atribut dalam XHTML harus diapit dengan tanda kutip (bisa tanda kutip ganda atau tunggal).

❌ Salah — Tanpa tanda kutip:

<img src=foto.jpg alt=Foto width=300 height=200> <table border=1> <input type=text name=nama size=30>

✅ Benar — Dengan tanda kutip ganda:

<img src="foto.jpg" alt="Foto" width="300" height="200" /> <table border="1"> <input type="text" name="nama" size="30" />

✅ Juga benar — Dengan tanda kutip tunggal:

<img src='foto.jpg' alt='Foto' width='300' height='200' />

📌 Aturan 5: Atribut Tidak Boleh Disingkat (No Attribute Minimization)

Dalam HTML, beberapa atribut boolean bisa ditulis tanpa nilai. Dalam XHTML, semua atribut harus memiliki nilai eksplisit.

❌ Salah (XHTML):

<input type="checkbox" checked> <input type="text" disabled> <option selected>Pilihan 1</option>

✅ Benar (XHTML):

<input type="checkbox" checked="checked" /> <input type="text" disabled="disabled" /> <option selected="selected">Pilihan 1</option>

📌 Aturan 6: Dokumen XHTML Harus Memiliki Satu Elemen Root

Setiap dokumen XHTML harus memiliki tepat satu elemen root, yaitu tag <html>, dan semua elemen lain harus berada di dalam elemen root ini.

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd"> <html xmlns="http://www.w3.org/1999/xhtml"> <head> <meta charset="UTF-8" /> <title>Dokumen XHTML</title> </head> <body> <p>Semua konten ada di dalam elemen root &lt;html&gt;</p> </body> </html>

Nesting Tag Browser mencoba memperbaiki Harus benar-benar tepat

6. Contoh Dokumen HTML vs XHTML

HTML5

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Halaman HTML</title> </head> <body> <h1>Judul Halaman</h1> <P>Paragraf dengan tag besar. <img src="foto.jpg" alt="foto"> <br> <input type="checkbox" checked> Setuju </body> </html>

✅ Halaman ini valid di HTML5 meskipun banyak "kekurangan".

XHTML 1.0

<?xml version="1.0" encoding="UTF-8"?> <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/ xhtml1/DTD/ xhtml1-strict.dtd"> <html xmlns= "http://www.w3.org/ 1999/xhtml" lang="id"> <head> <meta charset="UTF-8" /> <title>Halaman XHTML</title> </head> <body> <h1>Judul Halaman</h1> <p>Paragraf yang benar.</p> <img src="foto.jpg" alt="foto" /> <br /> <input type="checkbox" checked="checked" /> Setuju </body> </html>

✅ Semua aturan XHTML dipenuhi.

7. Perbedaan Penanganan Error

Salah satu perbedaan paling fundamental adalah cara browser menangani error:

Situasi HTML XHTML
Tag tidak ditutup ✅ Browser otomatis menutup ❌ Error — halaman rusak
Tag tidak tertutup dengan benar (nesting salah) ✅ Browser mencoba memperbaiki ❌ Error — parsing berhenti
Nama tag huruf besar ✅ Diterima (<P> = <p>) ❌ Error — tidak dikenali
Nilai atribut tanpa tanda kutip ✅ Diterima di HTML4 ❌ Error di XHTML
Karakter < dan & tanpa escape ⚠️ Tergantung konteks ❌ Error — harus &lt; dan &amp;

8. XHTML dan Karakter Khusus

Dalam XHTML, karakter-karakter khusus XML harus di-escape menggunakan HTML entities:

KarakterEntityKeterangan
<&lt;Tanda kurang dari (less than)
>&gt;Tanda lebih dari (greater than)
&&amp;Ampersand
"&quot;Tanda kutip ganda
'&apos;Tanda kutip tunggal (apostrof)
<!-- Dalam XHTML, karakter khusus harus di-escape --> <p>Nilai variabel: a &lt; b &amp;&amp; b &gt; c</p> <p>Tag HTML ditulis: &lt;p&gt;paragraf&lt;/p&gt;</p> <a href="halaman.html?id=1&amp;lang=id">Link</a>

9. XHTML dalam Praktik Saat Ini

Meskipun XHTML sempat populer di awal 2000-an, saat ini penggunaannya sangat berkurang karena:

  • ❌ Terlalu ketat — satu kesalahan kecil bisa membuat seluruh halaman gagal ditampilkan
  • ❌ Lebih verbose (banyak kode) tanpa manfaat yang jelas bagi pengguna biasa
  • ❌ HTML5 sudah mengadopsi praktik-praktik baik dari XHTML
  • ❌ Sebagian besar server masih mengirim XHTML dengan MIME type text/html, membuat browser memprosesnya sebagai HTML biasa
💡 Rekomendasi Saat Ini: Gunakan HTML5 dengan praktik penulisan yang baik (tutup semua tag, gunakan huruf kecil, gunakan tanda kutip untuk atribut). Ini memberikan fleksibilitas HTML dengan keterbacaan XHTML.

10. Praktik Terbaik HTML5 yang Terinspirasi XHTML

Meski menggunakan HTML5, ada baiknya mengikuti konvensi penulisan yang bersih seperti XHTML:

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Praktik Terbaik HTML5</title> </head> <body> <!-- ✅ Semua tag huruf kecil --> <h1>Judul Utama</h1> <!-- ✅ Semua tag ditutup --> <p>Ini adalah paragraf yang ditutup dengan benar.</p> <!-- ✅ Tag kosong juga "ditutup" (opsional di HTML5, tapi disarankan) --> <br /> <img src="foto.jpg" alt="Deskripsi foto" /> <hr /> <!-- ✅ Semua nilai atribut menggunakan tanda kutip --> <a href="halaman.html" class="link-utama">Klik di sini</a> <!-- ✅ Nesting yang benar --> <p><strong><em>Teks penting</em></strong></p> <!-- ✅ Form input dengan label --> <form action="/proses" method="post"> <label for="nama">Nama:</label> <input type="text" id="nama" name="nama" /> <button type="submit">Kirim</button> </form> </body> </html>

11. Ringkasan Perbedaan HTML dan XHTML

Aturan Contoh Salah (HTML memperbolehkan) Contoh Benar (XHTML wajib)
Huruf kecil <TABLE>, <TR>, <TD> <table>, <tr>, <td>
Tag ditutup <p>Teks <br> <p>Teks</p> <br />
Nesting benar <b><i>teks</b></i> <b><i>teks</i></b>
Tanda kutip atribut <a href=halaman.html> <a href="halaman.html">
Atribut boolean <input disabled> <input disabled="disabled" />
Escape karakter <a href="a.html&b=1"> <a href="a.html&amp;b=1">
📌 Kesimpulan:
  • Gunakan HTML5 untuk proyek web modern
  • Ikuti konvensi penulisan yang bersih: huruf kecil, tutup semua tag, gunakan tanda kutip
  • XHTML masih relevan secara historis dan memahaminya membantu kamu menulis HTML yang lebih baik
  • Validasi HTML kamu di W3C Markup Validation Service
