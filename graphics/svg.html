🔷 HTML SVG

SVG (Scalable Vector Graphics) adalah format grafis berbasis XML untuk menggambar grafis vektor di web. Berbeda dengan Canvas yang berbasis piksel, SVG mendefinisikan bentuk secara matematis sehingga gambar tetap tajam di semua ukuran dan resolusi layar.

1. Apa Itu SVG?

SVG adalah singkatan dari Scalable Vector Graphics. SVG menggunakan sintaks berbasis XML, yang berarti setiap elemen grafis (lingkaran, kotak, garis, dll.) adalah sebuah tag HTML yang bisa diakses dan dimanipulasi langsung melalui CSS atau JavaScript.

ℹ️ Keunggulan utama SVG: Gambar tidak akan buram saat diperbesar karena dideskripsikan secara matematis, bukan dengan piksel. Satu file SVG yang sama bisa tampil sempurna di layar kecil maupun billboard raksasa.
<!-- SVG langsung di dalam HTML --> <svg width="200" height="100" xmlns="http://www.w3.org/2000/svg"> <rect width="200" height="100" fill="#04AA6D" /> <text x="100" y="55" fill="white" text-anchor="middle" font-size="18"> Halo SVG! </text> </svg>

2. Elemen <rect> — Persegi Panjang

Elemen <rect> digunakan untuk menggambar persegi panjang. Atribut rx dan ry bisa digunakan untuk sudut yang membulat.

<svg width="400" height="130" xmlns="http://www.w3.org/2000/svg"> <!-- Persegi panjang biasa --> <rect x="10" y="20" width="120" height="80" fill="#04AA6D" /> <!-- Persegi panjang dengan border (stroke) --> <rect x="150" y="20" width="120" height="80" fill="none" stroke="#e91e63" stroke-width="3" /> <!-- Persegi dengan sudut bulat --> <rect x="290" y="20" width="100" height="80" fill="#1565C0" rx="15" ry="15" opacity="0.8" /> </svg>

▶ Hasil:

4. Elemen <ellipse> — Elips

Elemen <ellipse> serupa dengan lingkaran, namun memiliki dua jari-jari berbeda: horizontal (rx) dan vertikal (ry).

6. Elemen <polygon> — Poligon

Elemen <polygon> menggambar bentuk tertutup (closed shape) dari sekumpulan titik. Garis dari titik terakhir secara otomatis kembali ke titik pertama.

<svg width="400" height="160" xmlns="http://www.w3.org/2000/svg"> <!-- Segitiga --> <polygon points="90,10 20,150 160,150" fill="#FF5733" opacity="0.85" /> <!-- Segilima (pentagon) --> <polygon points="265,15 310,55 295,110 235,110 220,55" fill="#04AA6D" stroke="white" stroke-width="2" /> <!-- Bintang 6 sudut --> <polygon points="360,10 370,40 400,40 375,60 385,90 360,72 335,90 345,60 320,40 350,40" fill="#F39C12" /> </svg>

7. Elemen <polyline> — Garis Beruntun

Elemen <polyline> mirip dengan <polygon>, namun tidak menutup garis secara otomatis. Cocok untuk grafik garis (line chart).

8. Elemen <path> — Path (Jalur Kustom)

Elemen <path> adalah elemen SVG paling powerful. Ia dapat membuat hampir semua bentuk menggunakan atribut d (data path) yang berisi serangkaian perintah gambar.

Perintah Path Utama

PerintahNamaParameter
MMove Tox y — Pindah ke titik
LLine Tox y — Garis lurus ke titik
HHorizontal Linex — Garis horizontal
VVertical Liney — Garis vertikal
CCubic Bezierx1 y1, x2 y2, x y
QQuadratic Bezierx1 y1, x y
AArcrx ry xrot large-arc sweep x y
ZClose PathSambung ke titik awal

Huruf kecil (m, l, h, v, c, q, a, z) berarti koordinat relatif terhadap posisi saat ini.

<svg width="400" height="200" xmlns="http://www.w3.org/2000/svg"> <!-- Bentuk custom dengan garis lurus --> <path d="M 20 160 L 80 20 L 140 160 Z" fill="#FF5733" /> <!-- Kurva Bezier kuadratik --> <path d="M 170 160 Q 230 20 290 160" fill="none" stroke="#04AA6D" stroke-width="3" /> <!-- Kurva Bezier kubik --> <path d="M 170 160 C 185 20 275 20 290 160" fill="rgba(4,170,109,0.15)" stroke="none" /> <!-- Arc (busur elips) --> <path d="M 310 160 A 50 80 0 0 1 390 160" fill="#9C27B0" opacity="0.8" /> <!-- Anak panah / arrow --> <path d="M 50 185 L 350 185 L 330 175 M 350 185 L 330 195" fill="none" stroke="#1565C0" stroke-width="2" stroke-linecap="round" /> </svg>

9. Elemen <text> dan <tspan> — Teks SVG

SVG memiliki elemen <text> untuk menampilkan teks. Teks SVG adalah bagian dari DOM, sehingga bisa diindeks oleh mesin pencari dan diakses oleh screen reader.

<svg width="400" height="160" xmlns="http://www.w3.org/2000/svg"> <!-- Teks biasa --> <text x="20" y="40" font-size="22" fill="#04AA6D" font-family="Segoe UI, sans-serif" font-weight="bold"> Halo, SVG! </text> <!-- Teks tengah (text-anchor) --> <text x="200" y="80" font-size="16" fill="#333" text-anchor="middle" font-style="italic"> Teks di tengah </text> <!-- Teks dengan stroke --> <text x="20" y="120" font-size="28" fill="none" stroke="#e91e63" stroke-width="1.5"> Outline Only </text> <!-- tspan untuk span di dalam teks --> <text x="20" y="155" font-size="15" fill="#555"> Ini <tspan fill="#04AA6D" font-weight="bold">hijau</tspan> dan <tspan fill="#e91e63">merah</tspan> </text> </svg>

10. Gradien dan Filter pada SVG

SVG mendukung gradien melalui elemen <defs>. Gradien didefinisikan di dalam <defs> lalu direferensikan menggunakan url(#id).

<svg width="400" height="150" xmlns="http://www.w3.org/2000/svg"> <defs> <!-- Linear Gradient --> <linearGradient id="linGrad" x1="0%" y1="0%" x2="100%" y2="0%"> <stop offset="0%" stop-color="#04AA6D" /> <stop offset="100%" stop-color="#1a237e" /> </linearGradient> <!-- Radial Gradient --> <radialGradient id="radGrad" cx="50%" cy="50%" r="50%"> <stop offset="0%" stop-color="#FFEB3B" /> <stop offset="100%" stop-color="#FF5722" /> </radialGradient> </defs> <rect x="10" y="20" width="180" height="100" fill="url(#linGrad)" rx="8" /> <circle cx="310" cy="70" r="60" fill="url(#radGrad)" /> </svg>

11. Animasi SVG

SVG mendukung animasi bawaan menggunakan elemen <animate> dan <animateTransform>, atau bisa juga menggunakan CSS @keyframes.

<svg width="400" height="120" xmlns="http://www.w3.org/2000/svg"> <!-- Lingkaran bergerak (translate animasi) --> <circle cx="60" cy="60" r="30" fill="#04AA6D"> <animateTransform attributeName="transform" type="translate" values="0,0; 280,0; 0,0" dur="3s" repeatCount="indefinite" /> </circle> <!-- Kotak berputar --> <rect x="350" y="35" width="40" height="40" fill="#e91e63"> <animateTransform attributeName="transform" type="rotate" values="0 370 55; 360 370 55" dur="2s" repeatCount="indefinite" /> </rect> </svg>

12. SVG vs Canvas — Perbandingan Lengkap

🔷 SVG (Scalable Vector Graphics)

  • ✅ Berbasis vektor — tajam di semua resolusi
  • ✅ Bagian dari DOM — bisa diakses CSS & JS
  • ✅ Teks dapat diindeks search engine
  • ✅ Mudah dibuat animasi dengan CSS
  • ✅ Event listener per elemen
  • ✅ Ideal untuk ikon, logo, ilustrasi
  • ❌ Lambat untuk ribuan elemen kompleks
  • ❌ Tidak cocok untuk efek berbasis piksel

🎨 Canvas (HTML Canvas)

  • ✅ Performa tinggi untuk animasi kompleks
  • ✅ Kontrol penuh piksel per piksel
  • ✅ Cocok untuk game dan manipulasi gambar
  • ✅ WebGL untuk grafis 3D
  • ✅ Bisa ekspor sebagai gambar (PNG/JPG)
  • ❌ Gambar raster — buram saat diperbesar
  • ❌ Tidak ada akses DOM per elemen
  • ❌ Tidak bisa diindeks search engine
KriteriaSVGCanvas
Ikon / Logo✅ Direkomendasikan❌ Tidak ideal
Game 2D❌ Kurang performa✅ Direkomendasikan
Infografis✅ Direkomendasikan✅ Bisa
Photo Editing❌ Tidak cocok✅ Direkomendasikan
Animasi Interaktif✅ Mudah✅ Fleksibel
Responsif/Scalable✅ Native⚠️ Perlu penanganan manual
💡 Saran: Tidak perlu memilih salah satu secara mutlak! Dalam aplikasi web modern, kedua teknologi sering digunakan bersamaan sesuai kebutuhan spesifik masing-masing komponen.
