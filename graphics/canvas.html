🎨 HTML Canvas

Elemen <canvas> adalah salah satu fitur paling powerful yang diperkenalkan oleh HTML5. Elemen ini menyediakan area gambar berbasis piksel di dalam halaman web yang dapat dikendalikan sepenuhnya menggunakan JavaScript.

1. Apa Itu Elemen <canvas>?

Elemen <canvas> adalah wadah (container) kosong untuk grafis. Elemen ini tidak dapat menggambar apapun sendiri — Anda harus menggunakan JavaScript untuk melakukan operasi menggambar melalui Canvas API.

Canvas bekerja seperti "papan kanvas" digital di mana Anda bisa menggambar piksel demi piksel menggunakan skrip. Hasilnya adalah gambar raster (berbasis piksel), mirip dengan PNG atau JPG.

<!-- Sintaks dasar elemen canvas --> <canvas id="myCanvas" width="400" height="200"> Browser Anda tidak mendukung Canvas. </canvas>
⚠️ Penting: Teks di dalam tag <canvas> hanya ditampilkan jika browser tidak mendukung canvas. Ini berfungsi sebagai fallback content.

2. Mengakses Konteks Canvas (getContext)

Sebelum bisa menggambar, Anda perlu mendapatkan objek "konteks" dari canvas. Konteks inilah yang menyediakan semua method menggambar.

// Mendapatkan elemen canvas dari DOM var canvas = document.getElementById("myCanvas"); // Mendapatkan konteks 2D var ctx = canvas.getContext("2d"); // Sekarang Anda bisa menggambar menggunakan 'ctx'
ℹ️ getContext("2d") mengembalikan objek CanvasRenderingContext2D yang memiliki puluhan method dan properti untuk menggambar. Selain "2d", ada juga "webgl" untuk grafis 3D.

3. Menggambar Persegi Panjang (Rectangle)

Canvas API menyediakan tiga method bawaan untuk menggambar persegi panjang:

  • fillRect(x, y, width, height) — Menggambar persegi panjang yang terisi warna
  • strokeRect(x, y, width, height) — Menggambar persegi panjang hanya garisnya (outline)
  • clearRect(x, y, width, height) — Menghapus area persegi panjang (menjadi transparan)
<canvas id="rectCanvas" width="400" height="180"></canvas> <script> var canvas = document.getElementById("rectCanvas"); var ctx = canvas.getContext("2d"); // Persegi panjang terisi penuh (merah) ctx.fillStyle = "#FF5733"; ctx.fillRect(20, 20, 160, 100); // Persegi panjang hanya outline (biru) ctx.strokeStyle = "#1565C0"; ctx.lineWidth = 3; ctx.strokeRect(220, 20, 150, 100); // Menghapus sebagian area dari persegi merah ctx.clearRect(50, 50, 60, 40); </script>

4. Menggambar Lingkaran (Circle/Arc)

Canvas tidak memiliki method khusus untuk lingkaran. Sebagai gantinya, kita menggunakan method arc() yang menggambar busur (arc) — dan dengan sudut penuh (0 hingga 2π), kita mendapatkan lingkaran sempurna.

ctx.arc(x, y, radius, startAngle, endAngle, anticlockwise) // x, y : koordinat pusat lingkaran // radius : jari-jari lingkaran // startAngle : sudut mulai dalam radian (0 = kanan) // endAngle : sudut akhir (Math.PI * 2 = lingkaran penuh) // anticlockwise : true = berlawanan jarum jam (opsional)
<canvas id="circleCanvas" width="400" height="180"></canvas> <script> var canvas = document.getElementById("circleCanvas"); var ctx = canvas.getContext("2d"); // Lingkaran terisi (solid fill) ctx.beginPath(); ctx.arc(90, 90, 60, 0, Math.PI * 2); ctx.fillStyle = "#04AA6D"; ctx.fill(); ctx.strokeStyle = "#027a4e"; ctx.lineWidth = 3; ctx.stroke(); // Setengah lingkaran (semi-circle) ctx.beginPath(); ctx.arc(240, 90, 55, 0, Math.PI); // 0 sampai PI = setengah ctx.strokeStyle = "#e91e63"; ctx.lineWidth = 4; ctx.stroke(); // Busur / Arc biasa ctx.beginPath(); ctx.arc(360, 90, 50, Math.PI * 0.25, Math.PI * 1.25); ctx.fillStyle = "#FF9800"; ctx.fill(); </script>

▶ Hasil:

⚠️ beginPath(): Selalu panggil ctx.beginPath() sebelum menggambar bentuk baru. Ini memberi tahu canvas bahwa Anda memulai path (jalur) baru, sehingga operasi gambar tidak terhubung dengan bentuk sebelumnya.

5. Menggambar Garis (Line)

Untuk menggambar garis, kita menggunakan kombinasi method moveTo(), lineTo(), dan stroke().

  • moveTo(x, y) — Memindahkan "pena" ke titik awal tanpa menggambar
  • lineTo(x, y) — Menggambar garis dari posisi saat ini ke titik baru
  • stroke() — Merender/menampilkan garis yang telah didefinisikan
<canvas id="lineCanvas" width="400" height="200"></canvas> <script> var canvas = document.getElementById("lineCanvas"); var ctx = canvas.getContext("2d"); // Garis sederhana ctx.beginPath(); ctx.moveTo(20, 50); ctx.lineTo(380, 50); ctx.strokeStyle = "#333"; ctx.lineWidth = 2; ctx.stroke(); // Garis putus-putus (setLineDash) ctx.beginPath(); ctx.setLineDash([10, 5]); // [panjang dash, panjang gap] ctx.moveTo(20, 100); ctx.lineTo(380, 100); ctx.strokeStyle = "#e91e63"; ctx.lineWidth = 2; ctx.stroke(); // Segitiga dari garis-garis ctx.setLineDash([]); // reset dash ctx.beginPath(); ctx.moveTo(200, 120); ctx.lineTo(100, 185); ctx.lineTo(300, 185); ctx.closePath(); // sambung ke titik awal ctx.strokeStyle = "#1565C0"; ctx.lineWidth = 3; ctx.stroke(); ctx.fillStyle = "rgba(21, 101, 192, 0.2)"; ctx.fill(); </script>

6. Menggambar Teks (Text)

Canvas dapat menggambar teks menggunakan method berikut:

  • fillText(text, x, y) — Menulis teks terisi warna
  • strokeText(text, x, y) — Menulis teks hanya outline-nya
  • measureText(text) — Mengukur lebar teks (hasilnya dalam piksel)
<canvas id="textCanvas" width="400" height="200"></canvas> <script> var canvas = document.getElementById("textCanvas"); var ctx = canvas.getContext("2d"); // Teks terisi biasa ctx.font = "bold 28px Segoe UI"; ctx.fillStyle = "#04AA6D"; ctx.fillText("Halo, Canvas!", 60, 60); // Teks dengan outline saja ctx.font = "30px Georgia"; ctx.strokeStyle = "#e91e63"; ctx.lineWidth = 1.5; ctx.strokeText("Outline Text", 80, 110); // Teks dengan alignment ctx.font = "18px Arial"; ctx.fillStyle = "#555"; ctx.textAlign = "center"; ctx.fillText("Teks di tengah canvas", 200, 155); // Teks kecil ctx.font = "italic 14px Arial"; ctx.fillStyle = "#999"; ctx.textAlign = "left"; ctx.fillText("Canvas width: " + canvas.width + "px | height: " + canvas.height + "px", 20, 190); </script>

7. Contoh Lengkap: Menggabungkan Semua Elemen

Berikut adalah contoh yang menggabungkan berbagai teknik menggambar canvas untuk membuat sebuah kartu sederhana.

<canvas id="fullCanvas" width="400" height="250"></canvas> <script> var canvas = document.getElementById("fullCanvas"); var ctx = canvas.getContext("2d"); // Background kartu ctx.fillStyle = "#1a1a2e"; ctx.fillRect(0, 0, 400, 250); // Dekorasi lingkaran besar (transparan) ctx.beginPath(); ctx.arc(350, 50, 80, 0, Math.PI * 2); ctx.fillStyle = "rgba(4, 170, 109, 0.15)"; ctx.fill(); // Garis dekoratif atas ctx.beginPath(); ctx.moveTo(0, 55); ctx.lineTo(400, 55); ctx.strokeStyle = "#04AA6D"; ctx.lineWidth = 2; ctx.stroke(); // Judul ctx.font = "bold 24px Segoe UI"; ctx.fillStyle = "#04AA6D"; ctx.fillText("HTML CANVAS", 30, 42); // Subtitle ctx.font = "13px Segoe UI"; ctx.fillStyle = "#aaa"; ctx.fillText("Elemen Grafis HTML5", 30, 90); // Lingkaran kecil dekoratif var colors = ["#FF5733","#04AA6D","#3498DB","#F39C12","#9B59B6"]; for (var i = 0; i < 5; i++) { ctx.beginPath(); ctx.arc(50 + i * 70, 160, 25, 0, Math.PI * 2); ctx.fillStyle = colors[i]; ctx.fill(); } // Label ctx.font = "12px Segoe UI"; ctx.fillStyle = "white"; ctx.textAlign = "center"; var labels = ["fill","arc","line","text","path"]; for (var j = 0; j < 5; j++) { ctx.fillText(labels[j], 50 + j * 70, 200); } // Footer text ctx.textAlign = "left"; ctx.font = "11px Arial"; ctx.fillStyle = "#555"; ctx.fillText("Canvas API — 2D Context", 30, 235); </script>

8. Gradien pada Canvas

Canvas mendukung dua jenis gradien:

  • createLinearGradient(x0,y0,x1,y1) — Gradien linear (dari satu titik ke titik lain)
  • createRadialGradient(x0,y0,r0,x1,y1,r1) — Gradien radial (lingkaran ke lingkaran)
<canvas id="gradCanvas" width="400" height="120"></canvas> <script> var canvas = document.getElementById("gradCanvas"); var ctx = canvas.getContext("2d"); // Linear Gradient (kiri ke kanan) var linGrad = ctx.createLinearGradient(0, 0, 190, 0); linGrad.addColorStop(0, "#04AA6D"); linGrad.addColorStop(1, "#1a237e"); ctx.fillStyle = linGrad; ctx.fillRect(10, 20, 180, 80); // Radial Gradient (dari dalam ke luar) var radGrad = ctx.createRadialGradient(300, 60, 10, 300, 60, 60); radGrad.addColorStop(0, "#FFEB3B"); radGrad.addColorStop(0.5, "#FF5722"); radGrad.addColorStop(1, "rgba(0,0,0,0)"); ctx.fillStyle = radGrad; ctx.fillRect(220, 0, 170, 120); </script>
