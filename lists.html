HTML Lists (Daftar)

HTML menyediakan tiga jenis daftar untuk menampilkan item-item secara terorganisir: Unordered List (daftar tak berurutan), Ordered List (daftar berurutan), dan Description List (daftar deskripsi).

1. Unordered List — Daftar Tak Berurutan (<ul>)

Unordered List digunakan ketika urutan item tidak penting. Setiap item ditandai dengan bullet (titik/bulatan) secara default.

<ul> <li>Apel</li> <li>Mangga</li> <li>Jeruk</li> <li>Pisang</li> </ul>
Hasil:
  • Apel
  • Mangga
  • Jeruk
  • Pisang

Tipe Bullet Unordered List

Gunakan properti CSS list-style-type untuk mengubah bentuk bullet:

Nilai list-style-type Tampilan Keterangan
disc (default) ● Lingkaran penuh (default)
circle ○ Lingkaran kosong
square ■ Kotak penuh
none (tidak ada) Tanpa tanda bullet
<!-- Disc (default) --> <ul style="list-style-type: disc;"> <li>Item A</li> <li>Item B</li> </ul> <!-- Circle --> <ul style="list-style-type: circle;"> <li>Item A</li> <li>Item B</li> </ul> <!-- Square --> <ul style="list-style-type: square;"> <li>Item A</li> <li>Item B</li> </ul> <!-- None --> <ul style="list-style-type: none; padding: 0;"> <li>Item A</li> <li>Item B</li> </ul>
Perbandingan tipe bullet:

disc (default):

  • Item A
  • Item B

circle:

  • Item A
  • Item B

square:

  • Item A
  • Item B

none:

  • Item A
  • Item B

2. Ordered List — Daftar Berurutan (<ol>)

Ordered List digunakan ketika urutan item penting, seperti langkah-langkah instruksi atau peringkat. Setiap item diberi nomor secara otomatis.

<ol> <li>Cuci tangan terlebih dahulu</li> <li>Siapkan bahan-bahan</li> <li>Mulai memasak</li> <li>Sajikan di piring</li> </ol>
Hasil:
  1. Cuci tangan terlebih dahulu
  2. Siapkan bahan-bahan
  3. Mulai memasak
  4. Sajikan di piring

Atribut type pada Ordered List

Gunakan atribut type untuk mengubah format penomoran:

Nilai type Format Contoh
1 (default) Angka desimal 1, 2, 3, ...
a Huruf kecil a, b, c, ...
A Huruf besar A, B, C, ...
i Angka Romawi kecil i, ii, iii, ...
I Angka Romawi besar I, II, III, ...
<!-- Huruf kecil --> <ol type="a"> <li>Item pertama</li> <li>Item kedua</li> </ol> <!-- Angka Romawi besar --> <ol type="I"> <li>Pendahuluan</li> <li>Pembahasan</li> </ol>
Perbandingan tipe ordered list:

type="a" (huruf kecil):

  1. Item satu
  2. Item dua
  3. Item tiga

type="A" (huruf besar):

  1. Item satu
  2. Item dua
  3. Item tiga

type="i" (romawi kecil):

  1. Item satu
  2. Item dua
  3. Item tiga

type="I" (romawi besar):

  1. Item satu
  2. Item dua
  3. Item tiga

Atribut start dan reversed

<!-- Mulai dari angka 5 --> <ol start="5"> <li>Langkah kelima</li> <li>Langkah keenam</li> </ol> <!-- Urutan terbalik (10, 9, 8, ...) --> <ol reversed> <li>Item terakhir</li> <li>Item kedua dari belakang</li> <li>Item pertama</li> </ol>

3. Description List — Daftar Deskripsi (<dl>)

Description List digunakan untuk menampilkan pasangan istilah dan deskripsinya. Cocok untuk glosarium, kamus, atau FAQ.

Tag Keterangan
<dl> Description List — wadah daftar deskripsi
<dt> Description Term — istilah/kata yang didefinisikan
<dd> Description Details — penjelasan/definisi dari istilah
<dl> <dt>HTML</dt> <dd>HyperText Markup Language — bahasa standar untuk membuat halaman web</dd> <dt>CSS</dt> <dd>Cascading Style Sheets — digunakan untuk mengatur tampilan halaman HTML</dd> <dt>JavaScript</dt> <dd>Bahasa pemrograman yang membuat halaman web menjadi interaktif</dd> </dl>
Hasil:
HTML
HyperText Markup Language — bahasa standar untuk membuat halaman web
CSS
Cascading Style Sheets — digunakan untuk mengatur tampilan halaman HTML
JavaScript
Bahasa pemrograman yang membuat halaman web menjadi interaktif

4. Nested List — Daftar Bersarang

Daftar dapat disusun secara bertingkat (nested) dengan menempatkan <ul> atau <ol> di dalam elemen <li>.

<ul> <li>Buah-buahan <ul> <li>Tropis <ul> <li>Mangga</li> <li>Durian</li> </ul> </li> <li>Subtropis <ul> <li>Apel</li> <li>Anggur</li> </ul> </li> </ul> </li> <li>Sayuran <ul> <li>Bayam</li> <li>Kangkung</li> </ul> </li> </ul>
Hasil:
  • Buah-buahan
    • Tropis
      • Mangga
      • Durian
    • Subtropis
      • Apel
      • Anggur
  • Sayuran
    • Bayam
    • Kangkung

Daftar Campuran (Ordered + Unordered)

<ol> <li>Persiapan <ul> <li>Siapkan laptop</li> <li>Install text editor</li> </ul> </li> <li>Mulai coding <ul> <li>Buat file HTML</li> <li>Tulis kode</li> </ul> </li> </ol>

5. Kustomisasi Daftar dengan CSS

Navigasi menggunakan <ul>

Salah satu penggunaan umum <ul> adalah membuat navigasi horizontal:

<style> .nav-menu { list-style: none; padding: 0; display: flex; gap: 20px; background: #04AA6D; padding: 12px 20px; border-radius: 6px; } .nav-menu li a { color: white; text-decoration: none; font-weight: 500; } .nav-menu li a:hover { text-decoration: underline; } </style> <ul class="nav-menu"> <li><a href="#">Beranda</a></li> <li><a href="#">Tentang</a></li> <li><a href="#">Layanan</a></li> <li><a href="#">Kontak</a></li> </ul>
Hasil — Navigasi dari <ul>:

  • Beranda
  • Tentang
  • Layanan
  • Kontak

Daftar dengan Ikon Kustom

<style> .checklist { list-style: none; padding: 0; } .checklist li { padding: 8px 0 8px 30px; position: relative; border-bottom: 1px solid #eee; } .checklist li::before { content: "✓"; position: absolute; left: 0; color: #04AA6D; font-weight: bold; } </style> <ul class="checklist"> <li>Desain responsif</li> <li>Kode yang bersih</li> <li>Dokumentasi lengkap</li> <li>Performa tinggi</li> </ul>
Hasil — Checklist kustom:
  • Desain responsif
  • Kode yang bersih
  • Dokumentasi lengkap
  • Performa tinggi

Daftar Dua Kolom

<style> .two-col { columns: 2; /* Bagi menjadi 2 kolom */ list-style-type: disc; padding-left: 20px; } </style> <ul class="two-col"> <li>Jakarta</li> <li>Surabaya</li> <li>Bandung</li> <li>Medan</li> <li>Semarang</li> <li>Makassar</li> </ul>
Hasil — Daftar dua kolom:
  • Jakarta
  • Surabaya
  • Bandung
  • Medan
  • Semarang
  • Makassar
💡 Kapan menggunakan jenis daftar apa?
  • <ul> — Untuk daftar item yang tidak memerlukan urutan (bahan makanan, fitur produk, menu navigasi)
  • <ol> — Untuk instruksi bertahap, langkah-langkah, atau peringkat
  • <dl> — Untuk glosarium, FAQ, atau pasangan istilah-definisi

Ringkasan Tag Daftar

Tag Jenis Keterangan
<ul> Unordered List Daftar dengan bullet point, urutan tidak penting
<ol> Ordered List Daftar bernomor, urutan penting
<li> List Item Item dalam <ul> atau <ol>
<dl> Description List Daftar istilah dan deskripsi
<dt> Description Term Istilah dalam <dl>
<dd> Description Details Deskripsi dari <dt>
