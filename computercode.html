HTML Computer Code Elements

HTML menyediakan beberapa elemen khusus untuk menampilkan konten yang berkaitan dengan pemrograman komputer dan kode. Elemen-elemen ini memiliki makna semantik tertentu dan biasanya ditampilkan dengan font monospace (setiap karakter memiliki lebar yang sama).

Elemen Deskripsi Contoh Tampilan
<code> Menampilkan sepotong kode komputer (inline) printf("Hello");
<kbd> Input dari keyboard (tombol yang ditekan pengguna) Ctrl + C
<samp> Output/keluaran dari program komputer File not found.
<var> Variabel dalam program atau persamaan matematika x = y + 5
<pre> Preformatted text — menjaga whitespace dan baris baru Teks
  dengan spasi

1. 💻 Elemen <code>

Elemen <code> digunakan untuk menampilkan sepotong kode komputer secara inline (di dalam teks biasa). Browser menampilkannya dengan font monospace. Elemen ini tidak menjaga whitespace ekstra atau baris baru.

<!-- Contoh penggunaan <code> --> <p>Fungsi <code>printf()</code> digunakan untuk menampilkan output di C.</p> <p>Dalam JavaScript, gunakan <code>console.log()</code> untuk debug.</p> <p>Tag HTML <code>&lt;h1&gt;</code> digunakan untuk heading utama.</p>

🟢 Hasil Tampilan:

Fungsi printf() digunakan untuk menampilkan output di C.

Dalam JavaScript, gunakan console.log() untuk debug.

Tag HTML <h1> digunakan untuk heading utama.

⚠️ Perhatian: Elemen <code> tidak menjaga spasi ekstra dan baris baru. Untuk menampilkan blok kode multi-baris, bungkus <code> di dalam <pre>.

2. ⌨️ Elemen <kbd>

Elemen <kbd> (keyboard) mendefinisikan input yang diberikan oleh pengguna — biasanya input dari keyboard, tetapi bisa juga perintah suara atau input lainnya. Isi elemen ini biasanya ditampilkan dengan font monospace oleh browser.

<!-- Menampilkan kombinasi tombol keyboard --> <p>Tekan <kbd>Ctrl</kbd> + <kbd>C</kbd> untuk menyalin teks.</p> <p>Tekan <kbd>Ctrl</kbd> + <kbd>V</kbd> untuk menempel teks.</p> <p>Tekan <kbd>Alt</kbd> + <kbd>F4</kbd> untuk menutup jendela.</p> <p>Gunakan <kbd>Tab</kbd> untuk berpindah antar form field.</p>

🟢 Hasil Tampilan:

Tekan Ctrl + C untuk menyalin teks.

Tekan Ctrl + V untuk menempel teks.

Tekan Alt + F4 untuk menutup jendela.

Gunakan Tab untuk berpindah antar form field.

Styling <kbd> dengan CSS

/* Membuat tampilan tombol keyboard yang realistis */ kbd { background-color: #eee; border: 1px solid #b4b4b4; border-radius: 4px; box-shadow: 0 1px 1px rgba(0,0,0,.2), 0 2px 0 0 rgba(255,255,255,.7) inset; color: #333; display: inline-block; font-size: 0.85em; font-weight: 700; line-height: 1; padding: 2px 6px; white-space: nowrap; }

3. 🖥️ Elemen <samp>

Elemen <samp> (sample) mendefinisikan contoh output atau keluaran dari sebuah program komputer, skrip, atau sistem. Biasanya ditampilkan dengan font monospace.

<!-- Menampilkan output program --> <p>Setelah menjalankan program, output yang muncul adalah:</p> <samp> Hello, World! Program selesai dengan kode 0. </samp> <p>Pesan error yang muncul: <samp>Error: File not found.</samp></p> <p>Hasil kalkulasi: <samp>5 + 3 = 8</samp></p>

🟢 Hasil Tampilan:

Setelah menjalankan program, output yang muncul adalah:

Hello, World!
Program selesai dengan kode 0.

Pesan error yang muncul: Error: File not found.

Hasil kalkulasi: 5 + 3 = 8

4. 🔢 Elemen <var>

Elemen <var> digunakan untuk mendefinisikan sebuah variabel — baik dalam konteks pemrograman maupun dalam persamaan matematika. Browser biasanya menampilkannya dengan huruf miring (italic).

<!-- Variabel matematika --> <p>Luas lingkaran = π × <var>r</var><sup>2</sup></p> <p>Persamaan linear: <var>y</var> = <var>m</var><var>x</var> + <var>b</var></p> <!-- Variabel dalam konteks pemrograman --> <p>Deklarasi: <code>let <var>nama</var> = "Budi";</code></p> <p>Nilai <var>x</var> + <var>y</var> adalah: <samp>15</samp></p>

🟢 Hasil Tampilan:

Luas lingkaran = π × r2

Persamaan linear: y = mx + b

Deklarasi: let nama = "Budi";

Nilai x + y adalah: 15

5. 📄 Elemen <pre>

Elemen <pre> (preformatted text) mendefinisikan teks yang sudah diformat sebelumnya. Teks di dalam <pre> ditampilkan dengan font monospace dan menjaga semua spasi, tab, dan baris baru persis seperti yang ditulis dalam kode HTML. Sangat berguna untuk menampilkan blok kode program.

<pre> <code> def sapa(nama): print(f"Halo, {nama}!") sapa("Dunia") # Output: Halo, Dunia! </code> </pre>

🟢 Hasil Tampilan:

def sapa(nama):
    print(f"Halo, {nama}!")

sapa("Dunia")
# Output: Halo, Dunia!

Contoh Kode JavaScript dengan <pre><code>

<pre> <code> // Program menghitung faktorial function faktorial(n) { if (n === 0 || n === 1) return 1; return n * faktorial(n - 1); } console.log(faktorial(5)); // Output: 120 </code> </pre>

🟢 Hasil Tampilan:

// Program menghitung faktorial
function faktorial(n) {
    if (n === 0 || n === 1) return 1;
    return n * faktorial(n - 1);
}

console.log(faktorial(5)); // Output: 120

Perbedaan <pre> vs Teks Biasa

<!-- Tanpa <pre>: spasi diabaikan --> <p> Teks dengan spasi banyak </p> <!-- Tampilan: "Teks dengan spasi banyak" (spasi dikompres) --> <!-- Dengan <pre>: spasi dipertahankan --> <pre> Teks dengan spasi banyak </pre> <!-- Tampilan: Teks dengan spasi banyak -->

🔗 Kombinasi Elemen dalam Dokumentasi Teknis

Dalam penulisan dokumentasi teknis, seringkali semua elemen ini digunakan bersama:

<p> Untuk menjalankan program, buka terminal dan ketik perintah <kbd>python</kbd> <kbd>app.py</kbd>. </p> <p> Fungsi <code>hitung_luas(<var>panjang</var>, <var>lebar</var>)</code> mengembalikan nilai luas persegi panjang. </p> <pre><code> def hitung_luas(panjang, lebar): return panjang * lebar </code></pre> <p>Output yang diharapkan: <samp>Luas = 50</samp></p>

🟢 Hasil Tampilan:

Untuk menjalankan program, buka terminal dan ketik perintah python app.py.

Fungsi hitung_luas(panjang, lebar) mengembalikan nilai luas persegi panjang. 

def hitung_luas(panjang, lebar):
    return panjang * lebar

Output yang diharapkan: Luas = 50

🎨 Styling Elemen Computer Code dengan CSS

/* Styling elemen <code> inline */ code { background-color: #f4f4f4; padding: 2px 6px; border-radius: 3px; font-family: 'Courier New', monospace; color: #c7254e; font-size: 0.9em; } /* Styling blok kode <pre> */ pre { background: #282c34; color: #abb2bf; padding: 20px; border-radius: 6px; overflow-x: auto; font-family: 'Courier New', monospace; line-height: 1.6; font-size: 0.95em; } /* Styling <kbd> seperti tombol keyboard */ kbd { background-color: #eee; border: 1px solid #b4b4b4; border-radius: 3px; box-shadow: 0 1px 1px rgba(0,0,0,0.2); color: #333; padding: 1px 6px; font-size: 0.85em; } /* Styling <samp> */ samp { font-family: 'Courier New', monospace; background: #f5f5f5; padding: 2px 6px; color: #666; } /* Styling <var> */ var { font-style: italic; color: #0066cc; font-family: 'Times New Roman', serif; }
✅ Kapan Menggunakan Elemen Mana:
  • <code> — Untuk nama fungsi, variabel, perintah dalam teks biasa
  • <pre><code> — Untuk blok kode multi-baris
  • <kbd> — Untuk tombol keyboard atau kombinasi shortcut
  • <samp> — Untuk menampilkan output/hasil program
  • <var> — Untuk nama variabel atau simbol matematika
