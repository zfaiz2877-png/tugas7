HTML Block dan Inline Elements

Setiap elemen HTML memiliki nilai tampilan (display value) bawaan. Dua nilai tampilan yang paling umum adalah block dan inline. Memahami perbedaan keduanya sangat penting untuk menguasai tata letak halaman web.

1. Perbandingan Block vs Inline

📦 Block Elements

  • Selalu dimulai di baris baru
  • Mengambil seluruh lebar yang tersedia
  • Memiliki margin atas dan bawah
  • Dapat berisi block maupun inline element
  • Dapat diatur width & height

📝 Inline Elements

  • Tidak dimulai di baris baru
  • Hanya mengambil lebar sesuai kontennya
  • Tidak memiliki margin atas/bawah
  • Sebaiknya hanya berisi inline elements
  • Width & height tidak berpengaruh

2. Block-Level Elements

Elemen block selalu dimulai di baris baru dan mengambil lebar penuh dari elemen induknya (parent). Bayangkan setiap blok seperti kotak yang memanjang dari kiri ke kanan.

<div>Ini adalah div (block)</div> <p>Ini adalah paragraf (block)</p> <h1>Ini adalah heading (block)</h1>
Visualisasi — setiap elemen block mengisi lebar penuh:
<div> — Div Element (mengisi lebar penuh)
<p> — Paragraf (baris baru, lebar penuh)
<h1> — Heading 1 (baris baru, lebar penuh)
<ul> — Unordered List (baris baru, lebar penuh)

Daftar Elemen Block yang Umum

Elemen-elemen berikut adalah block-level elements:

<div> <p> <h1> <h2> <h3> <h4> <h5> <h6> <ul> <ol> <li> <table> <form> <header> <footer> <main> <section> <article> <aside> <nav> <blockquote> <pre> <hr> <br> <fieldset> <figure> <figcaption> <address> <dd> <dt> <dl>

Contoh penggunaan block element:

<!-- Semua elemen ini dimulai di baris baru --> <h1>Judul Utama (H1)</h1> <h2>Sub Judul (H2)</h2> <p>Ini adalah sebuah paragraf. Paragraf selalu dimulai di baris baru dan ada jarak (margin) antara paragraf satu dengan lainnya.</p> <div>Ini adalah div, wadah generik block-level.</div> <ul> <li>Item daftar</li> </ul>
Hasil:

Judul Utama (H1)

Sub Judul (H2)

Ini adalah sebuah paragraf. Paragraf selalu dimulai di baris baru dan ada jarak (margin) antara paragraf satu dengan lainnya.

Ini adalah div, wadah generik block-level.
  • Item daftar

3. Inline Elements

Elemen inline tidak memulai baris baru. Elemen ini hanya mengambil lebar sebesar konten yang ada di dalamnya. Beberapa elemen inline bisa berada dalam satu baris yang sama.

<p> Teks biasa, lalu <span>ini span</span>, lalu <a href="#">ini link</a>, lalu <strong>teks tebal</strong>, lalu <em>teks miring</em> — semua dalam satu baris! </p>
Hasil:

Teks biasa, lalu ini span, lalu ini link, lalu teks tebal, lalu teks miring — semua dalam satu baris!

Visualisasi elemen inline dalam satu baris:
Teks biasa <span> teks biasa <a> teks <strong> biasa <em> terus mengalir...

Daftar Elemen Inline yang Umum

<span> <a> <img> <strong> <b> <em> <i> <u> <small> <big> <sub> <sup> <code> <kbd> <label> <input> <button> <select> <textarea> <abbr> <cite> <q> <time> <mark> <bdo>

Contoh penggunaan inline element:

<p> Harga produk ini adalah <strong>Rp 150.000</strong> dan tersedia dalam warna <span style="color: red;">merah</span> dan <span style="color: blue;">biru</span>. Kunjungi <a href="produk.html">halaman produk</a> untuk informasi lebih lanjut. </p> <p> Rumus air adalah H<sub>2</sub>O dan E = mc<sup>2</sup>. Istilah HTML merupakan <abbr title="HyperText Markup Language">HTML</abbr>. </p>
Hasil:

Harga produk ini adalah Rp 150.000 dan tersedia dalam warna merah dan biru. Kunjungi halaman produk untuk informasi lebih lanjut.

Rumus air adalah H2O dan E = mc2. Istilah HTML merupakan HTML.

4. Elemen <div> — Block Container Generik

Tag <div> adalah elemen block yang paling sering digunakan sebagai wadah (container) untuk mengelompokkan elemen-elemen HTML lainnya. Secara bawaan, <div> tidak memiliki gaya khusus.

<!-- div sebagai wadah dengan styling --> <div style="background: #f0f0f0; padding: 20px; border-radius: 8px; margin: 10px 0;"> <h3>Kartu Produk</h3> <p>Deskripsi produk ada di sini.</p> <a href="produk.html">Lihat Detail</a> </div> <!-- Membuat layout dengan div --> <div style="display: flex; gap: 15px;"> <div style="flex: 1; background: #e8f5e9; padding: 15px;">Kolom Kiri</div> <div style="flex: 1; background: #f3e5f5; padding: 15px;">Kolom Kanan</div> </div>

Kartu Produk

Deskripsi produk ada di sini.

Lihat Detail
Kolom Kiri
Kolom Kanan

5. Elemen <span> — Inline Container Generik

Tag <span> adalah elemen inline yang digunakan sebagai wadah generik untuk mengelompokkan atau memberi style pada teks atau elemen inline lainnya.

<p> Saya <span style="color: #04AA6D; font-weight: bold;">suka</span> belajar HTML. Ini sangat <span style="background: yellow; padding: 0 3px;">menarik</span> dan bermanfaat. </p> <!-- Memberi ID atau class pada bagian teks tertentu --> <p>Status: <span class="status-aktif" id="status">Aktif</span></p>

Saya suka belajar HTML. Ini sangat menarik dan bermanfaat.

Status: Aktif

6. Mengubah Display dengan CSS

Anda dapat mengubah perilaku default elemen menggunakan properti CSS display:

<style> /* Mengubah elemen inline menjadi block */ span.jadi-block { display: block; } /* Mengubah elemen block menjadi inline */ div.jadi-inline { display: inline; } /* Inline-block: kombinasi keduanya */ span.inline-block { display: inline-block; width: 100px; height: 80px; background: #04AA6D; color: white; text-align: center; line-height: 80px; margin: 5px; } </style>
