HTML Plug-ins (<object> dan <embed>)

Apa itu Plug-ins?

Plug-ins adalah program komputer yang memperluas fungsionalitas standar browser (misalnya memutar audio, video, menampilkan dokumen PDF, atau menjalankan applet).

1. Elemen <object>

Elemen <object> didukung oleh semua browser dan digunakan untuk menyematkan objek multimedia seperti audio, video, Java applet, PDF, dan Flash ke dalam halaman web.

Menyematkan Gambar atau Dokumen HTML

<object data="snippet.html" width="400" height="200"></object>

Menyematkan Dokumen PDF

<object data="document.pdf" type="application/pdf" width="100%" height="500px"> <p>Browser Anda tidak mendukung preview PDF. <a href="document.pdf">Unduh PDF di sini</a>.</p> </object>

2. Elemen <embed>

Elemen <embed> mendefinisikan wadah (container) untuk sumber daya eksternal (aplikasi eksternal atau konten interaktif).

<embed src="audioclip.mp3" width="300" height="50"> <embed src="animation.swf" width="400" height="300">
Catatan Modern: Sebagian besar browser modern tidak lagi mendukung plugin lawas seperti Adobe Flash atau Java Applet demi keamanan dan performa. Gunakan elemen HTML5 standar (<video>, <audio>, <canvas>, <svg>) jika memungkinkan.
