🎵 HTML Audio

Elemen <audio> diperkenalkan dalam HTML5 untuk menyematkan konten audio langsung ke dalam halaman web. Sebelum HTML5, pemutaran audio di web bergantung pada plugin seperti Adobe Flash atau Real Player yang sudah tidak didukung lagi.

ℹ️ Informasi: Elemen <audio> sangat mirip dengan elemen <video> dalam hal atribut dan penggunaannya. Perbedaan utamanya adalah <audio> tidak memiliki atribut width, height, dan poster karena audio tidak memiliki konten visual.

1. Elemen <audio> Dasar

Sintaks paling sederhana dari elemen <audio> menggunakan atribut src dan controls:

<audio src="lagu.mp3" controls> Browser Anda tidak mendukung elemen audio. </audio>

🎵 [Di sini akan muncul pemutar audio dengan kontrol play/pause/volume/progress bar]
(Kontrol muncul jika atribut "controls" ditambahkan)

⚠️ Fallback Text: Teks di antara tag <audio> dan </audio> hanya ditampilkan jika browser tidak mendukung elemen <audio>. Selalu sertakan teks fallback yang informatif.

2. Atribut src

Atribut src menentukan URL atau path ke file audio yang ingin diputar.

<!-- Path relatif --> <audio src="audio/lagu.mp3" controls></audio> <!-- Path absolut --> <audio src="/assets/audio/lagu.mp3" controls></audio> <!-- URL eksternal --> <audio src="https://www.example.com/audio/lagu.mp3" controls></audio>

3. Atribut controls

Atribut controls menambahkan antarmuka kontrol pemutar audio bawaan browser, yang biasanya mencakup tombol play/pause, progress bar, pengatur volume, dan tombol bisu (mute).

<!-- Tanpa controls (tersembunyi, tidak bisa dikontrol manual) --> <audio src="lagu.mp3"></audio> <!-- Dengan controls (tampilan kontrol pemutar) --> <audio src="lagu.mp3" controls></audio>
💡 Tips: Hampir selalu gunakan controls pada elemen audio agar pengguna dapat mengontrol pemutaran. Tanpa controls, audio tidak terlihat dan tidak bisa dikontrol kecuali menggunakan JavaScript.

4. Atribut autoplay

Atribut autoplay membuat audio mulai diputar secara otomatis ketika halaman selesai dimuat.

<audio src="lagu.mp3" autoplay controls> Browser Anda tidak mendukung elemen audio. </audio>
⚠️ Peringatan: Sebagian besar browser modern memblokir autoplay audio yang memiliki suara karena dianggap mengganggu pengguna. Kebijakan ini disebut Autoplay Policy. Audio dengan autoplay hanya berjalan jika:
  • Pengguna sebelumnya telah berinteraksi dengan halaman tersebut
  • Audio diatur ke muted
  • Browser memberikan izin khusus untuk situs tersebut
<!-- Solusi: gunakan muted untuk mendukung autoplay --> <audio src="lagu.mp3" autoplay muted controls> Browser Anda tidak mendukung elemen audio. </audio>

5. Atribut loop

Atribut loop membuat audio diputar ulang secara terus-menerus setelah mencapai akhir. Sangat berguna untuk musik latar (background music) pada halaman web.

<audio src="lagu.mp3" controls loop> Browser Anda tidak mendukung elemen audio. </audio> <!-- Kombinasi untuk musik latar: autoplay + muted + loop --> <audio src="ambient.mp3" autoplay muted loop> Browser Anda tidak mendukung elemen audio. </audio>

6. Atribut muted

Atribut muted membisukan audio secara default saat pertama kali dimuat/diputar. Pengguna dapat mengaktifkan suara kembali melalui kontrol pemutar.

<audio src="lagu.mp3" controls muted> Browser Anda tidak mendukung elemen audio. </audio>

7. Atribut preload

Atribut preload memberi petunjuk kepada browser tentang bagaimana file audio harus diunduh saat halaman dimuat.

Nilai Deskripsi Gunakan Ketika
none Browser tidak mengunduh audio sebelum pengguna menekan play Audio jarang diputar / hemat bandwidth
metadata Browser hanya mengunduh metadata (durasi, dll.) — default Sebagian besar kasus umum
auto Browser mengunduh seluruh file audio saat halaman dimuat Audio pasti akan diputar segera
<audio src="lagu.mp3" controls preload="metadata"> Browser Anda tidak mendukung elemen audio. </audio>

8. Elemen <source> – Multiple Format

Sama seperti pada video, elemen <source> digunakan di dalam <audio> untuk menyediakan beberapa format audio. Browser akan memilih format pertama yang didukungnya.

Format Audio yang Didukung HTML5

Format Ekstensi MIME Type Keterangan
MP3 .mp3 audio/mpeg Format paling populer, didukung semua browser modern. Lossy compression.
WAV .wav audio/wav Format lossless berkualitas tinggi. Ukuran file besar. Didukung Chrome, Firefox, Safari, Edge.
OGG .ogg audio/ogg Format open-source gratis. Didukung Chrome, Firefox, Opera. Tidak didukung Safari.
AAC .aac audio/aac Format Apple. Didukung Safari, Chrome, Edge. Kualitas lebih baik dari MP3.
WebM .webm audio/webm Format Google. Didukung Chrome, Firefox, Opera.
FLAC .flac audio/flac Format lossless open-source. Didukung Chrome, Firefox, Safari (terbaru).

Contoh Penggunaan <source>

<audio controls> <source src="lagu.mp3" type="audio/mpeg"> <source src="lagu.wav" type="audio/wav"> <source src="lagu.ogg" type="audio/ogg"> Browser Anda tidak mendukung elemen audio. </audio>
ℹ️ Cara Kerja: Browser membaca elemen <source> dari atas ke bawah dan memilih format pertama yang didukungnya. Jika tidak ada format yang didukung, browser akan menampilkan teks fallback. Letakkan format yang paling kompatibel (MP3) di posisi pertama.

9. Atribut type pada <source>

Selalu sertakan atribut type pada setiap <source> untuk membantu browser menentukan format tanpa harus mengunduh file terlebih dahulu:

<!-- Dengan type (direkomendasikan) --> <audio controls> <source src="lagu.mp3" type="audio/mpeg"> <source src="lagu.ogg" type="audio/ogg"> Browser Anda tidak mendukung elemen audio. </audio> <!-- Tanpa type (tidak direkomendasikan) --> <audio controls> <source src="lagu.mp3"> <source src="lagu.ogg"> Browser Anda tidak mendukung elemen audio. </audio>

10. Teks Fallback (Cadangan)

Teks fallback ditempatkan di antara tag pembuka dan penutup <audio>. Konten ini hanya muncul jika browser tidak mendukung elemen <audio> HTML5.

<!-- Fallback sederhana --> <audio src="lagu.mp3" controls> Browser Anda tidak mendukung pemutaran audio HTML5. </audio> <!-- Fallback dengan tautan unduhan --> <audio controls> <source src="lagu.mp3" type="audio/mpeg"> <source src="lagu.ogg" type="audio/ogg"> <p> Maaf, browser Anda tidak mendukung audio HTML5. Silakan <a href="lagu.mp3">unduh file audio</a> untuk mendengarkannya. </p> </audio>

11. Perbandingan: <audio> vs <video>

🎵 <audio>

  • Untuk file audio/suara
  • Tidak ada area visual
  • Tidak ada atribut width/height
  • Tidak ada atribut poster
  • Format: MP3, WAV, OGG, AAC
  • Ukuran file umumnya lebih kecil

🎬 <video>

  • Untuk file video/gambar bergerak
  • Memiliki area tampilan visual
  • Ada atribut width/height
  • Ada atribut poster (thumbnail)
  • Format: MP4, WebM, OGG
  • Ukuran file umumnya lebih besar

Kedua elemen berbagi atribut yang sama: controls, autoplay, loop, muted, preload, dan mendukung elemen <source>.

12. Contoh Lengkap

Berikut adalah contoh halaman HTML dengan pemutar audio yang lengkap dan profesional:

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Halaman Audio</title> <style> .audio-player { background: #f1f1f1; padding: 20px; border-radius: 8px; text-align: center; max-width: 400px; margin: 20px auto; } </style> </head> <body> <h2>Pemutar Musik</h2> <div class="audio-player"> <h3>🎵 Judul Lagu</h3> <p>Nama Artis</p> <audio controls preload="metadata"> <source src="lagu.mp3" type="audio/mpeg"> <source src="lagu.wav" type="audio/wav"> <source src="lagu.ogg" type="audio/ogg"> <p>Browser Anda tidak mendukung audio HTML5. <a href="lagu.mp3">Unduh lagu</a></p> </audio> </div> </body> </html>

13. Ringkasan Semua Atribut

Atribut Tipe Deskripsi
src URL Menentukan URL sumber file audio
controls Boolean Menampilkan kontrol pemutar bawaan browser
autoplay Boolean Audio diputar otomatis saat halaman dimuat
loop Boolean Audio diulang dari awal setelah selesai
muted Boolean Membisukan audio secara default
preload none/metadata/auto Cara browser memuat audio saat halaman dibuka

15. Tips & Praktik Terbaik

Situasi Rekomendasi
Pemutar audio umum Gunakan <audio controls> dengan beberapa <source>
Musik latar halaman Gunakan autoplay muted loop
Efek suara / notifikasi Gunakan JavaScript Audio() API daripada elemen <audio>
Podcast / audio panjang Gunakan preload="metadata" untuk menghemat bandwidth
Kompatibilitas maksimal Sediakan format MP3 (utama), OGG (alternatif), WAV (fallback)
Aksesibilitas Selalu sertakan teks fallback dan pertimbangkan menyediakan transkrip
📌 Ringkasan Penting:
• Gunakan <audio src="..." controls> untuk pemutar audio dasar
• Gunakan <source> dengan type untuk mendukung berbagai format
• MP3 adalah format paling kompatibel — letakkan di posisi pertama
• Tambahkan muted jika ingin autoplay bekerja di browser modern
• Selalu sertakan teks fallback yang informatif
• Gunakan preload="metadata" sebagai keseimbangan antara UX dan bandwidth
