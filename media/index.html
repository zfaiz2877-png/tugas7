📽️ HTML Media

HTML menyediakan elemen-elemen khusus untuk menyematkan konten multimedia langsung ke dalam halaman web. Dengan HTML5, kita dapat menampilkan video dan memutar audio tanpa memerlukan plugin pihak ketiga seperti Flash. Pelajari semua tentang multimedia HTML di bagian ini.

💡 Tips: HTML5 memperkenalkan elemen <video> dan <audio> yang memungkinkan penambahan media langsung ke halaman web dengan mudah dan standar.

📋 Ringkasan Elemen Media HTML

Elemen Deskripsi
<video> Menyematkan konten video ke dalam halaman HTML
<audio> Menyematkan konten audio ke dalam halaman HTML
<source> Mendefinisikan sumber media untuk elemen <video> atau <audio>
<track> Mendefinisikan teks track untuk elemen <video> (subtitle, caption, dll.)
<embed> Mendefinisikan wadah untuk konten eksternal (plug-in)
<object> Mendefinisikan objek tertanam (embedded object)

🌐 Format Media yang Didukung

Jenis Format MIME Type Keterangan
Video MP4 video/mp4 Didukung semua browser modern
Video WebM video/webm Format open-source Google
Video OGG video/ogg Format open-source, Firefox/Chrome
Audio MP3 audio/mpeg Didukung semua browser modern
Audio WAV audio/wav Format lossless, kualitas tinggi
Audio OGG audio/ogg Format open-source, Firefox/Chrome
📌 Catatan: Selalu sediakan beberapa format file sebagai alternatif agar media dapat diputar di semua browser. Gunakan elemen <source> di dalam <video> atau <audio> untuk tujuan ini.
