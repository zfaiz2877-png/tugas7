🎬 HTML Video

Elemen <video> diperkenalkan dalam HTML5 untuk memudahkan penyematan konten video langsung ke dalam halaman web tanpa memerlukan plugin eksternal. Sebelum HTML5, video harus diputar menggunakan teknologi seperti Adobe Flash yang tidak lagi didukung browser modern.

ℹ️ Sejarah Singkat: Sebelum HTML5, tidak ada standar baku untuk menampilkan video di web. Video memerlukan plugin seperti Flash, Silverlight, atau RealPlayer. HTML5 mengubah segalanya dengan memperkenalkan elemen <video> yang didukung oleh semua browser modern.

1. Elemen <video> Dasar

Sintaks paling sederhana dari elemen <video> adalah dengan menggunakan atribut src untuk menentukan sumber video dan controls untuk menampilkan kontrol pemutar.

<video src="film.mp4" controls> Browser Anda tidak mendukung elemen video. </video>

🎬 [Di sini akan muncul pemutar video dengan kontrol play/pause/volume/fullscreen]
(Kontrol muncul jika atribut "controls" ditambahkan)

⚠️ Fallback Text: Teks di antara tag <video> dan </video> hanya akan ditampilkan jika browser tidak mendukung elemen <video>. Ini disebut fallback content dan penting untuk aksesibilitas.

2. Atribut src

Atribut src menentukan URL atau path ke file video yang ingin ditampilkan. Bisa berupa path relatif, path absolut, atau URL lengkap.

<!-- Path relatif --> <video src="video/film.mp4" controls></video> <!-- Path absolut --> <video src="/assets/video/film.mp4" controls></video> <!-- URL eksternal --> <video src="https://www.example.com/video/film.mp4" controls></video>

3. Atribut controls

Atribut controls menambahkan kontrol pemutar bawaan browser ke video, termasuk tombol play/pause, pengatur volume, progress bar, dan tombol fullscreen. Atribut ini bersifat boolean (cukup ditulis tanpa nilai).

<!-- Tanpa controls (tidak ada kontrol) --> <video src="film.mp4"></video> <!-- Dengan controls (ada kontrol pemutar) --> <video src="film.mp4" controls></video>
💡 Tips: Selalu gunakan atribut controls kecuali Anda membuat kontrol video kustom sendiri menggunakan JavaScript. Tanpa kontrol, pengguna tidak bisa menghentikan atau mengatur volume video.

4. Atribut width dan height

Atribut width dan height menentukan dimensi area pemutar video dalam piksel. Disarankan untuk selalu menentukan dimensi agar halaman tidak melompat saat video dimuat.

<video src="film.mp4" controls width="640" height="360"> Browser Anda tidak mendukung elemen video. </video>
📐 Rasio Aspek: Video umumnya memiliki rasio aspek 16:9 (widescreen). Contoh ukuran umum: 1280×720 (HD), 1920×1080 (Full HD), 640×360 (SD). Jika hanya satu dimensi yang diatur, browser akan menjaga rasio aspek secara otomatis.

5. Atribut autoplay

Atribut autoplay membuat video mulai diputar secara otomatis saat halaman dimuat. Namun, sebagian besar browser modern memblokir autoplay dengan suara karena alasan pengalaman pengguna (UX).

<video src="film.mp4" autoplay controls> Browser Anda tidak mendukung elemen video. </video>
⚠️ Penting: Banyak browser modern (Chrome, Firefox, Safari) memblokir autoplay jika video memiliki suara. Untuk mengatasi ini, gunakan kombinasi autoplay dan muted. Video yang dibisukan (muted) biasanya diizinkan untuk autoplay.
<!-- Solusi autoplay yang direkomendasikan --> <video src="film.mp4" autoplay muted controls> Browser Anda tidak mendukung elemen video. </video>

6. Atribut loop

Atribut loop membuat video diputar ulang secara terus-menerus dari awal setelah mencapai akhir. Berguna untuk video latar belakang atau animasi.

<video src="film.mp4" controls loop> Browser Anda tidak mendukung elemen video. </video> <!-- Kombinasi: autoplay + muted + loop untuk video background --> <video src="background.mp4" autoplay muted loop> Browser Anda tidak mendukung elemen video. </video>

7. Atribut muted

Atribut muted membisukan suara video secara default. Video tetap diputar tetapi tanpa audio. Pengguna dapat mengaktifkan suara kembali melalui kontrol pemutar.

<video src="film.mp4" controls muted> Browser Anda tidak mendukung elemen video. </video>

8. Atribut poster

Atribut poster menentukan gambar yang akan ditampilkan sebelum video diputar atau selama video sedang diunduh. Jika tidak ditentukan, browser akan menggunakan frame pertama video sebagai poster.

<video src="film.mp4" controls poster="thumbnail.jpg" width="640" height="360"> Browser Anda tidak mendukung elemen video. </video>

9. Atribut preload

Atribut preload memberi petunjuk kepada browser tentang bagaimana video harus dimuat saat halaman dibuka.

Nilai Deskripsi
none Browser tidak akan memuat video sama sekali sebelum pengguna menekan play
metadata Browser hanya memuat metadata video (durasi, dimensi, dll.) — default
auto Browser dapat memuat seluruh video saat halaman dimuat
<video src="film.mp4" controls preload="metadata"> Browser Anda tidak mendukung elemen video. </video>

10. Elemen <source> – Multiple Format

Elemen <source> digunakan di dalam <video> untuk menyediakan beberapa format video sebagai alternatif. Browser akan memilih format pertama yang didukungnya dan mengabaikan sisanya.

Mengapa ini penting? Karena tidak semua browser mendukung format video yang sama:

Format Ekstensi MIME Type Dukungan Browser
MP4 (H.264) .mp4 video/mp4 Chrome, Firefox, Safari, Edge, Opera
WebM (VP8/VP9) .webm video/webm Chrome, Firefox, Edge, Opera
OGG (Theora) .ogg / .ogv video/ogg Chrome, Firefox, Opera
<video controls width="640" height="360"> <source src="film.mp4" type="video/mp4"> <source src="film.webm" type="video/webm"> <source src="film.ogg" type="video/ogg"> Browser Anda tidak mendukung elemen video. </video>
ℹ️ Cara Kerja: Browser membaca elemen <source> dari atas ke bawah. Ia akan memilih format pertama yang bisa diputar. Karena MP4 paling banyak didukung, letakkan MP4 di posisi pertama.

11. Atribut type pada <source>

Atribut type pada elemen <source> memberitahu browser tentang format MIME dari file media, sehingga browser tidak perlu mengunduh file untuk mengetahui apakah format tersebut didukung atau tidak.

<source src="film.mp4" type="video/mp4"> <source src="film.webm" type="video/webm"> <source src="film.ogg" type="video/ogg">
💡 Tips Performa: Selalu sertakan atribut type pada setiap elemen <source>. Ini membantu browser menentukan dengan cepat format mana yang didukung tanpa perlu mengunduh file terlebih dahulu.

12. Teks Fallback (Cadangan)

Teks atau konten yang diletakkan di antara tag <video> dan </video> disebut fallback content. Konten ini hanya ditampilkan jika browser tidak mendukung elemen video HTML5.

<video src="film.mp4" controls> <!-- Fallback text sederhana --> Browser Anda tidak mendukung pemutaran video HTML5. Silakan <a href="film.mp4">unduh video</a> untuk menontonnya. </video>
<!-- Fallback dengan pesan lebih informatif --> <video controls width="640" height="360"> <source src="film.mp4" type="video/mp4"> <source src="film.webm" type="video/webm"> <p> Maaf, browser Anda tidak mendukung video HTML5. Anda dapat <a href="film.mp4">mengunduh video di sini</a>. </p> </video>

13. Contoh Lengkap

Berikut adalah contoh penggunaan elemen <video> secara lengkap dan profesional:

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Halaman Video</title> </head> <body> <h2>Video Tutorial HTML</h2> <video controls width="640" height="360" poster="thumbnail.jpg" preload="metadata"> <source src="tutorial.mp4" type="video/mp4"> <source src="tutorial.webm" type="video/webm"> <source src="tutorial.ogg" type="video/ogg"> <p>Browser Anda tidak mendukung video HTML5. <a href="tutorial.mp4">Unduh video</a></p> </video> </body> </html>

14. Ringkasan Semua Atribut

Atribut Tipe Deskripsi
src URL Menentukan URL sumber file video
controls Boolean Menampilkan kontrol pemutar bawaan browser
autoplay Boolean Video diputar otomatis saat halaman dimuat
loop Boolean Video diulang dari awal setelah selesai
muted Boolean Membisukan audio video secara default
width Pixels Menentukan lebar pemutar video
height Pixels Menentukan tinggi pemutar video
poster URL Gambar yang ditampilkan sebelum video diputar
preload none/metadata/auto Cara browser memuat video saat halaman dibuka
