HTML Id (Atribut id)

Atribut id digunakan untuk memberikan identitas unik pada sebuah elemen HTML. Nilainya harus unik di seluruh halaman — tidak boleh ada dua elemen yang memiliki nilai id yang sama. Atribut id digunakan oleh CSS (untuk styling) maupun JavaScript (untuk manipulasi DOM).

📌 Catatan: Nilai id bersifat case-sensitive (peka huruf besar-kecil). Artinya, id="myHeader" dan id="myheader" dianggap sebagai dua id yang berbeda. Selain itu, setiap id harus unik dalam satu halaman HTML.

1. Sintaks Dasar Atribut id

Untuk memberikan id pada elemen, tambahkan atribut id="namaId" di dalam tag pembuka. Di CSS, id ditarget menggunakan tanda pagar (#) diikuti nama id-nya.

<!-- HTML: memberikan id pada elemen --> <h1 id="judul-utama">Ini Judul Utama</h1> <p id="paragraf-intro">Ini paragraf intro.</p> /* CSS: menarget id dengan tanda pagar (#) */ #judul-utama { color: #04AA6D; font-size: 36px; } #paragraf-intro { font-size: 18px; color: #555; }

2. Aturan Keunikan id

Berbeda dengan atribut class, nilai id harus benar-benar unik dalam satu dokumen HTML. Tidak boleh ada dua elemen dengan id yang sama.

<!-- BENAR: setiap elemen memiliki id yang berbeda --> <div id="header">Bagian Header</div> <div id="konten">Bagian Konten</div> <div id="footer">Bagian Footer</div> <!-- SALAH: dua elemen memiliki id yang sama --> <div id="header">Header Pertama</div> <div id="header">Header Kedua</div> <!-- ❌ SALAH! -->
⚠️ Peringatan: Menggunakan id yang sama pada lebih dari satu elemen adalah pelanggaran standar HTML dan dapat menyebabkan perilaku yang tidak terduga, terutama saat menggunakan JavaScript (getElementById hanya akan mengembalikan elemen pertama). Jika Anda butuh menarget banyak elemen, gunakan atribut class.

3. Menggunakan id di CSS

Untuk menarget elemen dengan id tertentu di CSS, gunakan tanda pagar (#) diikuti nama id. Selector id memiliki spesifisitas yang lebih tinggi daripada selector kelas.

<!DOCTYPE html> <html> <head> <style> #header { background-color: #04AA6D; color: white; padding: 20px; text-align: center; } #sidebar { background-color: #f4f4f4; float: left; width: 200px; padding: 15px; min-height: 200px; } #main { margin-left: 230px; padding: 15px; } #footer { background-color: #333; color: white; padding: 15px; text-align: center; clear: both; } </style> </head> <body> <div id="header"> <h1>Website Saya</h1> </div> <div id="sidebar"> <h3>Menu</h3> <ul> <li>Beranda</li> <li>Tentang</li> <li>Kontak</li> </ul> </div> <div id="main"> <h2>Selamat Datang</h2> <p>Ini adalah konten utama halaman.</p> </div> <div id="footer"> <p>© 2024 Website Saya</p> </div> </body> </html>

4. Menggunakan id di JavaScript

Salah satu kegunaan terpenting dari id adalah dalam JavaScript. Metode document.getElementById("namaId") memungkinkan kita mengakses dan memanipulasi elemen secara langsung berdasarkan id-nya.

<!DOCTYPE html> <html> <body> <h1 id="judul-halaman">Judul Awal</h1> <p id="teks-demo">Paragraf ini bisa diubah.</p> <button onclick="ubahKonten()">Ubah Konten</button> <button onclick="ubahWarna()">Ubah Warna</button> <button onclick="sembunyikan()">Sembunyikan</button> <script> function ubahKonten() { document.getElementById("judul-halaman").innerHTML = "Judul Telah Diubah!"; document.getElementById("teks-demo").innerHTML = "Teks ini sudah berubah menggunakan JavaScript!"; } function ubahWarna() { document.getElementById("judul-halaman").style.color = "#e74c3c"; document.getElementById("teks-demo").style.backgroundColor = "#ffffcc"; } function sembunyikan() { document.getElementById("teks-demo").style.display = "none"; } </script> </body> </html>

5. Menggunakan id sebagai Bookmark (Jangkar)

Atribut id dapat digunakan untuk membuat bookmark (jangkar) di dalam halaman HTML. Ini sangat berguna untuk halaman yang panjang, memungkinkan pengguna melompat langsung ke bagian tertentu.

Cara Membuat Bookmark

Ada dua langkah untuk membuat dan menggunakan bookmark:

  1. Buat target bookmark dengan memberikan id pada elemen tujuan.
  2. Buat link yang mengarah ke id tersebut menggunakan sintaks href="#namaId".
<!-- Langkah 1: Buat target dengan id --> <h2 id="bab1">Bab 1: Pengenalan HTML</h2> <p>...konten bab 1...</p> <h2 id="bab2">Bab 2: CSS Dasar</h2> <p>...konten bab 2...</p> <h2 id="bab3">Bab 3: JavaScript</h2> <p>...konten bab 3...</p> <!-- Langkah 2: Buat link menuju bookmark --> <!-- Link di halaman yang SAMA --> <a href="#bab1">Pergi ke Bab 1</a> <a href="#bab2">Pergi ke Bab 2</a> <a href="#bab3">Pergi ke Bab 3</a> <!-- Link dari halaman LAIN --> <a href="materi.html#bab2">Buka Bab 2 dari halaman lain</a>

6. Spesifisitas: id vs class

Dalam CSS, spesifisitas menentukan aturan mana yang "menang" ketika ada konflik gaya. Selector id (#) memiliki spesifisitas yang lebih tinggi daripada selector kelas (.).

<style> .warna-biru { color: blue; /* Spesifisitas: 0,1,0 */ } #warna-merah { color: red; /* Spesifisitas: 1,0,0 — LEBIH TINGGI, akan menang! */ } </style> <!-- Elemen ini akan berwarna MERAH karena id lebih spesifik --> <p id="warna-merah" class="warna-biru">Warna teks ini apa?</p>
Hasil:

Warna teks ini apa? → Merah! (karena id lebih spesifik)

7. Perbandingan: id vs class

Aspek id class
Selector CSS #namaId (tanda pagar) .namaKelas (tanda titik)
Keunikan Harus unik per halaman Boleh digunakan berulang
Satu elemen Hanya satu id per elemen Boleh punya banyak kelas
Spesifisitas Tinggi (menang atas class) Lebih rendah dari id
JavaScript getElementById("namaId") getElementsByClassName("nama")
Bookmark/Anchor Ya, href="#namaId" Tidak bisa
Best practice Elemen unik: header, footer, modal Komponen berulang: kartu, tombol

8. Aturan Penamaan id

Aturan Keterangan
Unik per halaman Tidak boleh ada dua elemen dengan id yang sama
Tidak boleh diawali angka id="section1" ✅ — id="1section" ❌
Tidak boleh mengandung spasi Gunakan tanda hubung: id="main-content"
Case-sensitive id="Header" ≠ id="header"
Deskriptif Gunakan nama yang bermakna: id="login-form"

Ringkasan

💡 Poin-poin penting tentang HTML Id:
  • Atribut id memberikan identitas unik pada elemen HTML.
  • Setiap nilai id harus unik dalam satu halaman — tidak boleh duplikat.
  • Di CSS, targetkan id menggunakan selector pagar: #namaId { ... }.
  • Di JavaScript, gunakan document.getElementById("namaId") untuk mengakses elemen.
  • Gunakan id sebagai bookmark/jangkar dengan href="#namaId".
  • Id memiliki spesifisitas CSS yang lebih tinggi daripada class.
