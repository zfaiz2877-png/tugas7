HTML Classes (Atribut class)

Atribut class pada HTML digunakan untuk menentukan satu atau lebih nama kelas untuk suatu elemen. Kelas ini kemudian dapat digunakan oleh CSS untuk memberi gaya pada elemen tersebut, atau oleh JavaScript untuk mengakses dan memanipulasi elemen.

📌 Catatan: Atribut class bisa digunakan pada semua elemen HTML. Satu elemen bisa memiliki lebih dari satu kelas, dan satu kelas bisa diterapkan pada banyak elemen berbeda.

1. Sintaks Dasar Atribut class

Untuk memberikan kelas pada elemen HTML, tambahkan atribut class="namaKelas" di dalam tag pembuka. Di CSS, kelas ditarget menggunakan tanda titik (.) diikuti nama kelasnya.

<!-- HTML: memberikan kelas pada elemen --> <div class="namaKelas">Konten elemen</div> <p class="namaKelas">Paragraf dengan kelas</p> /* CSS: menarget kelas dengan tanda titik (.) */ .namaKelas { /* aturan gaya di sini */ color: blue; font-size: 18px; }

2. Menggunakan class pada Elemen <div>

Contoh penggunaan atribut class yang paling umum adalah pada elemen <div>. Dengan mendefinisikan kelas di CSS, kita bisa menerapkan gaya yang sama pada banyak elemen sekaligus.

<!DOCTYPE html> <html> <head> <style> .kota { background-color: #04AA6D; color: white; margin: 10px 0; padding: 15px; border-radius: 8px; } </style> </head> <body> <div class="kota"> <h2>Jakarta</h2> <p>Ibu kota Republik Indonesia.</p> </div> <div class="kota"> <h2>Surabaya</h2> <p>Kota pahlawan, terbesar kedua di Indonesia.</p> </div> <div class="kota"> <h2>Bandung</h2> <p>Kota Kembang dengan udara sejuk.</p> </div> </body> </html>
Hasil:

Jakarta

Ibu kota Republik Indonesia.

Surabaya

Kota pahlawan, terbesar kedua di Indonesia.

Bandung

Kota Kembang dengan udara sejuk.

3. Menggunakan class pada Elemen Berbeda

Keunggulan atribut class adalah bahwa ia tidak terbatas pada satu jenis elemen. Kelas yang sama bisa diterapkan pada berbagai macam elemen HTML sekaligus — semua elemen dengan kelas tersebut akan mendapatkan gaya yang sama.

<style> .teks-hijau { color: #04AA6D; font-weight: bold; } </style> <h1 class="teks-hijau">Judul dengan warna hijau</h1> <h2 class="teks-hijau">Sub-judul dengan warna hijau</h2> <p class="teks-hijau">Paragraf dengan warna hijau</p> <span class="teks-hijau">Span dengan warna hijau</span>
Hasil:

Judul dengan warna hijau

Sub-judul dengan warna hijau

Paragraf dengan warna hijau

Span dengan warna hijau

4. Elemen dengan Beberapa Kelas (Multiple Classes)

Sebuah elemen HTML bisa memiliki lebih dari satu kelas sekaligus. Cukup pisahkan nama-nama kelas dengan spasi di dalam atribut class. Elemen akan mendapatkan gaya dari semua kelas yang disebutkan.

<style> .teks-tengah { text-align: center; } .teks-besar { font-size: 30px; } .teks-hijau { color: green; } </style> <!-- Elemen dengan SATU kelas --> <p class="teks-tengah">Hanya teks tengah.</p> <!-- Elemen dengan DUA kelas --> <p class="teks-tengah teks-besar">Teks tengah DAN besar.</p> <!-- Elemen dengan TIGA kelas --> <p class="teks-tengah teks-besar teks-hijau"> Teks tengah, besar, DAN hijau! </p>
Hasil:

Hanya teks tengah.

Teks tengah DAN besar.

Teks tengah, besar, DAN hijau!

📌 Penting: Urutan nama kelas dalam atribut class tidak mempengaruhi hasil. Yang menentukan adalah urutan aturan di CSS (cascade). Misalnya, class="kelas-a kelas-b" dan class="kelas-b kelas-a" menghasilkan tampilan yang sama.

5. Selector Kelas di CSS

Di CSS, kelas ditargetkan menggunakan tanda titik (.) sebelum nama kelas. Kita juga bisa membuat selector yang lebih spesifik dengan menggabungkan nama elemen dan kelas.

/* Menarget SEMUA elemen dengan kelas "info" */ .info { color: blue; } /* Menarget hanya elemen <p> dengan kelas "info" */ p.info { color: blue; font-style: italic; } /* Menarget hanya elemen <h2> dengan kelas "info" */ h2.info { color: darkblue; font-size: 24px; } /* Menarget elemen yang memiliki KEDUA kelas */ .kelas-a.kelas-b { /* hanya elemen yang punya kelas-a DAN kelas-b */ background: yellow; }

6. Contoh Praktis: Kartu Produk

Berikut contoh penggunaan class untuk membuat kartu-kartu produk yang seragam:

<style> .kartu { border: 1px solid #ddd; border-radius: 8px; padding: 20px; margin: 10px; width: 200px; display: inline-block; box-shadow: 0 2px 5px rgba(0,0,0,0.1); vertical-align: top; } .kartu-judul { color: #04AA6D; margin: 0 0 10px 0; } .kartu-harga { font-size: 1.2em; font-weight: bold; color: #e74c3c; } .tombol-beli { display: block; background: #04AA6D; color: white; text-align: center; padding: 8px; border-radius: 4px; margin-top: 10px; text-decoration: none; } </style> <div class="kartu"> <h3 class="kartu-judul">Laptop X1</h3> <p>Laptop gaming terbaru.</p> <p class="kartu-harga">Rp 12.000.000</p> <a href="#" class="tombol-beli">Beli Sekarang</a> </div> <div class="kartu"> <h3 class="kartu-judul">Mouse Pro</h3> <p>Mouse wireless ergonomis.</p> <p class="kartu-harga">Rp 350.000</p> <a href="#" class="tombol-beli">Beli Sekarang</a> </div>
Hasil:

Laptop X1

Laptop gaming terbaru.

Rp 12.000.000

Beli Sekarang

Mouse Pro

Mouse wireless ergonomis.

Rp 350.000

Beli Sekarang

7. Menggunakan class dengan JavaScript

Selain CSS, atribut class juga sangat berguna dalam JavaScript. Kita bisa mengakses elemen berdasarkan kelasnya menggunakan metode getElementsByClassName() atau querySelector().

<!-- HTML --> <button onclick="ubahWarna()">Ubah Warna</button> <div class="kotak">Kotak 1</div> <div class="kotak">Kotak 2</div> <div class="kotak">Kotak 3</div> <script> function ubahWarna() { // Mengambil SEMUA elemen dengan kelas "kotak" var elemen = document.getElementsByClassName("kotak"); // Mengubah warna latar semua elemen tersebut for (var i = 0; i < elemen.length; i++) { elemen[i].style.backgroundColor = "#04AA6D"; elemen[i].style.color = "white"; } } </script>

8. Aturan Penamaan Class

Berikut aturan dan konvensi yang perlu diperhatikan saat memberi nama kelas:

Aturan Contoh Benar Contoh Salah
Huruf kecil (konvensi) class="tombol-merah" class="TombolMerah" (hindari)
Pisah kata dengan tanda hubung class="nav-bar" class="nav bar" (= dua kelas)
Tidak boleh diawali angka class="item-1" class="1item"
Case-sensitive class="merah" ≠ class="Merah" —
Nama bermakna/deskriptif class="kartu-produk" class="x123" (hindari)

9. Contoh Tombol dengan Multiple Classes

<style> .btn { padding: 8px 16px; border-radius: 4px; color: white; border: none; cursor: pointer; } .btn-hijau { background: #04AA6D; } .btn-merah { background: #e74c3c; } .btn-biru { background: #3498db; } .btn-besar { font-size: 20px; padding: 14px 28px; } </style> <button class="btn btn-hijau">Hijau</button> <button class="btn btn-merah">Merah</button> <button class="btn btn-biru">Biru</button> <button class="btn btn-hijau btn-besar">Hijau Besar</button>
Hasil:

Hijau Merah Biru Hijau Besar

10. class vs id

Perbedaan utama antara atribut class dan id:

Aspek class id
Selector CSS .namaKelas (titik) #namaId (pagar)
Keunikan Boleh digunakan pada banyak elemen Harus unik — hanya satu elemen per halaman
Satu elemen Boleh memiliki banyak kelas Hanya boleh memiliki satu id
Spesifisitas CSS Lebih rendah Lebih tinggi
Kegunaan Styling berulang / komponen Elemen unik / navigasi / JavaScript

Ringkasan

💡 Poin-poin penting tentang HTML Classes:
  • Gunakan atribut class untuk menerapkan gaya pada satu atau banyak elemen.
  • Di CSS, targetkan kelas menggunakan selector titik: .namaKelas { ... }.
  • Satu elemen bisa memiliki beberapa kelas sekaligus, pisahkan dengan spasi.
  • Satu kelas bisa diterapkan ke berbagai jenis elemen HTML yang berbeda.
  • Gunakan nama kelas yang deskriptif dan konsisten.
  • Manfaatkan getElementsByClassName() di JavaScript untuk manipulasi elemen.
