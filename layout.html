HTML Layout

HTML menyediakan beberapa elemen semantik yang mendefinisikan berbagai bagian dari halaman web. Elemen-elemen layout ini membantu browser, mesin pencari, dan pembaca layar untuk memahami struktur dan makna konten halaman.

🖼️ Diagram Tata Letak Halaman Web Umum

Berikut adalah contoh tata letak halaman web yang umum menggunakan elemen semantik HTML:

<header> Logo & Judul Website
<nav>   Menu Navigasi   |   Home   |   About   |   Contact
<main> & <article> / <section>

Konten utama halaman berada di sini. Bisa berisi artikel, posting blog, atau informasi utama yang ingin disampaikan kepada pengunjung.

📋 Elemen-Elemen Layout HTML

HTML5 memperkenalkan elemen-elemen semantik berikut untuk layout halaman:

Elemen Deskripsi
<header> Mendefinisikan header untuk dokumen atau section. Biasanya berisi logo, judul, dan navigasi utama.
<nav> Mendefinisikan sekumpulan link navigasi utama (menu).
<main> Mendefinisikan konten utama dari dokumen. Hanya boleh ada satu <main> per halaman.
<section> Mendefinisikan sebuah bagian/seksi dalam dokumen dengan topik yang berkaitan.
<article> Mendefinisikan konten independen yang berdiri sendiri (posting blog, artikel berita, komentar).
<aside> Mendefinisikan konten di samping konten utama (sidebar, iklan, info tambahan).
<footer> Mendefinisikan footer untuk dokumen atau section. Biasanya berisi informasi hak cipta, kontak, dll.

1. Elemen <header>

Elemen <header> mewakili konten pengantar atau sekumpulan link navigasi. Biasanya berisi logo, judul situs, dan menu navigasi utama. Sebuah halaman boleh memiliki beberapa <header> (misalnya header untuk sebuah artikel).

<header> <h1>Website Saya</h1> <p>Tagline atau deskripsi singkat</p> <nav> <a href="/home">Home</a> <a href="/about">About</a> </nav> </header>

2. Elemen <nav>

Elemen <nav> mendefinisikan sekumpulan link navigasi. Tidak semua link harus berada di dalam <nav> — hanya blok utama link navigasi saja.

<nav> <ul> <li><a href="/home">Beranda</a></li> <li><a href="/produk">Produk</a></li> <li><a href="/kontak">Kontak</a></li> </ul> </nav>

3. Elemen <main>

Elemen <main> mewakili konten dominan (utama) dari <body>. Konten dalam <main> harus unik untuk dokumen tersebut. Hanya satu elemen <main> yang diperbolehkan per halaman.

<main> <h2>Artikel Terbaru</h2> <p>Ini adalah konten utama halaman saya...</p> </main>

4. Elemen <section>

Elemen <section> mendefinisikan sebuah bagian dalam dokumen. Menurut dokumentasi W3C, "seksi adalah pengelompokan konten bertema, biasanya dengan heading." Gunakan <section> untuk membagi halaman menjadi bagian-bagian logis.

<section> <h2>Tentang Kami</h2> <p>Kami adalah perusahaan teknologi yang berdiri sejak 2010...</p> </section> <section> <h2>Layanan Kami</h2> <p>Kami menyediakan berbagai layanan digital...</p> </section>

5. Elemen <article>

Elemen <article> mewakili konten yang berdiri sendiri dan bisa didistribusikan atau digunakan ulang secara independen — misalnya posting forum, artikel majalah, artikel berita, posting blog, komentar pengguna, widget interaktif, atau konten independen lainnya.

<article> <h2>Belajar HTML untuk Pemula</h2> <p>Ditulis oleh: John Doe | 24 September 2024</p> <p>HTML adalah bahasa markup standar untuk membuat halaman web...</p> </article>

6. Elemen <aside>

Elemen <aside> mendefinisikan konten yang ditempatkan di samping konten yang sedang ditampilkan, seperti sidebar. Konten di dalamnya harus berkaitan secara tidak langsung dengan konten sekitarnya (iklan, link terkait, bio penulis, dll.).

<aside> <h3>Artikel Terkait</h3> <ul> <li><a href="#">Cara Membuat Website</a></li> <li><a href="#">Tutorial CSS Dasar</a></li> </ul> </aside>

7. Elemen <footer>

Elemen <footer> mendefinisikan footer untuk dokumen atau seksi. Biasanya berisi: informasi hak cipta, informasi penulis, link ke dokumen terkait, informasi kontak, sitemap, dan lain-lain.

<footer> <p>&copy; 2024 Website Saya. Semua Hak Dilindungi.</p> <p> <a href="/privacy">Kebijakan Privasi</a> | <a href="/kontak">Hubungi Kami</a> </p> </footer>

📄 Contoh Struktur Halaman Lengkap

Berikut adalah contoh struktur halaman HTML lengkap menggunakan semua elemen layout:

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Contoh Layout HTML</title> </head> <body> <header> <h1>Website Berita Indonesia</h1> </header> <nav> <a href="/">Beranda</a> | <a href="/politik">Politik</a> | <a href="/olahraga">Olahraga</a> </nav> <main> <section> <h2>Berita Utama</h2> <article> <h3>Judul Berita Pertama</h3> <p>Isi berita pertama...</p> </article> <article> <h3>Judul Berita Kedua</h3> <p>Isi berita kedua...</p> </article> </section> <aside> <h3>Berita Populer</h3> <ul> <li><a href="#">Berita Populer 1</a></li> <li><a href="#">Berita Populer 2</a></li> </ul> </aside> </main> <footer> <p>&copy; 2024 Website Berita Indonesia</p> </footer> </body> </html>

🎨 Teknik Layout dengan CSS

Untuk mengatur posisi elemen-elemen layout, gunakan salah satu teknik CSS berikut:

Teknik Deskripsi Cocok Untuk
CSS Flexbox Layout satu dimensi (baris atau kolom) Navigasi, kartu, centering
CSS Grid Layout dua dimensi (baris dan kolom) Layout halaman penuh, galeri
CSS Float Mengapungkan elemen ke kiri/kanan (cara lama) Konten dengan gambar melayang
CSS Positioning Menempatkan elemen secara absolut/relatif/fixed Header sticky, popup, overlay
/* Contoh layout dengan Flexbox */ header { display: flex; justify-content: space-between; align-items: center; } main { display: flex; gap: 20px; } article { flex: 3; } aside { flex: 1; } /* Contoh layout dengan Grid */ body { display: grid; grid-template-areas: "header header" "nav nav" "main aside" "footer footer"; grid-template-columns: 3fr 1fr; }
💡 Tips: Selalu gunakan elemen semantik yang tepat daripada menggunakan <div> untuk segalanya. Elemen semantik membuat kode lebih mudah dibaca, meningkatkan aksesibilitas, dan membantu SEO (Search Engine Optimization).

⚖️ Semantik vs Non-Semantik

Sebelum HTML5, developer menggunakan <div> untuk semua bagian layout. Sekarang, gunakan elemen semantik yang bermakna:

❌ Cara Lama (Non-Semantik) ✅ Cara Baru (Semantik)
<div id="header"> <header>
<div id="nav"> <nav>
<div id="main"> <main>
<div id="sidebar"> <aside>
<div id="footer"> <footer>
🔍 Penting: Browser lama seperti IE8 tidak mendukung elemen HTML5 semantik. Jika perlu mendukung browser lama, tambahkan CSS: header, nav, main, section, article, aside, footer { display: block; }
