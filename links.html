HTML Links (Tautan)

Tautan (link) adalah salah satu fitur paling fundamental dalam HTML dan World Wide Web. Dengan tautan, pengguna dapat berpindah dari satu halaman ke halaman lain hanya dengan satu klik. Tautan ditemukan di hampir semua halaman web.

1. Elemen <a> dan Atribut href

Tautan HTML didefinisikan menggunakan tag <a> (anchor). Atribut href (Hypertext REFerence) menentukan tujuan dari tautan tersebut.

<a href="https://www.example.com">Kunjungi Example</a>
Hasil:

Kunjungi Example

Sintaks dasar tag <a>:

<a href="url-tujuan">Teks yang dapat diklik</a>
📌 Catatan: Secara default, tautan akan tampil dengan garis bawah dan berwarna biru (belum dikunjungi), ungu (sudah dikunjungi), dan merah (sedang diklik).

2. Atribut target

Atribut target menentukan di mana dokumen yang ditautkan akan dibuka.

Nilai target Keterangan
_self Default. Membuka dokumen di jendela/tab yang sama.
_blank Membuka dokumen di jendela atau tab baru.
_parent Membuka dokumen di frame induk (parent frame).
_top Membuka dokumen di seluruh badan jendela (menggantikan semua frame).
<!-- Membuka di tab baru --> <a href="https://www.google.com" target="_blank">Buka Google di Tab Baru</a> <!-- Membuka di tab yang sama (default) --> <a href="about.html" target="_self">Halaman Tentang Kami</a>
💡 Tips Keamanan: Saat menggunakan target="_blank", sebaiknya tambahkan rel="noopener noreferrer" untuk alasan keamanan, agar halaman yang dibuka tidak dapat mengakses halaman asli melalui window.opener.

<a href="url" target="_blank" rel="noopener noreferrer">Link Aman</a>

3. URL Absolut vs URL Relatif

Nilai atribut href dapat berupa URL absolut atau URL relatif.

URL Absolut

URL absolut adalah URL lengkap termasuk protokol dan nama domain. Digunakan untuk menautkan ke situs web lain.

<!-- URL Absolut - menuju website lain --> <a href="https://www.w3schools.com">W3Schools</a> <a href="https://www.wikipedia.org">Wikipedia</a>

URL Relatif

URL relatif tidak menyertakan nama domain. Digunakan untuk menautkan ke halaman dalam website yang sama.

<!-- URL Relatif - menuju halaman di website yang sama --> <a href="tentang.html">Tentang Kami</a> <a href="kontak.html">Hubungi Kami</a> <a href="/galeri/foto.html">Galeri Foto</a> <a href="../index.html">Kembali ke Beranda</a>
📌 Perbedaan penting:
  • Absolut: https://www.contoh.com/halaman.html → mencakup protokol + domain + path
  • Relatif: halaman.html atau ../halaman.html → hanya path dari lokasi file saat ini

4. Warna dan Gaya Tautan

Secara default, browser menampilkan tautan dengan warna:

  • Biru dengan garis bawah — tautan yang belum dikunjungi
  • Ungu dengan garis bawah — tautan yang sudah dikunjungi
  • Merah dengan garis bawah — tautan yang sedang aktif (diklik)
Belum dikunjungi (biru) Sudah dikunjungi (ungu)

Anda dapat mengubah warna tautan dengan CSS menggunakan pseudo-class:

a:link { color: #04AA6D; } /* Belum dikunjungi */ a:visited { color: #800080; } /* Sudah dikunjungi */ a:hover { color: #ff5722; } /* Saat mouse hover */ a:active { color: #ff0000; } /* Saat diklik */

Tautan tanpa garis bawah

a { text-decoration: none; color: #04AA6D; } a:hover { text-decoration: underline; }

Tautan sebagai Tombol

Tautan dapat dibuat tampak seperti tombol menggunakan CSS:

<a href="halaman.html" style=" background-color: #04AA6D; color: white; padding: 10px 20px; text-decoration: none; border-radius: 5px; display: inline-block; ">Klik Saya</a>
Klik Saya

5. Tautan Bookmark (Menggunakan #id)

Bookmark atau tautan jangkar digunakan untuk melompat ke bagian tertentu dari halaman yang sama atau halaman lain. Cara kerjanya dengan memberikan atribut id pada elemen tujuan, lalu menggunakan #id pada href.

<!-- Langkah 1: Beri id pada elemen tujuan --> <h2 id="bagian-kontak">Hubungi Kami</h2> <!-- Langkah 2: Buat tautan yang menuju id tersebut --> <a href="#bagian-kontak">Pergi ke Bagian Kontak</a> <!-- Tautan bookmark ke halaman lain --> <a href="halaman-lain.html#bagian-kontak">Kontak di Halaman Lain</a>
💡 Penggunaan umum: Tautan bookmark sering digunakan untuk tombol "Kembali ke Atas" atau navigasi dalam halaman yang panjang (one-page website).

6. Tautan Email dan Telepon

Tag <a> juga dapat digunakan untuk membuka aplikasi email atau telepon:

<!-- Tautan Email --> <a href="mailto:info@contoh.com">Kirim Email</a> <!-- Tautan Telepon --> <a href="tel:+6281234567890">Hubungi: +62 812 3456 7890</a> <!-- Email dengan subject dan body --> <a href="mailto:info@contoh.com?subject=Pertanyaan&body=Halo"> Kirim Email dengan Subject </a>

7. Contoh Lengkap

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Contoh Tautan HTML</title> <style> a { color: #04AA6D; text-decoration: none; } a:hover { text-decoration: underline; color: #028a57; } </style> </head> <body> <h1 id="atas">Halaman Utama</h1> <!-- Tautan Absolut --> <a href="https://www.google.com" target="_blank" rel="noopener"> Buka Google </a> <!-- Tautan Relatif --> <a href="tentang.html">Tentang Kami</a> <!-- Tautan Email --> <a href="mailto:admin@situs.com">Hubungi Admin</a> <!-- Bookmark --> <a href="#atas">↑ Kembali ke Atas</a> </body> </html>

Ringkasan

Konsep Sintaks Keterangan
Tautan dasar <a href="url">Teks</a> Membuat tautan dapat diklik
Tab baru target="_blank" Buka di tab/jendela baru
URL Absolut href="https://..." Link ke situs lain
URL Relatif href="halaman.html" Link ke halaman dalam situs
Bookmark href="#id-elemen" Lompat ke bagian tertentu
Email href="mailto:email" Buka aplikasi email
Telepon href="tel:nomor" Buka aplikasi telepon
