HTML Buttons

Elemen <button> HTML

Tag <button> mendefinisikan tombol yang dapat diklik.

Di dalam elemen <button>, Anda dapat meletakkan teks (dan tag seperti <i>, <b>, <strong>, <br>, <img>, dll.). Hal ini tidak dimungkinkan dengan tombol yang dibuat menggunakan elemen <input>.

Contoh Sintaks Dasar

<button type="button" onclick="alert('Halo Dunia!')">Klik Saya!</button>

Contoh Live Tombol Interaktif

Atribut type pada Tombol

Selalu tentukan atribut type untuk elemen tombol. Nilai yang didukung meliputi:

  • button: Tombol standar yang dapat diklik (biasanya untuk memicu JavaScript).
  • submit: Tombol untuk mengirimkan formulir (nilai default di dalam tag <form>).
  • reset: Tombol untuk mengatur ulang semua data dalam formulir ke nilai awal.

Tombol Sebagai Tautan

<button onclick="document.location='https://www.w3schools.com'">Buka W3Schools</button>
Tips & Best Practice: Selalu tentukan atribut type="button" jika tombol tidak digunakan untuk mengirim formulir. Jika tidak ditentukan, beberapa browser akan memperlakukannya sebagai tombol kirim (submit) form secara default.
