HTML URL Encoding

URL encoding (juga disebut Percent Encoding) adalah mekanisme untuk mengkodekan informasi dalam URL (Uniform Resource Locator) agar dapat dikirimkan dengan aman melalui internet. URL hanya boleh menggunakan karakter-karakter ASCII tertentu.

1. Apa Itu URL?

URL (Uniform Resource Locator) adalah alamat unik yang digunakan untuk mengakses sumber daya di internet, seperti halaman web, gambar, file, dan sebagainya.

Anatomi URL:

https://www.contoh.com/pencarian?q=belajar+html&lang=id#hasil
https:// → Protokol/Skema www.contoh.com → Host/Domain /pencarian → Path ?q=belajar+html&lang=id → Query String #hasil → Fragment/Anchor

2. Mengapa URL Hanya Boleh ASCII?

Standar URL (RFC 3986) menetapkan bahwa URL hanya boleh berisi karakter ASCII. Ini karena URL dirancang sejak era internet awal ketika hanya ASCII yang digunakan secara universal.

Karakter yang boleh digunakan langsung dalam URL (tanpa encoding):

A-Z a-z 0-9 - _ . ~ Karakter-karakter khusus yang memiliki fungsi dalam URL: : / ? # [ ] @ ! $ & ' ( ) * + , ; =
