HTML Tables (Tabel)

Tabel HTML digunakan untuk menyusun data dalam baris dan kolom. Tabel sangat berguna untuk menampilkan informasi terstruktur seperti jadwal, daftar harga, laporan, dan data perbandingan.

1. Struktur Dasar Tabel

Tabel HTML dibuat menggunakan kombinasi beberapa tag:

Tag Keterangan
<table> Mendefinisikan tabel
<tr> Table Row — mendefinisikan baris pada tabel
<th> Table Header — sel header (tebal, rata tengah secara default)
<td> Table Data — sel data biasa
<thead> Mengelompokkan konten header tabel
<tbody> Mengelompokkan konten isi tabel
<tfoot> Mengelompokkan konten footer tabel
<caption> Menambahkan judul/keterangan tabel

Contoh tabel paling sederhana:

<table> <tr> <th>Nama</th> <th>Usia</th> </tr> <tr> <td>Budi</td> <td>25</td> </tr> <tr> <td>Siti</td> <td>22</td> </tr> </table>
Hasil:

Nama Usia
Budi 25
Siti 22

2. Border Tabel

Secara default, tabel HTML tidak memiliki border. Anda perlu menambahkan CSS untuk menampilkan border:

<style> table, th, td { border: 1px solid black; border-collapse: collapse; /* Gabungkan border jadi satu */ } </style> <table> <tr> <th>Produk</th> <th>Harga</th> </tr> <tr> <td>Apel</td> <td>Rp 5.000</td> </tr> </table>
📌 border-collapse:
  • border-collapse: collapse — Menggabungkan border sel yang berdekatan menjadi satu garis (lebih rapi)
  • border-collapse: separate — Setiap sel memiliki border sendiri-sendiri (default)

3. Cell Padding dan Cell Spacing

padding menentukan jarak antara konten sel dengan border sel:

<style> th, td { padding: 15px; /* Jarak konten dengan tepi sel */ } </style>

Anda juga bisa menggunakan border-spacing untuk jarak antar sel (ketika border-collapse: separate):

<style> table { border-spacing: 5px; /* Jarak antar sel */ } </style>

4. Tabel dengan Styling Lengkap

<style> table { border-collapse: collapse; width: 100%; } th, td { border: 1px solid #ddd; padding: 10px; text-align: left; } th { background-color: #04AA6D; color: white; } tr:nth-child(even) { background-color: #f2f2f2; /* Warna baris genap */ } tr:hover { background-color: #ddd; /* Efek hover */ } </style> <table> <tr> <th>Nama</th> <th>Jabatan</th> <th>Kota</th> </tr> <tr> <td>Budi Santoso</td> <td>Manajer</td> <td>Jakarta</td> </tr> <tr> <td>Siti Rahayu</td> <td>Developer</td> <td>Bandung</td> </tr> <tr> <td>Ahmad Fauzi</td> <td>Designer</td> <td>Surabaya</td> </tr> </table>
Hasil:

Nama Jabatan Kota
Budi Santoso Manajer Jakarta
Siti Rahayu Developer Bandung
Ahmad Fauzi Designer Surabaya

5. Colspan — Menggabungkan Kolom

Atribut colspan pada <td> atau <th> digunakan untuk membuat satu sel memanjang ke beberapa kolom.

<table> <tr> <th colspan="2">Informasi Pribadi</th> <!-- Mencakup 2 kolom --> <th colspan="2">Kontak</th> <!-- Mencakup 2 kolom --> </tr> <tr> <td>Nama</td> <td>Usia</td> <td>Email</td> <td>Telepon</td> </tr> <tr> <td>Budi</td> <td>25</td> <td>budi@mail.com</td> <td>0812-xxx</td> </tr> </table>
Hasil:

Informasi Pribadi Kontak
Nama Usia Email Telepon
Budi 25 budi@mail.com 0812-xxx

6. Rowspan — Menggabungkan Baris

Atribut rowspan digunakan untuk membuat satu sel memanjang ke beberapa baris.

<table> <tr> <th>Hari</th> <th>Jadwal</th> </tr> <tr> <td rowspan="2">Senin</td> <!-- Mencakup 2 baris --> <td>08.00 - Matematika</td> </tr> <tr> <td>10.00 - Bahasa Indonesia</td> </tr> <tr> <td>Selasa</td> <td>08.00 - IPA</td> </tr> </table>
Hasil:

Hari Jadwal
Senin 08.00 - Matematika
10.00 - Bahasa Indonesia
Selasa 08.00 - IPA

7. Struktur Tabel Lengkap (<thead>, <tbody>, <tfoot>)

Untuk tabel yang lebih terstruktur, gunakan <thead>, <tbody>, dan <tfoot>:

<table> <caption>Laporan Penjualan Bulan Ini</caption> <thead> <tr> <th>Produk</th> <th>Qty</th> <th>Harga</th> <th>Total</th> </tr> </thead> <tbody> <tr> <td>Laptop</td> <td>3</td> <td>Rp 8.000.000</td> <td>Rp 24.000.000</td> </tr> <tr> <td>Mouse</td> <td>10</td> <td>Rp 150.000</td> <td>Rp 1.500.000</td> </tr> </tbody> <tfoot> <tr> <td colspan="3"><strong>Total Keseluruhan</strong></td> <td><strong>Rp 25.500.000</strong></td> </tr> </tfoot> </table>
Hasil:

Laporan Penjualan Bulan Ini
Produk Qty Harga Total
Laptop 3 Rp 8.000.000 Rp 24.000.000
Mouse 10 Rp 150.000 Rp 1.500.000
Total Keseluruhan Rp 25.500.000

8. Tips Styling Tabel

<style> /* Lebar kolom */ table { width: 100%; } th:first-child { width: 40%; } /* Rata kanan untuk angka */ td:last-child { text-align: right; } /* Warna bergantian (zebra stripes) */ tr:nth-child(even) { background: #f2f2f2; } tr:nth-child(odd) { background: #ffffff; } /* Efek hover */ tr:hover { background: #e8f5e9; } /* Tabel responsif (bisa di-scroll horizontal di layar kecil) */ .table-wrapper { overflow-x: auto; } </style> <div class="table-wrapper"> <table> ... </table> </div>
💡 Tabel Responsif: Bungkus tabel dalam <div style="overflow-x: auto;"> agar tabel bisa di-scroll secara horizontal pada layar kecil/mobile, sehingga tidak merusak tata letak halaman.

Ringkasan Tag Tabel

Tag/Atribut Fungsi Contoh
<table> Wadah utama tabel <table>...</table>
<tr> Baris tabel <tr>...</tr>
<th> Sel header (tebal, tengah) <th>Nama</th>
<td> Sel data biasa <td>Budi</td>
colspan Gabung beberapa kolom <td colspan="3">
rowspan Gabung beberapa baris <td rowspan="2">
<caption> Judul tabel <caption>Laporan</caption>
<thead>/<tbody>/<tfoot> Pengelompokan bagian tabel Membantu styling & aksesibilitas
