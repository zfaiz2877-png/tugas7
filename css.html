HTML CSS (Cascading Style Sheets)

CSS (Cascading Style Sheets) digunakan untuk memformat tampilan halaman web. CSS berfungsi untuk mengontrol warna, font, ukuran teks, jarak antar elemen, cara elemen diposisikan/ditampilkan, gambar latar, dan masih banyak lagi.

Kata "cascading" (bertingkat/berjenjang) berarti bahwa sebuah style dapat mengalir dari parent element ke child element, dan aturan dengan spesifisitas lebih tinggi akan mengalahkan aturan yang lebih umum.

1. Tiga Cara Menggunakan CSS

Ada tiga cara untuk menambahkan CSS ke dalam dokumen HTML:

🖊️

Inline CSS

Ditulis langsung di dalam atribut style pada elemen HTML

📄

Internal CSS

Ditulis di dalam tag <style> di dalam bagian <head>

📁

External CSS

Ditulis di file terpisah (.css) dan dihubungkan via tag <link>

2. Inline CSS — CSS Langsung di Tag

Inline CSS digunakan untuk menerapkan style unik pada satu elemen tunggal. Caranya dengan menambahkan atribut style langsung ke tag HTML tersebut. Nilai dari atribut style dapat berisi properti CSS apa pun.

<!DOCTYPE html> <html> <body> <h1 style="color: blue; text-align: center;"> Judul Berwarna Biru </h1> <p style="color: red; font-size: 18px; font-family: Verdana;"> Paragraf ini berwarna merah dengan font Verdana ukuran 18px. </p> <p style="background-color: #FFD700; padding: 15px; border-radius: 8px;"> Paragraf ini memiliki latar kuning dengan padding dan sudut melengkung. </p> </body> </html>
Hasil:

Judul Berwarna Biru

Paragraf ini berwarna merah dengan font Verdana ukuran 18px.

Paragraf ini memiliki latar kuning dengan padding dan sudut melengkung.

⚠️ Kekurangan Inline CSS:
  • Tidak efisien — harus ditulis ulang di setiap elemen yang sama.
  • Sulit dikelola — bayangkan harus mengubah 100 paragraf satu per satu.
  • Mencampur konten (HTML) dengan presentasi (CSS), melanggar prinsip pemisahan kekhawatiran.
Gunakan hanya untuk: Override style pada elemen spesifik, email HTML, atau quick testing.

3. Internal CSS — CSS di Dalam <style>

Internal CSS (atau Embedded CSS) mendefinisikan style untuk satu halaman HTML tunggal. Style ditulis di dalam elemen <style> yang ditempatkan di bagian <head> dokumen HTML.

Keunggulan Internal CSS adalah kamu bisa mengatur style untuk banyak elemen sekaligus cukup dalam satu tempat.

<!DOCTYPE html> <html> <head> <style> body { background-color: #f0f8ff; font-family: 'Segoe UI', Arial, sans-serif; } h1 { color: #04AA6D; text-align: center; border-bottom: 3px solid #04AA6D; padding-bottom: 10px; } p { color: #444; font-size: 16px; line-height: 1.7; } .highlight { background-color: yellow; padding: 2px 5px; } .box { background-color: white; border: 1px solid #ccc; padding: 20px; border-radius: 8px; box-shadow: 0 2px 6px rgba(0,0,0,0.1); } </style> </head> <body> <div class="box"> <h1>Website Saya</h1> <p>Ini adalah paragraf pertama.</p> <p>Kata <span class="highlight">penting</span> disorot.</p> </div> </body> </html>
Hasil:

Website Saya

Ini adalah paragraf pertama.

Kata penting disorot.

Sintaks Aturan CSS:

selector { property: value; property: value; }
Bagian Penjelasan Contoh
Selector Menentukan elemen HTML mana yang akan diberi style h1, p, .kelas, #id
Property Aspek tampilan yang ingin diubah color, font-size, background
Value Nilai yang diterapkan untuk properti tersebut red, 16px, #FF0000

4. External CSS — CSS di File Terpisah

External CSS adalah metode yang paling direkomendasikan untuk website nyata. Style ditulis di file terpisah dengan ekstensi .css, lalu dihubungkan ke file HTML menggunakan tag <link>.

Keunggulan utama: Satu file CSS bisa digunakan oleh banyak halaman HTML. Jika ingin mengubah tampilan, cukup edit file CSS-nya saja, semua halaman akan berubah.

Langkah 1 — Buat file CSS (mystyle.css):

/* File: mystyle.css */ body { background-color: #f4f4f4; font-family: 'Segoe UI', Arial, sans-serif; margin: 0; padding: 0; } h1 { color: #04AA6D; text-align: center; font-size: 2.5em; } h2 { color: #333; border-left: 4px solid #04AA6D; padding-left: 10px; } p { color: #555; line-height: 1.8; font-size: 16px; } .container { max-width: 900px; margin: 0 auto; padding: 20px; background: white; } .btn { display: inline-block; padding: 10px 25px; background-color: #04AA6D; color: white; border-radius: 5px; text-decoration: none; font-weight: bold; }

Langkah 2 — Hubungkan ke file HTML dengan tag <link>:

<!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <title>Website Saya</title> <!-- Menghubungkan file CSS eksternal --> <link rel="stylesheet" href="mystyle.css"> </head> <body> <div class="container"> <h1>Selamat Datang!</h1> <h2>Tentang Kami</h2> <p>Website ini menggunakan External CSS untuk styling.</p> <a href="kontak.html" class="btn">Hubungi Kami</a> </div> </body> </html>
Hasil (simulasi):

Selamat Datang!

Tentang Kami

Website ini menggunakan External CSS untuk styling.

Hubungi Kami
📌 Atribut Tag <link>:
  • rel="stylesheet" — menyatakan hubungan file dengan dokumen HTML (stylesheet)
  • href="mystyle.css" — path/lokasi menuju file CSS
  • Tag <link> selalu ditempatkan di dalam elemen <head>

5. Properti CSS yang Sering Digunakan

/* Warna Teks dan Latar */ color: #333; background-color: #f0f0f0; /* Font */ font-family: 'Arial', sans-serif; font-size: 16px; font-weight: bold; font-style: italic; /* Teks */ text-align: center; text-decoration: underline; line-height: 1.6; letter-spacing: 1px; /* Box Model */ width: 100%; max-width: 900px; height: auto; padding: 20px; margin: 10px auto; border: 1px solid #ccc; border-radius: 8px; /* Display */ display: block; display: inline; display: inline-block; display: flex; display: grid; display: none;

7. Prioritas CSS (Cascading Order)

Ketika beberapa style diterapkan pada elemen yang sama, CSS menggunakan aturan cascade untuk menentukan style mana yang dipakai. Urutan prioritasnya dari tertinggi ke terendah:

Inline CSS
(Prioritas Tertinggi)
→ menimpa
Internal CSS
(Prioritas Sedang)
→ menimpa
External CSS
(Prioritas Rendah)
→ menimpa
Browser Default
(Prioritas Terendah)
<!-- File: style.css berisi: h1 { color: green; } --> <!DOCTYPE html> <html> <head> <link rel="stylesheet" href="style.css"> <!-- External: hijau --> <style> h1 { color: blue; } /* Internal: biru — menimpa external */ </style> </head> <body> <h1 style="color: red;">Judul Ini Akan Berwarna Merah</h1> <!-- Inline CSS (merah) menimpa Internal (biru) dan External (hijau) --> </body> </html>

💡 Tips Belajar CSS:
  • Mulai dengan Internal CSS saat belajar — semuanya dalam satu file, mudah dilihat.
  • Pindah ke External CSS saat project mulai berkembang.
  • Hindari terlalu banyak Inline CSS dalam kode produksi.
  • Gunakan DevTools browser (F12) untuk bereksperimen dengan CSS secara langsung.
  • Pelajari CSS Selectors: tag, class (.kelas), dan ID (#id).
