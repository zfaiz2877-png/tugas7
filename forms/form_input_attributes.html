HTML Input Attributes

Elemen <input> mendukung banyak atribut yang mengontrol perilaku, tampilan, dan validasi input. Menguasai atribut-atribut ini memungkinkan kamu membuat form yang lebih interaktif, aman, dan ramah pengguna.

1. value — Nilai Awal

Atribut value menentukan nilai awal (default) dari elemen input. Nilai ini akan muncul saat halaman pertama dimuat.

<!-- Input teks dengan nilai awal --> <input type="text" name="nama" value="Budi Santoso"> <!-- Tombol submit dengan teks kustom --> <input type="submit" value="Daftar Sekarang"> <!-- Radio button yang dipilih secara default --> <input type="radio" name="pilihan" value="ya" checked> Ya <input type="radio" name="pilihan" value="tidak"> Tidak

2. readonly Boolean — Hanya Baca

Atribut readonly membuat input tidak bisa diubah oleh pengguna, tetapi nilainya tetap dikirim ke server saat form disubmit. Ini berbeda dengan disabled.

<!-- Pengguna tidak bisa mengubah nilainya --> <input type="text" name="kode" value="TXN-20240924" readonly> <!-- Readonly juga bisa ditulis seperti ini --> <input type="text" name="id" value="USR-001" readonly="readonly">
💡 Gunakan readonly untuk menampilkan data yang tidak boleh diubah pengguna, seperti kode referensi atau ID sistem.

3. disabled Boolean — Dinonaktifkan

Atribut disabled menonaktifkan elemen input sepenuhnya — pengguna tidak bisa mengklik atau memodifikasinya. Input yang disabled tidak ikut dikirim ke server.

<!-- Input dinonaktifkan --> <input type="text" name="kota" value="Jakarta" disabled> <!-- Tombol dinonaktifkan --> <input type="submit" value="Kirim" disabled>

4. size — Lebar Input

Atribut size menentukan lebar tampilan input dalam jumlah karakter. Nilai default adalah 20. Ini hanya mengatur tampilan, bukan batas karakter yang bisa dimasukkan.

<!-- Lebar input berbeda --> <input type="text" name="kode_pos" size="7" placeholder="Kode Pos"> <input type="text" name="nama" size="40" placeholder="Nama Lengkap">

5. maxlength — Maksimum Karakter

Atribut maxlength menentukan jumlah maksimum karakter yang boleh dimasukkan ke dalam input. Browser akan menghentikan pengetikan saat batas tercapai.

<!-- Maksimum 10 karakter --> <input type="text" name="kode" maxlength="10" placeholder="Maks 10 karakter"> <!-- Gabungan size dan maxlength --> <input type="text" name="pin" size="6" maxlength="6" placeholder="PIN 6 digit">

6. min & max — Nilai Minimum & Maksimum

Atribut min dan max menentukan batas bawah dan atas untuk input angka, tanggal, waktu, dan range.

<!-- Angka antara 1 dan 100 --> <input type="number" name="nilai" min="1" max="100" value="50"> <!-- Tanggal antara 2024-01-01 dan 2024-12-31 --> <input type="date" name="tanggal" min="2024-01-01" max="2024-12-31"> <!-- Waktu antara 09:00 dan 18:00 --> <input type="time" name="jam" min="09:00" max="18:00">

7. multiple Boolean — Banyak Nilai

Atribut multiple memungkinkan pengguna memasukkan lebih dari satu nilai. Berlaku untuk input tipe email dan file.

<!-- Beberapa email dipisahkan koma --> <input type="email" name="emails" multiple placeholder="email1@domain.com, email2@domain.com"> <!-- Upload beberapa file sekaligus --> <input type="file" name="foto" multiple accept="image/*">

8. pattern — Pola Validasi (Regex)

Atribut pattern menentukan ekspresi reguler (regex) yang harus dipenuhi oleh nilai input saat form dikirim. Selalu tambahkan title untuk memberi petunjuk format yang benar.

<!-- Hanya 3 huruf kapital --> <input type="text" name="kode_negara" pattern="[A-Z]{3}" title="Masukkan 3 huruf kapital (contoh: IDN)" placeholder="IDN"> <!-- Format nomor telepon Indonesia --> <input type="tel" name="telepon" pattern="0[0-9]{8,11}" title="Nomor telepon Indonesia (08xxx...)" placeholder="08xxxxxxxxx"> <!-- Password minimal 8 karakter, ada huruf dan angka --> <input type="password" name="pw" pattern="(?=.*\d)(?=.*[a-z]).{8,}" title="Min 8 karakter, mengandung huruf dan angka">
💡 Coba klik "Coba Submit" tanpa mengisi format yang benar untuk melihat pesan validasi!

9. placeholder — Teks Petunjuk

Atribut placeholder menampilkan teks petunjuk di dalam input yang hilang secara otomatis saat pengguna mulai mengetik. Digunakan untuk memberi contoh format.

<input type="text" name="nama" placeholder="Nama lengkap Anda"> <input type="email" name="email" placeholder="contoh@gmail.com"> <input type="tel" name="hp" placeholder="08xx-xxxx-xxxx"> <input type="url" name="web" placeholder="https://www.website.com">
⚠ Jangan andalkan placeholder sebagai pengganti label! Gunakan keduanya untuk aksesibilitas yang baik.

10. required Boolean — Wajib Diisi

Atribut required menandai bahwa input tersebut wajib diisi sebelum form bisa dikirim. Browser akan menampilkan pesan error jika input kosong.

<form action="/daftar.php" method="post"> <label>Nama: <input type="text" name="nama" required></label> <label>Email: <input type="email" name="email" required></label> <!-- Bisa juga ditulis required="required" --> <label>Password: <input type="password" name="pw" required="required"></label> <input type="submit" value="Daftar"> </form>
💡 Coba klik "Coba Submit" tanpa mengisi kolom untuk melihat validasi browser bekerja!

11. step — Interval Nilai

Atribut step menentukan interval nilai yang valid. Misalnya, step="5" pada input angka berarti hanya 0, 5, 10, 15, ... yang valid.

<!-- Interval 5: 0, 5, 10, 15... --> <input type="number" name="qty" min="0" max="100" step="5" value="0"> <!-- Interval 0.5: 0, 0.5, 1.0, 1.5... --> <input type="number" name="berat" min="0" step="0.5" placeholder="Berat (kg)"> <!-- Interval tanggal per 7 hari --> <input type="date" name="tanggal" step="7">

12. autofocus Boolean — Fokus Otomatis

Atribut autofocus membuat input tersebut otomatis mendapat fokus (kursor langsung berada di input tersebut) saat halaman selesai dimuat.

<form action="/login.php" method="post"> <!-- Input username langsung aktif saat halaman dibuka --> <input type="text" name="username" autofocus placeholder="Username Anda"> <input type="password" name="password" placeholder="Password"> <input type="submit" value="Masuk"> </form>
⚠ Gunakan autofocus hanya pada satu elemen per halaman, dan hanya jika elemen tersebut adalah input utama yang pertama kali perlu diisi pengguna.

13. height & width — Dimensi Gambar

Atribut height dan width menentukan tinggi dan lebar dalam piksel. Atribut ini hanya berlaku untuk input type="image".

<!-- Tombol submit berbentuk gambar --> <input type="image" src="https://www.w3schools.com/tags/img_submit.gif" alt="Kirim" width="128" height="128">
💡 Selalu tentukan width dan height pada type="image" untuk mencegah pergeseran layout halaman saat gambar dimuat.

14. list — Menghubungkan ke Datalist

Atribut list menghubungkan input dengan elemen <datalist> yang memiliki id yang sama, sehingga muncul saran autocomplete.

<input type="text" name="bahasa" list="daftar_bahasa" placeholder="Ketik nama bahasa..."> <datalist id="daftar_bahasa"> <option value="HTML"> <option value="CSS"> <option value="JavaScript"> <option value="Python"> <option value="PHP"> <option value="Java"> <option value="TypeScript"> </datalist>

15. autocomplete — Pelengkapan Otomatis

Atribut autocomplete mengontrol apakah browser boleh menyarankan nilai sebelumnya yang pernah diketik pengguna. Bisa diterapkan di level form maupun per input.

<!-- Aktifkan autocomplete di level form --> <form action="/aksi.php" method="post" autocomplete="on"> <!-- Autocomplete aktif untuk nama (default mengikuti form) --> <input type="text" name="nama" placeholder="Nama Anda"> <!-- Matikan autocomplete untuk field tertentu --> <input type="text" name="otp" autocomplete="off" placeholder="Kode OTP"> <!-- Petunjuk spesifik untuk browser --> <input type="email" name="email" autocomplete="email"> <input type="tel" name="hp" autocomplete="tel"> </form>
💡 Nilai autocomplete bisa lebih spesifik: name, email, tel, street-address, postal-code, dll. untuk membantu pengisian form otomatis di browser.

🌟 Contoh Form Registrasi Lengkap

Menggabungkan berbagai atribut input dalam satu form:

<form action="/daftar.php" method="post" autocomplete="on"> <label for="nama">Nama Lengkap: *</label> <input type="text" id="nama" name="nama" placeholder="Masukkan nama lengkap" required autofocus maxlength="100"> <label for="email">Email: *</label> <input type="email" id="email" name="email" placeholder="email@contoh.com" required autocomplete="email"> <label for="hp">No. HP: *</label> <input type="tel" id="hp" name="hp" placeholder="08xxxxxxxxxx" pattern="0[0-9]{8,11}" title="Contoh: 08123456789" required> <label for="usia">Usia (17-99): *</label> <input type="number" id="usia" name="usia" min="17" max="99" step="1" required> <label for="referal">Kode Referal (opsional):</label> <input type="text" id="referal" name="referal" maxlength="8" placeholder="Kode 8 karakter" pattern="[A-Z0-9]{8}" title="8 karakter huruf kapital dan angka"> <input type="submit" value="Daftar Sekarang"> </form>
