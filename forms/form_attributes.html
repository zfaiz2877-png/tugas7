HTML Form Attributes

Elemen <form> memiliki berbagai atribut yang mengontrol bagaimana form bekerja — mulai dari ke mana data dikirim, metode pengiriman, hingga pengaturan keamanan dan tampilan. Mari kita pelajari satu per satu.

📋 Ringkasan Semua Atribut Form

Atribut Nilai Fungsi
actionURLURL tujuan pengiriman data form
methodget | postMetode HTTP untuk mengirim data
autocompleteon | offMengaktifkan/menonaktifkan pelengkapan otomatis
novalidate(boolean)Menonaktifkan validasi browser
enctypelihat nilai di bawahEnkoding data saat dikirim
nameteksNama form untuk referensi JavaScript
target_blank | _self | _parent | _topDi mana respons ditampilkan
relnoopener | noreferrer | dll.Relasi antara dokumen saat ini dan yang dituju

1. Atribut action

Atribut action menentukan di mana data form dikirim setelah pengguna menekan tombol Submit. Nilainya adalah URL file server yang akan memproses data.

<!-- Kirim data ke file PHP di server --> <form action="/proses_form.php" method="post"> <input type="text" name="nama" placeholder="Nama Anda"> <input type="submit" value="Kirim"> </form> <!-- Tanpa action = kirim ke halaman yang sama --> <form method="post"> <input type="text" name="cari"> <input type="submit" value="Cari"> </form>
⚠ Jika atribut action dihilangkan, data dikirim ke URL halaman saat ini.

2. Atribut method

Atribut method menentukan metode HTTP yang digunakan untuk mengirim data form.

<!-- Metode GET: data tampil di URL --> <form action="/cari.php" method="get"> <input type="text" name="q" placeholder="Kata kunci..."> <input type="submit" value="Cari"> </form> <!-- URL hasil: /cari.php?q=kata+kunci --> <!-- Metode POST: data tersembunyi --> <form action="/login.php" method="post"> <input type="text" name="username"> <input type="password" name="password"> <input type="submit" value="Masuk"> </form>

3. Atribut autocomplete

Atribut autocomplete menentukan apakah browser boleh melengkapi nilai input secara otomatis berdasarkan nilai yang pernah dimasukkan pengguna sebelumnya.

<!-- Autocomplete aktif (default) --> <form action="/aksi.php" method="post" autocomplete="on"> <label>Nama: <input type="text" name="nama"></label> <label>Email: <input type="email" name="email"></label> <input type="submit"> </form> <!-- Autocomplete dinonaktifkan --> <form action="/aksi.php" method="post" autocomplete="off"> <label>Kode OTP: <input type="text" name="otp"></label> <input type="submit"> </form>
💡 Nonaktifkan autocomplete untuk kolom yang bersifat sensitif atau sekali pakai seperti kode OTP.

4. Atribut novalidate

Atribut novalidate adalah atribut boolean yang bila ada, menginstruksikan browser untuk tidak melakukan validasi data form saat form dikirim.

<!-- Browser tidak akan memvalidasi input email --> <form action="/aksi.php" method="post" novalidate> <label>Email: <input type="email" name="email" placeholder="masukkan email"> </label> <input type="submit" value="Kirim (tanpa validasi)"> </form>
⚠ Tanpa novalidate, browser akan menolak pengiriman jika email tidak valid.

5. Atribut enctype

Atribut enctype menentukan bagaimana data form dikodekan saat dikirim ke server. Atribut ini hanya berlaku untuk method post.

NilaiKeterangan
application/x-www-form-urlencodedDefault. Semua karakter dikodekan sebelum dikirim
multipart/form-dataWajib digunakan jika form menyertakan upload file
text/plainData dikirim tanpa encoding (tidak disarankan)
<!-- Form untuk upload file - wajib multipart/form-data --> <form action="/upload.php" method="post" enctype="multipart/form-data"> <label>Pilih file: <input type="file" name="berkas"> </label> <input type="submit" value="Upload"> </form>

6. Atribut name

Atribut name pada elemen <form> memberikan nama unik pada form sehingga dapat direferensikan oleh JavaScript atau diidentifikasi dalam dokumen dengan beberapa form.

<form name="formLogin" action="/login.php" method="post"> <input type="text" name="username"> <input type="password" name="password"> <input type="submit" value="Masuk"> </form> <script> // Mengakses form lewat nama di JavaScript var form = document.forms["formLogin"]; var user = form["username"].value; </script>

7. Atribut target

Atribut target menentukan di mana respons dari form ditampilkan setelah form dikirim.

NilaiKeterangan
_selfDefault. Respons ditampilkan di tab/jendela yang sama
_blankRespons dibuka di tab/jendela baru
_parentRespons ditampilkan di frame induk
_topRespons ditampilkan di seluruh jendela browser
<!-- Buka hasil di tab baru --> <form action="/hasil.php" method="get" target="_blank"> <input type="text" name="q" placeholder="Cari..."> <input type="submit" value="Cari di Tab Baru"> </form>

🌟 Contoh Form dengan Berbagai Atribut

<form action="/daftar.php" method="post" autocomplete="on" enctype="multipart/form-data" name="formDaftar" target="_self"> <label for="nama">Nama Lengkap:</label> <input type="text" id="nama" name="nama" required> <label for="email">Email:</label> <input type="email" id="email" name="email" required> <label for="foto">Foto Profil:</label> <input type="file" id="foto" name="foto" accept="image/*"> <input type="submit" value="Daftar Sekarang"> </form>

📋 Ringkasan

  • action — URL tujuan pengiriman data
  • method — GET (data di URL) atau POST (data tersembunyi)
  • autocomplete — on/off untuk pelengkapan otomatis
  • novalidate — menonaktifkan validasi browser
  • enctype — wajib multipart/form-data untuk upload file
  • name — nama form untuk referensi JavaScript
  • target — lokasi tampil respons (_blank, _self, dll.)
