HTML Input Form Attributes

Atribut Form Khusus untuk Elemen <input>

Bab ini menjelaskan berbagai atribut form* yang berlaku langsung pada elemen <input> dan <button> untuk menggantikan (override) pengaturan pada tag <form> induk.

Daftar Atribut Input Form

AtributDeskripsi
formMenentukan formulir tempat elemen input berada (bahkan jika elemen diletakkan di luar tag <form>).
formactionMenentukan URL file pemroses saat form dikirim melalui tombol ini (menggantikan atribut action form).
formenctypeMenentukan bagaimana data formulir harus dienkode saat dikirim (menggantikan atribut enctype form).
formmethodMenentukan metode HTTP (GET atau POST) untuk tombol ini (menggantikan atribut method form).
formnovalidateMenentukan bahwa form tidak boleh divalidasi saat dikirim melalui tombol ini.
formtargetMenentukan tempat menampilkan respon form (menggantikan atribut target form).

1. Atribut formaction

Atribut formaction memungkinkan satu formulir memiliki beberapa tombol kirim ke tujuan yang berbeda:

<form action="/action_page.php"> <label for="fname">First name:</label> <input type="text" id="fname" name="fname"><br><br> <input type="submit" value="Kirim Biasa"> <input type="submit" formaction="/action_admin.php" value="Kirim Sebagai Admin"> </form>

2. Atribut form (Input di Luar Form)

<form action="/action_page.php" id="form1"> <label for="fname">First name:</label> <input type="text" id="fname" name="fname"><br><br> <input type="submit" value="Submit"> </form> <!-- Input ini berada di luar tag <form> tetapi terhubung via atribut form --> <label for="lname">Last name:</label> <input type="text" id="lname" name="lname" form="form1">

3. Atribut formnovalidate

<form action="/action_page.php"> <label for="email">Enter your email:</label> <input type="email" id="email" name="email" required><br><br> <input type="submit" value="Submit dengan Validasi"> <input type="submit" formnovalidate="formnovalidate" value="Submit Tanpa Validasi"> </form>
Catatan: Atribut formaction, formenctype, formmethod, formnovalidate, dan formtarget hanya dapat digunakan dengan <input type="submit">, <input type="image">, dan <button type="submit">.
