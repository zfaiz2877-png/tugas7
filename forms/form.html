HTML Form

Form HTML digunakan untuk mengumpulkan input dari pengguna. Input pengguna kemudian dikirim ke server untuk diproses. Form adalah salah satu komponen paling penting dalam pengembangan web karena memungkinkan interaksi dua arah antara pengguna dan server.

📄 Elemen <form>

Elemen HTML <form> digunakan untuk membuat form HTML untuk input pengguna. Semua elemen input berada di dalam tag <form> ... </form>.

<form> <!-- Elemen-elemen input berada di sini --> . . </form>

Elemen <form> adalah kontainer untuk berbagai jenis elemen input, seperti:

  • Kolom teks (<input type="text">)
  • Kotak centang (<input type="checkbox">)
  • Tombol radio (<input type="radio">)
  • Tombol kirim (<input type="submit">)
  • Dan masih banyak lagi...

🔗 Atribut action

Atribut action mendefinisikan tindakan yang dilakukan ketika form dikirim. Biasanya berupa URL file di server yang akan memproses data form.

<form action="/action_page.php"> <label for="fname">Nama Depan:</label><br> <input type="text" id="fname" name="fname" value="Budi"><br><br> <input type="submit" value="Kirim"> </form>
⚠ Catatan: Jika atribut action dihilangkan, data akan dikirim ke halaman yang sama (URL saat ini).

🔄 Atribut method

Atribut method menentukan metode HTTP yang digunakan saat mengirimkan data form. Ada dua metode utama: GET dan POST.

Metode GET

<form action="/action_page.php" method="get"> <label for="fname">Nama:</label> <input type="text" id="fname" name="fname"> <input type="submit" value="Kirim"> </form>

Dengan metode GET, data form akan terlihat di URL:

https://www.contoh.com/action_page.php?fname=Budi&lname=Santoso

Metode POST

<form action="/action_page.php" method="post"> <label for="fname">Nama:</label> <input type="text" id="fname" name="fname"> <input type="submit" value="Kirim"> </form>

Dengan metode POST, data form tidak terlihat di URL dan dikirim tersembunyi.

Perbandingan GET vs POST

Aspek GET POST
Visibilitas Data Data tampil di URL Data tersembunyi
Keamanan Kurang aman Lebih aman
Panjang Data Terbatas (~2000 karakter) Tidak terbatas
Bookmark Bisa dibookmark Tidak bisa dibookmark
Cache Bisa di-cache browser Tidak di-cache
Penggunaan Umum Pencarian, filter data Login, upload, data sensitif
💡 Tips: Gunakan POST untuk data sensitif seperti password, data pribadi, atau form yang mengubah data di server. Gunakan GET untuk form pencarian atau filter yang tidak mengubah data.

📈 Cara Form Mengirim Data

Ketika pengguna mengklik tombol Submit, proses berikut terjadi:

  1. Browser mengumpulkan semua nilai dari elemen input dalam form
  2. Data dikodekan (URL encode untuk GET, atau dalam body request untuk POST)
  3. Browser mengirim permintaan HTTP ke URL yang ditentukan di atribut action
  4. Server menerima dan memproses data
  5. Server mengirim respons (halaman baru, pesan konfirmasi, dll.)
⚠ Penting: Setiap elemen input harus memiliki atribut name agar datanya bisa dikirim ke server. Input tanpa atribut name tidak akan disertakan dalam pengiriman data.

📧 Contoh: Form Kontak Lengkap

Berikut adalah contoh form kontak sederhana dengan nama, email, dan tombol kirim:

<form action="/kirim_pesan.php" method="post"> <label for="nama">Nama Lengkap:</label><br> <input type="text" id="nama" name="nama" placeholder="Masukkan nama Anda"><br><br> <label for="email">Alamat Email:</label><br> <input type="email" id="email" name="email" placeholder="contoh@email.com"><br><br> <input type="submit" value="Kirim Pesan"> </form>

✎ Elemen <input>

Elemen <input> adalah elemen form yang paling banyak digunakan. Ia dapat ditampilkan dalam berbagai cara tergantung atribut type-nya.

<input type="text"> <!-- Kolom teks satu baris --> <input type="radio"> <!-- Tombol radio --> <input type="checkbox"> <!-- Kotak centang --> <input type="submit"> <!-- Tombol kirim --> <input type="button"> <!-- Tombol klik -->

🏷 Elemen <label>

Elemen <label> mendefinisikan label untuk beberapa elemen form. Ini sangat berguna untuk pengguna pembaca layar (screen reader) dan meningkatkan aksesibilitas.

Atribut for pada <label> harus sama dengan atribut id pada elemen input yang sesuai agar label "terhubung" ke input tersebut.

<label for="nama">Nama:</label> <input type="text" id="nama" name="nama">
💡 Manfaat label: Saat pengguna mengklik teks label, input yang terhubung otomatis mendapat fokus. Ini sangat membantu untuk radio button dan checkbox.

📋 Ringkasan

  • Elemen <form> membungkus semua elemen input
  • Atribut action menentukan URL tujuan pengiriman data
  • Atribut method menentukan cara pengiriman: GET atau POST
  • Gunakan POST untuk data sensitif dan GET untuk pencarian
  • Setiap input harus punya atribut name agar datanya terkirim
  • Elemen <label> meningkatkan aksesibilitas form
