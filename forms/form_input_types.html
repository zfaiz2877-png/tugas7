HTML Input Types

Atribut type pada elemen <input> menentukan jenis input apa yang akan ditampilkan. HTML menyediakan banyak sekali tipe input untuk berbagai kebutuhan. Berikut adalah semua tipe input yang tersedia.

1. type="text" — Teks Biasa

Tipe default. Menampilkan kolom input teks satu baris.

<label for="nama">Nama:</label> <input type="text" id="nama" name="nama" placeholder="Nama Anda">

2. type="password" — Kata Sandi

Karakter yang diketik akan disembunyikan (ditampilkan sebagai titik/bintang).

<label for="pw">Password:</label> <input type="password" id="pw" name="password" placeholder="Masukkan password">

3. type="submit" & 4. type="reset" — Tombol Aksi

submit mengirim data form ke server. reset mereset semua input ke nilai awal.

<input type="submit" value="Kirim Form"> <input type="reset" value="Reset">

5. type="radio" — Pilihan Tunggal

Memungkinkan pengguna memilih satu pilihan dari beberapa opsi. Radio button dengan nama name yang sama membentuk satu grup.

<p>Pilih jenis kelamin:</p> <input type="radio" id="pria" name="gender" value="pria"> <label for="pria">Pria</label><br> <input type="radio" id="wanita" name="gender" value="wanita"> <label for="wanita">Wanita</label>

6. type="checkbox" — Pilihan Banyak

Memungkinkan pengguna memilih satu atau lebih pilihan dari beberapa opsi.

<p>Hobi kamu:</p> <input type="checkbox" id="membaca" name="hobi" value="membaca"> <label for="membaca"> Membaca</label><br> <input type="checkbox" id="olahraga" name="hobi" value="olahraga" checked> <label for="olahraga"> Olahraga</label><br> <input type="checkbox" id="memasak" name="hobi" value="memasak"> <label for="memasak"> Memasak</label>

7. type="button" — Tombol Kosong

Membuat tombol yang tidak memiliki aksi default. Biasanya dikombinasikan dengan JavaScript.

<input type="button" value="Klik Saya!" onclick="alert('Tombol diklik!')">

8. type="color" HTML5 — Pemilih Warna

Menampilkan antarmuka pemilih warna (color picker).

<label for="warna">Pilih warna favorit:</label> <input type="color" id="warna" name="warna" value="#04AA6D">

9. type="date" HTML5 — Pemilih Tanggal

Menampilkan kalender untuk memilih tanggal. Format: YYYY-MM-DD

<label for="tgl">Tanggal lahir:</label> <input type="date" id="tgl" name="tanggal_lahir" min="1950-01-01" max="2010-12-31">

10. type="datetime-local" HTML5 — Tanggal & Waktu

Memilih tanggal sekaligus waktu (jam dan menit) tanpa zona waktu.

<label for="jadwal">Jadwal meeting:</label> <input type="datetime-local" id="jadwal" name="jadwal">

11. type="email" HTML5 — Alamat Email

Browser akan memvalidasi bahwa nilai yang dimasukkan adalah format email yang valid.

<label for="email">Email:</label> <input type="email" id="email" name="email" placeholder="contoh@domain.com">

12. type="file" — Upload File

Menampilkan tombol untuk memilih file dari perangkat. Gunakan accept untuk membatasi tipe file.

<!-- Hanya gambar --> <input type="file" name="foto" accept="image/*"> <!-- Multiple file --> <input type="file" name="dokumen" multiple accept=".pdf,.doc,.docx">

13. type="hidden" — Input Tersembunyi

Input yang tidak terlihat di halaman, tetapi nilainya tetap dikirim ke server bersama data form.

<input type="hidden" name="user_id" value="12345"> <input type="hidden" name="session_token" value="abc123xyz"> <!-- Pengguna tidak melihat ini, tapi data terkirim -->
⚠ Jangan gunakan hidden field untuk data yang benar-benar rahasia karena bisa dilihat lewat kode sumber halaman.

14. type="image" — Tombol Submit Bergambar

Membuat tombol submit yang menggunakan gambar sebagai tampilannya.

<input type="image" src="submit_btn.png" alt="Submit" width="120" height="40">

15. type="month" HTML5 — Bulan & Tahun

Memilih bulan dan tahun (tanpa hari).

<label for="bulan">Bulan lahir:</label> <input type="month" id="bulan" name="bulan_lahir">

16. type="number" HTML5 — Angka

Input hanya menerima angka. Bisa dikombinasikan dengan min, max, dan step.

<label for="qty">Jumlah (1-10):</label> <input type="number" id="qty" name="qty" min="1" max="10" value="1" step="1">

17. type="range" HTML5 — Slider

Menampilkan slider untuk memilih nilai dalam rentang tertentu.

<label for="vol">Volume:</label> <input type="range" id="vol" name="volume" min="0" max="100" value="50" oninput="document.getElementById('volVal').innerText = this.value"> <span id="volVal">50</span>

18. type="search" HTML5 — Pencarian

Seperti input teks biasa, tetapi browser dapat menampilkan tombol X untuk menghapus teks.

<label for="cari">Cari:</label> <input type="search" id="cari" name="q" placeholder="Ketik kata kunci...">

19. type="tel" HTML5 — Nomor Telepon

Digunakan untuk memasukkan nomor telepon. Di perangkat mobile, keyboard angka akan muncul otomatis.

<label for="telp">No. Telepon:</label> <input type="tel" id="telp" name="telepon" placeholder="08xx-xxxx-xxxx" pattern="[0-9]{4}-[0-9]{4}-[0-9]{4}">

20. type="time" HTML5 — Waktu

Memilih waktu (jam dan menit). Format: HH:MM

<label for="jam">Waktu meeting:</label> <input type="time" id="jam" name="waktu_meeting" min="08:00" max="17:00">

21. type="url" HTML5 — Alamat URL

Browser memvalidasi bahwa nilai yang dimasukkan adalah format URL yang valid (dimulai dengan http:// dll.).

<label for="website">Website:</label> <input type="url" id="website" name="website" placeholder="https://www.contoh.com">

22. type="week" HTML5 — Minggu & Tahun

Memilih minggu dan tahun tertentu.

<label for="minggu">Pilih minggu:</label> <input type="week" id="minggu" name="minggu">
