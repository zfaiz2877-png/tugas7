HTML Form Elements

HTML menyediakan berbagai elemen yang digunakan di dalam form untuk mengumpulkan input dari pengguna. Setiap elemen memiliki fungsi unik. Mari kita pelajari semua elemen form satu per satu.

1. Elemen <input> Paling Sering Digunakan

Elemen <input> adalah elemen form paling serbaguna. Tampilannya bergantung pada nilai atribut type. Ini adalah elemen self-closing (tidak butuh tag penutup).

<!-- Input teks biasa --> <input type="text" name="nama" placeholder="Nama Anda"> <!-- Input password --> <input type="password" name="sandi" placeholder="Password"> <!-- Input email --> <input type="email" name="email" placeholder="Email Anda"> <!-- Tombol submit --> <input type="submit" value="Kirim">
💡 Semua tipe input akan dibahas lengkap di halaman HTML Input Types.

2. Elemen <label>

Elemen <label> mendefinisikan label untuk elemen input. Label meningkatkan aksesibilitas karena saat label diklik, input terkait mendapat fokus. Hubungkan label dengan input menggunakan atribut for dan id yang sama.

<!-- Cara 1: Label terhubung via for + id --> <label for="nama">Nama Lengkap:</label> <input type="text" id="nama" name="nama"> <!-- Cara 2: Input di dalam label --> <label> Nama Lengkap: <input type="text" name="nama"> </label>

3. Elemen <select> & <option>

Elemen <select> membuat dropdown (daftar pilihan). Setiap pilihan di dalam dropdown didefinisikan dengan elemen <option>.

<label for="kota">Pilih Kota:</label> <select id="kota" name="kota"> <option value="jakarta">Jakarta</option> <option value="bandung" selected>Bandung</option> <option value="surabaya">Surabaya</option> <option value="yogyakarta">Yogyakarta</option> <option value="bali">Bali</option> </select> <!-- Pilih banyak dengan multiple --> <select name="hobi" multiple size="3"> <option value="membaca">Membaca</option> <option value="olahraga">Olahraga</option> <option value="memasak">Memasak</option> </select>

Mengelompokkan Pilihan dengan <optgroup>

<select name="buah"> <optgroup label="Buah Tropis"> <option value="mangga">Mangga</option> <option value="durian">Durian</option> </optgroup> <optgroup label="Buah Impor"> <option value="apel">Apel</option> <option value="anggur">Anggur</option> </optgroup> </select>

4. Elemen <textarea>

Elemen <textarea> mendefinisikan kolom input teks multi-baris. Pengguna dapat mengetik banyak baris teks di dalamnya. Gunakan atribut rows dan cols untuk mengatur ukurannya.

<label for="pesan">Pesan Anda:</label> <textarea id="pesan" name="pesan" rows="5" cols="40" placeholder="Tulis pesan di sini..."> </textarea>

5. Elemen <button>

Elemen <button> mendefinisikan tombol yang dapat diklik. Berbeda dengan <input type="button">, elemen <button> dapat memiliki konten HTML di dalamnya (teks, gambar, ikon, dll.).

<!-- Tombol submit (default jika di dalam form) --> <button type="submit">📥 Kirim Form</button> <!-- Tombol reset --> <button type="reset">🔄 Reset</button> <!-- Tombol biasa (untuk JavaScript) --> <button type="button" onclick="alert('Halo!')"> 👋 Klik Saya </button>
⚠ Selalu tentukan atribut type pada <button>. Browser yang berbeda dapat menggunakan tipe default yang berbeda!

6. Elemen <fieldset> & <legend>

Elemen <fieldset> digunakan untuk mengelompokkan elemen form yang berkaitan dan menggambar kotak di sekelilingnya. Elemen <legend> memberikan judul/keterangan untuk fieldset.

<form action="/daftar.php" method="post"> <fieldset> <legend>Informasi Pribadi</legend> <label for="fn">Nama Depan:</label> <input type="text" id="fn" name="nama_depan"><br><br> <label for="ln">Nama Belakang:</label> <input type="text" id="ln" name="nama_belakang"><br><br> </fieldset> <fieldset> <legend>Informasi Akun</legend> <label for="em">Email:</label> <input type="email" id="em" name="email"><br><br> <label for="pw">Password:</label> <input type="password" id="pw" name="password"> </fieldset> <input type="submit" value="Daftar"> </form>

7. Elemen <datalist> HTML5

Elemen <datalist> menyediakan daftar saran (autocomplete) yang muncul saat pengguna mengetik di kolom input. Pengguna tetap bisa mengetik nilai sendiri. Hubungkan <input> ke <datalist> menggunakan atribut list dan id yang sama.

<label for="browser">Browser favorit:</label> <input list="browsers" id="browser" name="browser" placeholder="Ketik atau pilih..."> <datalist id="browsers"> <option value="Chrome"> <option value="Firefox"> <option value="Safari"> <option value="Opera"> <option value="Microsoft Edge"> </datalist>
💡 Coba ketik huruf "C" atau "F" di kolom di atas untuk melihat saran muncul!

8. Elemen <output> HTML5

Elemen <output> digunakan untuk menampilkan hasil perhitungan atau hasil dari operasi JavaScript. Sangat berguna dikombinasikan dengan input range atau operasi matematis.

<form oninput="hasil.value = parseInt(a.value) + parseInt(b.value)"> <label>Angka 1: <input type="number" id="a" name="a" value="10"></label> + <label>Angka 2: <input type="number" id="b" name="b" value="20"></label> = <output name="hasil" for="a b">30</output> </form>
+ = 30
