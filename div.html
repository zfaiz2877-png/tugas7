HTML <div> Element

Elemen <div> adalah salah satu elemen paling penting dan sering digunakan dalam HTML. Ia berfungsi sebagai container (wadah) blok yang dapat mengelompokkan elemen-elemen HTML lainnya untuk keperluan penataan (layout) dan pemberian gaya (styling).

📌 Catatan: <div> singkatan dari "Division" (divisi/bagian). Elemen ini tidak memiliki arti semantik khusus — ia hanya sebuah wadah kosong yang dapat diisi dengan konten apapun.

1. Apa itu Elemen <div>?

Elemen <div> adalah elemen block-level, artinya ia selalu memulai baris baru dan mengambil seluruh lebar yang tersedia (dari kiri ke kanan). Ini berbeda dengan elemen inline seperti <span> yang hanya mengambil lebar sesuai isinya.

Sintaks Dasar

<div> <!-- Konten apapun bisa dimasukkan di sini --> <h2>Judul dalam Div</h2> <p>Paragraf dalam Div.</p> </div>

Contoh Sederhana

<!DOCTYPE html> <html> <body> <div> <h2>Kota Jakarta</h2> <p>Jakarta adalah ibu kota Indonesia.</p> <p>Penduduknya sangat banyak.</p> </div> </body> </html>
Hasil:

Kota Jakarta

Jakarta adalah ibu kota Indonesia.

Penduduknya sangat banyak.

↑ Seluruh konten di atas berada di dalam satu <div>

2. <div> sebagai Elemen Block-Level

Karena <div> adalah elemen block-level, ia akan menempati seluruh baris sendiri. Dua buah <div> berurutan akan tampil vertikal (satu di atas yang lain), bukan bersebelahan.

<div style="background: #c9e8d4; padding: 10px;">Div Pertama</div> <div style="background: #ffeeba; padding: 10px;">Div Kedua</div> <div style="background: #d0e8ff; padding: 10px;">Div Ketiga</div>
Hasil:

Div Pertama
Div Kedua
Div Ketiga

3. Mengelompokkan Elemen dengan <div>

Salah satu kegunaan utama <div> adalah mengelompokkan elemen-elemen HTML agar dapat diberi gaya atau dimanipulasi secara bersamaan. Bayangkan <div> sebagai sebuah kotak yang mewadahi beberapa elemen sekaligus.

<!-- Tanpa div - sulit diatur --> <h2>Produk A</h2> <p>Harga: Rp 50.000</p> <img src="produkA.jpg" alt="Produk A"> <h2>Produk B</h2> <p>Harga: Rp 75.000</p> <img src="produkB.jpg" alt="Produk B"> <!-- Dengan div - lebih terorganisir --> <div class="kartu-produk"> <h2>Produk A</h2> <p>Harga: Rp 50.000</p> <img src="produkA.jpg" alt="Produk A"> </div> <div class="kartu-produk"> <h2>Produk B</h2> <p>Harga: Rp 75.000</p> <img src="produkB.jpg" alt="Produk B"> </div>

4. Menggunakan <div> dengan Atribut class

Dengan memberikan atribut class pada <div>, kita bisa menargetkan elemen tersebut dari CSS dan memberikan gaya yang konsisten pada banyak elemen sekaligus.

<!DOCTYPE html> <html> <head> <style> .kota { background-color: #04AA6D; color: white; margin: 10px; padding: 15px; border-radius: 8px; } </style> </head> <body> <div class="kota"> <h2>Jakarta</h2> <p>Ibu kota Indonesia.</p> </div> <div class="kota"> <h2>Surabaya</h2> <p>Kota terbesar kedua di Indonesia.</p> </div> <div class="kota"> <h2>Bandung</h2> <p>Dikenal sebagai Kota Kembang.</p> </div> </body> </html>
Hasil:

Jakarta

Ibu kota Indonesia.

Surabaya

Kota terbesar kedua di Indonesia.

Bandung

Dikenal sebagai Kota Kembang.

5. Menggunakan <div> dengan Atribut id

Atribut id digunakan untuk memberi identitas unik pada sebuah <div>. Tidak boleh ada dua elemen dengan id yang sama dalam satu halaman. Dengan id, kita bisa menargetkan div tertentu menggunakan selector #namaId di CSS.

<style> #header { background: #333; color: white; padding: 20px; } #konten { padding: 20px; background: #f9f9f9; } #footer { background: #04AA6D; color: white; padding: 15px; text-align: center; } </style> <div id="header"> <h1>Website Saya</h1> </div> <div id="konten"> <p>Ini adalah isi halaman utama.</p> </div> <div id="footer"> <p>© 2024 Website Saya</p> </div>
Hasil:

Website Saya

Ini adalah isi halaman utama.

© 2024 Website Saya

6. <div> untuk Layout Halaman Web

Salah satu penggunaan paling umum <div> adalah untuk membuat tata letak (layout) halaman web. Dengan menggabungkan <div> dan CSS (terutama Flexbox atau Grid), kita bisa membuat halaman web yang profesional dan responsif.

Contoh Layout dengan Flexbox

<style> .container { display: flex; gap: 20px; } .sidebar { width: 200px; background: #0382a4; color: white; padding: 15px; } .main-content { flex: 1; background: #5c85d6; color: white; padding: 15px; } </style> <div class="container"> <div class="sidebar"> <h3>Sidebar</h3> <p>Menu navigasi</p> </div> <div class="main-content"> <h2>Konten Utama</h2> <p>Isi halaman di sini.</p> </div> </div>
Hasil:

Sidebar

Menu navigasi

Konten Utama

Isi halaman di sini.

7. Layout Lengkap Halaman Web

Berikut contoh struktur HTML yang lengkap menggunakan <div> untuk membangun layout halaman web:

<!DOCTYPE html> <html> <head> <style> * { box-sizing: border-box; margin: 0; padding: 0; } body { font-family: Arial, sans-serif; } #header { background: #04AA6D; color: white; text-align: center; padding: 20px; } #navbar { background: #333; overflow: hidden; } #navbar a { color: white; float: left; padding: 14px 16px; text-decoration: none; } #navbar a:hover { background: #04AA6D; } #wrapper { display: flex; min-height: 300px; } #sidebar { width: 200px; background: #f4f4f4; padding: 20px; } #content { flex: 1; padding: 20px; } #footer { background: #333; color: white; text-align: center; padding: 15px; } </style> </head> <body> <div id="header"> <h1>Website Saya</h1> </div> <div id="navbar"> <a href="#">Beranda</a> <a href="#">Tentang</a> <a href="#">Kontak</a> </div> <div id="wrapper"> <div id="sidebar"> <h3>Kategori</h3> <ul> <li>Teknologi</li> <li>Bisnis</li> <li>Kesehatan</li> </ul> </div> <div id="content"> <h2>Artikel Terbaru</h2> <p>Selamat datang di website saya!</p> </div> </div> <div id="footer"> <p>© 2024 Website Saya. Semua hak dilindungi.</p> </div> </body> </html>

8. Perbedaan <div> dan <span>

Sering kali orang bingung antara <div> dan <span>. Perbedaan utamanya adalah pada tipe display-nya:

Fitur <div> <span>
Tipe Block-level Inline
Baris baru Ya, selalu mulai baris baru Tidak, mengalir dalam teks
Lebar Seluruh lebar yang tersedia Hanya selebar isinya
Kegunaan Mengelompokkan elemen blok Mengelompokkan teks/inline
Contoh penggunaan Bagian halaman, card, panel Warna teks tertentu, highlight kata
<!-- Contoh perbedaan div dan span --> <div style="background: #ffeeba; padding: 10px;"> Ini adalah DIV - mengambil satu baris penuh </div> <p> Ini teks biasa dengan <span style="background: #c8e6c9; padding: 2px 6px;">span di tengah</span> yang mengalir dalam teks. </p>
Hasil:

Ini adalah DIV - mengambil satu baris penuh

Ini teks biasa dengan span di tengah yang mengalir dalam teks.

9. Best Practices Penggunaan <div>

💡 Tips Terbaik:
  • Gunakan atribut class atau id untuk memudahkan styling dan scripting.
  • Jangan terlalu banyak menggunakan <div> yang tidak perlu ("div-itis").
  • Untuk elemen dengan makna semantik, gunakan tag HTML5 seperti <header>, <nav>, <main>, <footer>, <section>, dan <article>.
  • Gunakan <div> ketika tidak ada elemen semantik yang cocok.
  • Beri nama class/id yang deskriptif dan bermakna.

Perbandingan: div vs Elemen Semantik HTML5

<!-- Cara lama: hanya menggunakan div --> <div id="header">...</div> <div id="nav">...</div> <div id="main">...</div> <div id="footer">...</div> <!-- Cara modern: gunakan elemen semantik HTML5 --> <header>...</header> <nav>...</nav> <main>...</main> <footer>...</footer> <!-- div tetap berguna untuk pengelompokan non-semantik --> <div class="kartu"> <div class="kartu-gambar"><img src="foto.jpg"></div> <div class="kartu-isi"> <h3>Judul Kartu</h3> <p>Deskripsi kartu.</p> </div> </div>

Ringkasan

Konsep Penjelasan
<div> Elemen container block-level tanpa makna semantik
Block-level Selalu mulai baris baru, mengambil seluruh lebar
Atribut class Untuk styling banyak div sekaligus (selector .namaKelas)
Atribut id Untuk styling satu div unik (selector #namaId)
Layout Gunakan div + CSS Flexbox/Grid untuk tata letak halaman
vs <span> div = blok, span = inline
