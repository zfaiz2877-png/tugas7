HTML Page Title (Judul Halaman)

Judul halaman web didefinisikan menggunakan elemen <title> di dalam bagian <head> dokumen HTML. Judul ini sangat penting karena muncul di berbagai tempat dan mempengaruhi SEO (Search Engine Optimization) website Anda.

1. Elemen <title>

Elemen <title> mendefinisikan judul dokumen HTML. Judul ini tidak ditampilkan di dalam konten halaman, namun muncul di:

  • Tab browser
  • Hasil mesin pencari (Google, Bing, dll.)
  • Daftar bookmark / favorit
  • Toolbar browser
<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <!-- Elemen title --> <title>Belajar HTML - Tutorial Lengkap Bahasa Indonesia</title> </head> <body> <h1>Selamat Datang!</h1> <p>Ini adalah konten halaman.</p> </body> </html>
📌 Wajib Ada: Elemen <title> adalah elemen yang wajib ada di setiap dokumen HTML yang valid. Tanpa judul, dokumen HTML Anda tidak memenuhi standar W3C.

2. Title di Tab Browser

Judul yang Anda tentukan pada <title> akan langsung tampil di tab browser:

Simulasi tampilan tab browser:
W
Belajar HTML - Tutorial... ✕
Tab lainnya
🔒 www.contohdomain.com/belajar-html.html

3. Title di Hasil Pencarian (SEO)

Mesin pencari seperti Google menggunakan elemen <title> sebagai judul utama dalam hasil pencarian. Judul yang baik akan meningkatkan click-through rate (CTR) dari hasil pencarian.

Simulasi tampilan di hasil Google:
Belajar HTML - Tutorial Lengkap Bahasa Indonesia
www.contohdomain.com › html › belajar-html
Pelajari HTML dari dasar hingga mahir dengan tutorial lengkap dalam Bahasa Indonesia. Cocok untuk pemula. Tersedia contoh kode dan penjelasan mendalam.
Tutorial CSS untuk Pemula | Panduan Lengkap
www.situswebsaya.com › css › tutorial
Pelajari cara membuat website yang indah dengan CSS. Tutorial ini mencakup selector, properti, dan layout CSS modern.
💡 SEO Tip: Google umumnya menampilkan 50–60 karakter pertama dari judul halaman. Jika judul terlalu panjang, akan dipotong dengan tanda "...".

4. Title di Bookmark/Favorit

Saat pengguna menyimpan halaman ke favorit browser, nama yang digunakan secara otomatis diambil dari elemen <title>:

5. Panduan Menulis Title yang Baik

✅ Title yang Baik

  • Deskriptif dan relevan
  • Mengandung kata kunci penting
  • Panjang 50–60 karakter
  • Unik untuk setiap halaman
  • Mudah dibaca manusia

❌ Title yang Buruk

  • Terlalu umum: "Halaman" atau "Untitled"
  • Terlalu panjang (lebih dari 70 karakter)
  • Semua halaman judulnya sama
  • Berisi kata kunci berulang (keyword stuffing)
  • Tidak relevan dengan isi halaman

Contoh perbandingan:

<!-- ❌ Buruk: Tidak deskriptif --> <title>Halaman 1</title> <!-- ❌ Buruk: Terlalu panjang dan berulang --> <title>HTML HTML Tutorial HTML Belajar HTML HTML Dasar HTML Pemula HTML 2024</title> <!-- ✅ Baik: Deskriptif, singkat, mengandung kata kunci --> <title>Belajar HTML untuk Pemula - Panduan Lengkap 2024</title> <!-- ✅ Baik: Format nama brand --> <title>Tutorial CSS | Toko Buku Online TokoBuku.com</title>

7. Pentingnya Title untuk SEO

Elemen <title> adalah salah satu faktor SEO on-page yang paling penting. Berikut alasannya:

  • 🔍 Sinyal Relevansi — Mesin pencari menggunakan judul untuk memahami topik halaman dan menentukan untuk kata kunci apa halaman tersebut relevan.
  • 📈 Click-Through Rate (CTR) — Judul yang menarik mendorong lebih banyak orang mengklik hasil pencarian Anda.
  • 🎯 Pencocokan Intent — Judul yang sesuai dengan niat pencarian pengguna meningkatkan kemungkinan halaman Anda muncul di posisi teratas.
  • 🔗 Link Anchor Text — Saat orang menautkan halaman Anda tanpa anchor text khusus, browser sering menggunakan judul halaman sebagai teks tautan.

8. Title vs H1: Apa Bedanya?

Aspek <title> <h1>
Lokasi Di dalam <head> Di dalam <body>
Tampil di halaman ❌ Tidak terlihat di halaman ✅ Terlihat sebagai heading utama
Tampil di browser ✅ Di tab browser ❌ Tidak ada di tab
Mesin pencari ✅ Judul di hasil pencarian Mempengaruhi relevansi konten
Jumlah per halaman Tepat 1 Idealnya 1
📌 Best Practice: Meskipun <title> dan <h1> bisa berbeda, sebaiknya keduanya saling berhubungan dan konsisten. Biasanya judul di <title> sedikit lebih panjang karena menyertakan nama brand/situs.

9. Contoh Lengkap dengan Title Optimal

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- Judul halaman (muncul di tab & hasil pencarian) --> <title>Tutorial HTML untuk Pemula | BelajarWeb.id</title> <!-- Meta description (muncul di hasil pencarian) --> <meta name="description" content="Pelajari HTML dari nol hingga mahir dengan tutorial lengkap dalam Bahasa Indonesia. Cocok untuk pemula."> <!-- Favicon --> <link rel="icon" type="image/x-icon" href="favicon.ico"> </head> <body> <h1>Tutorial HTML untuk Pemula</h1> <p>Selamat datang di panduan belajar HTML...</p> </body> </html>
