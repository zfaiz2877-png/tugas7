HTML Colors (Warna HTML)

Warna dalam HTML dapat ditentukan dengan berbagai cara: menggunakan nama warna yang telah ditentukan, nilai RGB, nilai HEX, atau nilai HSL. HTML mendukung lebih dari 140 nama warna standar.

1. Nama Warna (Color Names)

HTML mendukung 140+ nama warna yang sudah didefinisikan secara standar. Kamu cukup menuliskan namanya dalam bahasa Inggris.

<h1 style="background-color: Tomato;">Tomato</h1> <h1 style="background-color: DodgerBlue;">DodgerBlue</h1> <h1 style="background-color: MediumSeaGreen;">MediumSeaGreen</h1> <h1 style="background-color: SlateBlue;">SlateBlue</h1>

2. Nilai RGB (Red, Green, Blue)

Nilai warna RGB mewakili kombinasi tiga komponen warna: Merah (Red), Hijau (Green), dan Biru (Blue). Setiap komponen memiliki nilai antara 0 sampai 255.

Sintaks: rgb(red, green, blue)

<!-- rgb(red, green, blue) --> <p style="background-color: rgb(255, 0, 0);">Merah Murni</p> <p style="background-color: rgb(0, 255, 0);">Hijau Murni</p> <p style="background-color: rgb(0, 0, 255);">Biru Murni</p> <p style="background-color: rgb(0, 0, 0);">Hitam (semua 0)</p> <p style="background-color: rgb(255, 255, 255);">Putih (semua 255)</p> <p style="background-color: rgb(128, 128, 128);">Abu-abu (semua sama)</p>

RGBA — RGB dengan Opacity (Transparansi)

RGBA menambahkan parameter keempat yaitu Alpha — yang menentukan tingkat keburaman/transparansi warna. Nilai alpha berkisar dari 0.0 (sepenuhnya transparan) hingga 1.0 (sepenuhnya buram).

<p style="background-color: rgba(255, 0, 0, 0.2);">rgba(255,0,0, 0.2) — 20% buram</p> <p style="background-color: rgba(255, 0, 0, 0.5);">rgba(255,0,0, 0.5) — 50% buram</p> <p style="background-color: rgba(255, 0, 0, 0.8);">rgba(255,0,0, 0.8) — 80% buram</p> <p style="background-color: rgba(255, 0, 0, 1.0);">rgba(255,0,0, 1.0) — 100% buram</p>
Hasil (perhatikan tingkat transparansi):
rgba(255, 0, 0, 0.2) — 20% buram
rgba(255, 0, 0, 0.5) — 50% buram
rgba(255, 0, 0, 0.8) — 80% buram
rgba(255, 0, 0, 1.0) — 100% buram

3. Nilai HEX (Hexadecimal)

Nilai warna heksadesimal (HEX) adalah cara lain yang sangat populer untuk menentukan warna dalam HTML/CSS. Warna HEX ditentukan dengan format: #RRGGBB

  • RR — komponen merah (00 sampai FF)
  • GG — komponen hijau (00 sampai FF)
  • BB — komponen biru (00 sampai FF)

Nilai 00 setara dengan 0 dalam desimal, dan FF setara dengan 255 dalam desimal.

<!-- #RRGGBB --> <p style="background-color: #FF0000;">#FF0000 — Merah</p> <p style="background-color: #00FF00;">#00FF00 — Hijau</p> <p style="background-color: #0000FF;">#0000FF — Biru</p> <p style="background-color: #04AA6D;">#04AA6D — Hijau W3Schools</p> <p style="background-color: #FF6347;">#FF6347 — Tomato</p>

Singkatan HEX 3-Digit

Ketika kedua digit pada setiap komponen sama, kamu bisa menggunakan bentuk singkat 3 digit:

#FF0000 = #F00 (Merah) #00FF00 = #0F0 (Hijau) #0000FF = #00F (Biru) #FFFF00 = #FF0 (Kuning) #000000 = #000 (Hitam) #FFFFFF = #FFF (Putih)

4. Nilai HSL (Hue, Saturation, Lightness)

HSL adalah singkatan dari Hue (rona), Saturation (saturasi/kejenuhan), dan Lightness (kecerahan).

Sintaks: hsl(hue, saturation, lightness)

  • Hue — derajat pada roda warna (0 sampai 360). 0 = merah, 120 = hijau, 240 = biru.
  • Saturation — persentase (0% = abu-abu, 100% = warna penuh)
  • Lightness — persentase (0% = hitam, 100% = putih, 50% = normal)

Roda Warna (Hue 0° - 360°):

← 0° (Merah) ——————————————— 360° (Merah) →

<p style="background-color: hsl(0, 100%, 50%);">hsl(0, 100%, 50%) — Merah</p> <p style="background-color: hsl(120, 100%, 50%);">hsl(120, 100%, 50%) — Hijau</p> <p style="background-color: hsl(240, 100%, 50%);">hsl(240, 100%, 50%) — Biru</p> <p style="background-color: hsl(39, 100%, 50%);">hsl(39, 100%, 50%) — Oranye</p> <p style="background-color: hsl(300, 76%, 72%);">hsl(300, 76%, 72%) — Violet</p>
Hasil:
hsl(0, 100%, 50%) — Merah
hsl(120, 100%, 50%) — Hijau
hsl(240, 100%, 50%) — Biru
hsl(39, 100%, 50%) — Oranye
hsl(300, 76%, 72%) — Violet

HSLA — HSL dengan Opacity:

<p style="background-color: hsla(0, 100%, 50%, 0.3);">hsla — 30% buram</p> <p style="background-color: hsla(0, 100%, 50%, 0.6);">hsla — 60% buram</p> <p style="background-color: hsla(0, 100%, 50%, 1.0);">hsla — 100% buram</p>

5. Perbandingan Semua Format Warna

Format Sintaks Contoh (Merah) Keterangan
Nama Warna NamaWarna Red 140+ nama tersedia, mudah diingat
RGB rgb(R, G, B) rgb(255,0,0) Nilai 0-255 untuk setiap channel
RGBA rgba(R, G, B, A) rgba(255,0,0,0.7) Sama dengan RGB + transparansi (0-1)
HEX #RRGGBB #FF0000 Hexadecimal, paling populer di web
HSL hsl(H, S%, L%) hsl(0,100%,50%) Intuitif untuk mengatur shade/tint
HSLA hsla(H, S%, L%, A) hsla(0,100%,50%,0.7) Sama dengan HSL + transparansi (0-1)
💡 Tips Memilih Format Warna:
  • Gunakan nama warna untuk prototyping cepat atau warna-warna umum.
  • Gunakan HEX ketika bekerja dengan design tools (Figma, Photoshop).
  • Gunakan RGB/RGBA ketika perlu mengatur transparansi dengan nilai numerik.
  • Gunakan HSL ketika ingin membuat variasi warna (lebih gelap/terang) secara intuitif.
📌 Warna Teks vs Warna Latar:
  • Gunakan properti color untuk mengatur warna teks.
  • Gunakan properti background-color untuk mengatur warna latar belakang.
