🖱️ HTML Drag and Drop API

HTML Drag and Drop API memungkinkan pengguna untuk memindahkan elemen halaman web dengan cara menarik (drag) dan melepaskannya (drop) ke posisi atau area lain. Fitur ini sangat umum digunakan dalam kanban board, file manager, dan pengaturan ulang urutan daftar.

✅ Dukungan Browser: Drag and Drop API didukung oleh semua browser modern: Chrome, Firefox, Edge, Safari, dan Opera.

1. Membuat Elemen yang Bisa Di-Drag

Tambahkan atribut draggable="true" pada elemen HTML untuk membuatnya bisa di-drag:

<img id="gambar1" src="foto.jpg" draggable="true" ondragstart="drag(event)"> <div id="kotak1" draggable="true" ondragstart="drag(event)"> Saya bisa di-drag! </div>

2. Alur Event Drag and Drop

Berikut urutan event yang terjadi dalam proses drag and drop:

1

ondragstart — Dipicu ketika pengguna mulai men-drag elemen. Simpan data elemen menggunakan event.dataTransfer.setData().

2

ondrag — Dipicu terus-menerus selama elemen sedang di-drag di atas halaman.

3

ondragenter — Dipicu ketika elemen yang di-drag memasuki area drop target.

4

ondragover — Dipicu terus-menerus saat elemen berada di atas drop target. Harus memanggil event.preventDefault() agar drop diizinkan.

5

ondragleave — Dipicu ketika elemen yang di-drag meninggalkan area drop target.

6

ondrop — Dipicu ketika elemen dilepaskan di drop target. Ambil data menggunakan event.dataTransfer.getData().

7

ondragend — Dipicu ketika operasi drag selesai (baik berhasil di-drop maupun dibatalkan).

3. Tabel Referensi Event

EventDipicu PadaKeterangan
ondragstartElemen yang di-dragSaat drag dimulai
ondragElemen yang di-dragSelama proses drag berlangsung
ondragenterDrop targetSaat elemen memasuki area target
ondragoverDrop targetSaat elemen berada di atas target
ondragleaveDrop targetSaat elemen meninggalkan area target
ondropDrop targetSaat elemen dilepaskan di target
ondragendElemen yang di-dragSaat operasi drag selesai

4. Contoh Kode Lengkap

<!-- HTML --> <div id="sumber"> <div id="item1" draggable="true" ondragstart="drag(event)"> 📦 Elemen 1 </div> </div> <div id="target" ondragover="allowDrop(event)" ondrop="drop(event)"> Lepaskan di sini </div> <!-- JavaScript --> function drag(event) { // Simpan ID elemen yang di-drag event.dataTransfer.setData("text/plain", event.target.id); event.dataTransfer.effectAllowed = "move"; } function allowDrop(event) { // WAJIB dipanggil agar drop diizinkan event.preventDefault(); event.dataTransfer.dropEffect = "move"; } function drop(event) { event.preventDefault(); const id = event.dataTransfer.getData("text/plain"); const elemen = document.getElementById(id); event.target.appendChild(elemen); }

5. Objek DataTransfer

Objek event.dataTransfer digunakan untuk membawa data selama proses drag:

Metode / PropertiKeterangan
setData(format, data)Menyimpan data dengan format tertentu (misal: "text/plain")
getData(format)Mengambil data yang telah disimpan
clearData()Menghapus semua data yang tersimpan
effectAllowedMenentukan efek yang diizinkan: "copy", "move", "link", "none"
dropEffectEfek drop yang digunakan: "copy", "move", "link", "none"
filesFileList untuk drag file dari OS
