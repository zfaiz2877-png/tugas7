💾 HTML Web Storage API

HTML Web Storage API memungkinkan aplikasi web menyimpan data secara lokal di browser pengguna. Berbeda dengan cookies, Web Storage lebih aman, lebih cepat, lebih mudah digunakan, dan dapat menyimpan data dalam jumlah yang lebih besar (umumnya 5–10 MB per origin).

💡 Keunggulan vs Cookies: Web Storage tidak dikirim ke server pada setiap request HTTP (tidak seperti cookies), sehingga lebih efisien dan aman untuk menyimpan data sisi klien.

1. Dua Jenis Web Storage

🗄️ localStorage

  • Data tidak hilang saat browser ditutup
  • Data bertahan tanpa batas waktu (permanen sampai dihapus manual)
  • Dapat diakses dari semua tab dan jendela browser pada domain yang sama
  • Kapasitas: ~5–10 MB
  • Cocok untuk: preferensi pengguna, tema, keranjang belanja

🕐 sessionStorage

  • Data hilang ketika tab atau browser ditutup
  • Hanya berlaku selama satu sesi browser
  • Terisolasi per tab (tab lain tidak bisa mengakses)
  • Kapasitas: ~5–10 MB
  • Cocok untuk: data form sementara, status navigasi, token sesi

2. Metode Web Storage

Metode / PropertiKeteranganContoh
setItem(key, value) Menyimpan data dengan kunci tertentu localStorage.setItem("nama", "Budi")
getItem(key) Mengambil data berdasarkan kunci localStorage.getItem("nama")
removeItem(key) Menghapus satu item berdasarkan kunci localStorage.removeItem("nama")
clear() Menghapus semua item dalam storage localStorage.clear()
key(index) Mendapatkan nama kunci berdasarkan indeks localStorage.key(0)
length Jumlah item yang tersimpan localStorage.length

3. Memeriksa Dukungan Browser

if (typeof(Storage) !== "undefined") { console.log("Web Storage didukung! ✅"); } else { console.log("Browser tidak mendukung Web Storage ❌"); }

4. Contoh localStorage

// Menyimpan data localStorage.setItem("username", "Budi Santoso"); localStorage.setItem("tema", "gelap"); localStorage.setItem("score", 1500); // Mengambil data let nama = localStorage.getItem("username"); // "Budi Santoso" let tema = localStorage.getItem("tema"); // "gelap" // Menghapus satu item localStorage.removeItem("tema"); // Menghapus semua item localStorage.clear(); // Menyimpan objek (harus di-JSON stringify) const user = { nama: "Budi", umur: 25, kota: "Jakarta" }; localStorage.setItem("user", JSON.stringify(user)); // Membaca objek (harus di-JSON parse) const userObj = JSON.parse(localStorage.getItem("user")); console.log(userObj.nama); // "Budi"

5. Contoh sessionStorage

// Penggunaan sessionStorage identik dengan localStorage sessionStorage.setItem("token", "abc123xyz"); sessionStorage.setItem("halaman_terakhir", "produk/detail/42"); let token = sessionStorage.getItem("token"); console.log(token); // "abc123xyz" // Data akan hilang saat tab ditutup! sessionStorage.removeItem("token"); sessionStorage.clear();

6. Event Storage

Event storage dipicu ketika data Web Storage berubah dari tab lain (khusus localStorage):

// Dengarkan perubahan storage dari tab lain window.addEventListener("storage", function(event) { console.log("Kunci berubah:", event.key); console.log("Nilai lama:", event.oldValue); console.log("Nilai baru:", event.newValue); console.log("URL halaman:", event.url); });
