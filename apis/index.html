HTML APIs

Submateri lengkap tentang HTML Application Programming Interfaces

HTML API (Application Programming Interface) adalah sekumpulan antarmuka pemrograman yang disediakan oleh browser modern untuk memungkinkan halaman web berinteraksi dengan perangkat keras, sistem operasi, dan layanan browser secara langsung menggunakan JavaScript. Dengan HTML APIs, pengembang web dapat membuat aplikasi yang lebih powerful, interaktif, dan mendekati kemampuan aplikasi native.

📍 API #1

HTML Geolocation API

Pelajari cara mendapatkan lokasi geografis pengguna (latitude & longitude) menggunakan navigator.geolocation. Termasuk watch position dan penanganan error.

🖱️ API #2

HTML Drag and Drop API

Pelajari cara membuat elemen yang dapat di-drag dan di-drop menggunakan atribut draggable dan event handler ondragstart, ondragover, serta ondrop.

💾 API #3

HTML Web Storage API

Pelajari penyimpanan data di browser menggunakan localStorage dan sessionStorage. Pahami perbedaan keduanya beserta metode setItem, getItem, removeItem, dan clear.

⚙️ API #4

HTML Web Workers API

Pelajari cara menjalankan skrip JavaScript di thread latar belakang menggunakan Web Workers, sehingga UI tidak membeku saat menjalankan proses berat.

📡 API #5

HTML SSE (Server-Sent Events)

Pelajari cara menerima data secara real-time dari server menggunakan EventSource. Pahami perbedaannya dengan WebSocket dan kapan harus menggunakannya.
