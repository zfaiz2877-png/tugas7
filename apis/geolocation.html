📍 HTML Geolocation API

HTML Geolocation API memungkinkan halaman web untuk mendapatkan informasi lokasi geografis pengguna, seperti latitude (garis lintang) dan longitude (garis bujur). API ini sangat berguna untuk aplikasi berbasis lokasi seperti peta, pencarian tempat terdekat, atau cuaca berdasarkan lokasi.

⚠️ Privasi Pengguna: Browser akan selalu meminta izin kepada pengguna sebelum mengakses lokasi mereka. Pengguna berhak menolak permintaan ini. Geolocation hanya bekerja di halaman yang menggunakan HTTPS (atau localhost saat development).

1. Memeriksa Dukungan Browser

Sebelum menggunakan Geolocation, selalu periksa apakah browser mendukungnya:

if ("geolocation" in navigator) { // Browser mendukung Geolocation console.log("Geolocation tersedia!"); } else { // Browser tidak mendukung Geolocation console.log("Geolocation tidak didukung oleh browser ini."); }

2. Mendapatkan Posisi Saat Ini

Gunakan metode getCurrentPosition() untuk mendapatkan lokasi pengguna sekali saja:

navigator.geolocation.getCurrentPosition(successCallback, errorCallback, options); // Contoh lengkap: navigator.geolocation.getCurrentPosition( function(position) { let lat = position.coords.latitude; let lon = position.coords.longitude; console.log("Latitude: " + lat); console.log("Longitude: " + lon); }, function(error) { console.log("Error: " + error.message); } );

Properti Objek Position

PropertiTipeKeterangan
coords.latitudeNumberGaris lintang dalam derajat desimal
coords.longitudeNumberGaris bujur dalam derajat desimal
coords.accuracyNumberAkurasi posisi dalam meter
coords.altitudeNumber/nullKetinggian di atas permukaan laut (meter)
coords.altitudeAccuracyNumber/nullAkurasi ketinggian dalam meter
coords.headingNumber/nullArah pergerakan (derajat dari utara)
coords.speedNumber/nullKecepatan pergerakan (meter/detik)
timestampNumberWaktu pengambilan posisi (Unix timestamp)

3. Memantau Posisi (Watch Position)

Gunakan watchPosition() untuk terus memantau pergerakan pengguna secara real-time. Metode ini terus memanggil callback setiap kali posisi berubah:

// Mulai memantau lokasi let watchId = navigator.geolocation.watchPosition( function(position) { let lat = position.coords.latitude; let lon = position.coords.longitude; document.getElementById("live-location").innerHTML = "Lat: " + lat + ", Lon: " + lon; }, function(error) { console.log(error.message); } ); // Menghentikan pemantauan navigator.geolocation.clearWatch(watchId);

4. Menangani Error

Objek error yang diterima di callback error memiliki properti code dan message:

function handleError(error) { switch(error.code) { case error.PERMISSION_DENIED: alert("Pengguna menolak permintaan lokasi."); break; case error.POSITION_UNAVAILABLE: alert("Informasi lokasi tidak tersedia."); break; case error.TIMEOUT: alert("Waktu permintaan lokasi habis."); break; default: alert("Terjadi error yang tidak diketahui."); break; } }

Kode Error Geolocation

KodeKonstantaKeterangan
1PERMISSION_DENIEDPengguna menolak izin akses lokasi
2POSITION_UNAVAILABLELokasi tidak dapat ditentukan
3TIMEOUTWaktu mendapatkan lokasi habis

5. Opsi Tambahan (PositionOptions)

Anda dapat menyetel opsi saat memanggil getCurrentPosition() atau watchPosition():

const options = { enableHighAccuracy: true, // Gunakan GPS jika tersedia (baterai lebih boros) timeout: 10000, // Batas waktu 10 detik (milidetik) maximumAge: 0 // Jangan gunakan data cache (0 = selalu segar) }; navigator.geolocation.getCurrentPosition(onSuccess, onError, options);
