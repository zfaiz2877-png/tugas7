HTML Images (Gambar)

Gambar membuat halaman web menjadi lebih menarik dan informatif. Dalam HTML, gambar disisipkan menggunakan tag <img>. Tag ini merupakan tag kosong (void element), artinya tidak memiliki tag penutup.

1. Tag <img> Dasar

Sintaks dasar untuk menyisipkan gambar:

<img src="nama-gambar.jpg" alt="Deskripsi gambar">

Tag <img> memiliki dua atribut yang wajib ada:

Atribut Keterangan
src Source (sumber) — menentukan path atau URL gambar yang akan ditampilkan
alt Alternative text — teks pengganti jika gambar gagal dimuat; penting untuk aksesibilitas dan SEO
Contoh tampilan gambar:

🖼️ Gambar di sini
📌 Pentingnya atribut alt: Atribut alt dibaca oleh screen reader untuk pengguna yang mengalami gangguan penglihatan. Selain itu, teks alt ditampilkan jika gambar gagal dimuat, dan membantu mesin pencari memahami konten gambar.

2. Atribut width dan height

Atribut width dan height digunakan untuk menentukan ukuran gambar dalam piksel. Selalu tentukan ukuran gambar untuk mengurangi layout shift saat halaman dimuat.

<img src="kucing.jpg" alt="Foto kucing lucu" width="300" height="200">

Ukuran juga bisa ditentukan melalui CSS:

<img src="kucing.jpg" alt="Foto kucing" style="width: 300px; height: 200px;"> <!-- Atau gunakan class CSS --> <style> .gambar-konten { width: 100%; /* Lebar penuh container */ max-width: 500px; /* Maksimal 500px */ height: auto; /* Tinggi menyesuaikan rasio aspek */ } </style> <img src="pemandangan.jpg" alt="Pemandangan gunung" class="gambar-konten">
💡 Tips: Gunakan height: auto bersama width tertentu agar gambar tidak terdistorsi (menjaga rasio aspek).

3. Path Gambar (src)

Nilai src dapat berupa path relatif, absolut, atau URL eksternal:

<!-- Gambar di folder yang sama --> <img src="kucing.jpg" alt="Kucing"> <!-- Gambar di subfolder --> <img src="gambar/kucing.jpg" alt="Kucing"> <!-- Gambar di folder induk --> <img src="../gambar/kucing.jpg" alt="Kucing"> <!-- URL gambar eksternal --> <img src="https://www.example.com/gambar/kucing.jpg" alt="Kucing">

4. Gambar Sebagai Tautan

Gambar dapat dijadikan tautan dengan membungkusnya di dalam tag <a>:

<a href="https://www.w3schools.com"> <img src="w3schools_logo.jpg" alt="Logo W3Schools" width="150"> </a>
Hasil — gambar yang dapat diklik:

🔗 Gambar Tautan
📌 Saat gambar dijadikan tautan, teksnya (nilai alt) akan dibacakan oleh screen reader sebagai teks tautan.

5. Float Gambar dengan CSS

Properti CSS float memungkinkan teks mengalir di samping gambar. Ini berguna untuk layout artikel atau blog.

Float ke Kiri

<img src="foto.jpg" alt="Foto" style="float: left; margin-right: 15px; width: 150px;"> <p>Teks akan mengalir di sebelah kanan gambar ini. Properti float: left membuat gambar menempel di sisi kiri, dan elemen di sekitarnya akan melingkupi gambar tersebut.</p>
Hasil:
🖼️ Foto

Teks akan mengalir di sebelah kanan gambar ini. Properti float: left membuat gambar menempel di sisi kiri, dan elemen di sekitarnya akan melingkupi gambar tersebut. Ini sangat berguna untuk artikel dan posting blog yang memiliki gambar ilustrasi.

Float ke Kanan

<img src="foto.jpg" alt="Foto" style="float: right; margin-left: 15px; width: 150px;"> <p>Teks akan mengalir di sebelah kiri gambar ini. Properti float: right membuat gambar menempel di sisi kanan.</p>
💡 Setelah menggunakan float, tambahkan clear: both atau gunakan clearfix agar elemen berikutnya tidak ikut melingkupi gambar:

.clearfix::after { content: ""; display: table; clear: both; }

6. Background Image (Gambar Latar)

Gambar latar belakang ditambahkan melalui CSS, bukan melalui tag <img>. Gunakan properti background-image.

<!-- Inline style --> <div style="background-image: url('pemandangan.jpg'); background-size: cover; background-position: center; height: 300px;"> Konten di atas gambar latar </div> <!-- Menggunakan CSS --> <style> .hero-section { background-image: url('hero.jpg'); background-size: cover; /* Menutupi seluruh area */ background-position: center; /* Tengah */ background-repeat: no-repeat; /* Tidak diulang */ min-height: 400px; } </style> <div class="hero-section"> <h1>Selamat Datang!</h1> </div>

Konten di atas background image

Nilai background-size

Nilai Keterangan
cover Gambar diperbesar untuk menutupi seluruh area (mungkin terpotong)
contain Gambar disesuaikan agar seluruh gambar terlihat (mungkin ada ruang kosong)
100% 100% Gambar diregangkan untuk memenuhi area (mungkin terdistorsi)
auto Ukuran asli gambar dipertahankan

7. Gambar Responsif

Gambar responsif akan menyesuaikan ukurannya dengan lebar layar:

<!-- Cara termudah membuat gambar responsif --> <img src="foto.jpg" alt="Foto" style="max-width: 100%; height: auto;"> <!-- Atau gunakan class CSS --> <style> img { max-width: 100%; height: auto; } </style>

8. Format Gambar yang Didukung

Format Ekstensi Kegunaan
JPEG .jpg, .jpeg Foto berkualitas tinggi, ukuran file kecil
PNG .png Gambar dengan transparansi, kualitas tinggi
GIF .gif Animasi sederhana, gambar dengan warna terbatas
WebP .webp Format modern, ukuran kecil, kualitas baik
SVG .svg Gambar vektor, dapat diperbesar tanpa pecah
ICO .ico Ikon, biasanya untuk favicon

9. Contoh Lengkap

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Contoh Gambar HTML</title> <style> .gambar-artikel { float: left; margin: 0 15px 10px 0; border-radius: 8px; } .clearfix::after { content: ""; display: table; clear: both; } .hero { background-image: url('hero.jpg'); background-size: cover; background-position: center; min-height: 200px; display: flex; align-items: center; justify-content: center; color: white; text-align: center; } </style> </head> <body> <!-- Hero dengan background image --> <div class="hero"> <h1>Selamat Datang</h1> </div> <!-- Gambar sebagai tautan --> <a href="produk.html"> <img src="produk.jpg" alt="Produk Unggulan" width="200" height="150"> </a> <!-- Artikel dengan gambar float --> <div class="clearfix"> <img src="artikel.jpg" alt="Ilustrasi" class="gambar-artikel" width="200" height="140"> <p>Ini adalah isi artikel yang mengalir di samping gambar.</p> </div> </body> </html>

Ringkasan Atribut <img>

Atribut Contoh Keterangan
src src="foto.jpg" Path atau URL gambar (wajib)
alt alt="Deskripsi" Teks alternatif (wajib)
width width="300" Lebar gambar dalam piksel
height height="200" Tinggi gambar dalam piksel
style style="float: left" Style CSS inline
title title="Tooltip" Teks tooltip saat hover
