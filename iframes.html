HTML Iframes

Elemen <iframe> (Inline Frame) digunakan untuk menyematkan halaman web lain ke dalam halaman HTML yang sedang aktif. Iframe menciptakan "jendela" di dalam halaman yang menampilkan konten dari sumber lain — baik halaman web, video YouTube, peta Google Maps, dan sebagainya.

📌 Catatan: <iframe> singkatan dari Inline Frame. Elemen ini memungkinkan halaman lain (atau bagian konten lain) tampil di dalam kotak/bingkai yang tertanam di halaman HTML kita.

1. Sintaks Dasar <iframe>

Atribut paling penting dari <iframe> adalah src, yang menentukan URL halaman yang akan ditampilkan di dalam frame.

<iframe src="URL_halaman_tujuan"></iframe> <!-- Contoh nyata: --> <iframe src="https://www.w3schools.com"></iframe>

2. Mengatur Ukuran Iframe

Secara default, iframe memiliki ukuran yang relatif kecil. Kita bisa mengatur ukurannya menggunakan atribut width dan height (nilai dalam piksel atau persen), atau menggunakan CSS.

<!-- Menggunakan atribut HTML --> <iframe src="demo.html" width="500" height="300"></iframe> <!-- Menggunakan CSS (direkomendasikan) --> <iframe src="demo.html" style="width: 100%; height: 400px; border: none;"> </iframe> <!-- Ukuran dalam persen (responsif) --> <iframe src="demo.html" width="100%" height="300"></iframe>

3. Menghapus Border Iframe

Secara default, iframe memiliki border (bingkai) tipis di sekelilingnya. Untuk menghilangkan border ini, gunakan properti CSS border: none atau atribut frameborder="0" (cara lama, sudah deprecated di HTML5).

<!-- Cara modern: gunakan CSS (DIREKOMENDASIKAN) --> <iframe src="demo.html" width="500" height="300" style="border: none;"> </iframe> <!-- Cara lama: frameborder (deprecated di HTML5, hindari) --> <iframe src="demo.html" width="500" height="300" frameborder="0"> <!-- Jangan gunakan ini --> </iframe>

4. Iframe sebagai Target Link

Iframe bisa dijadikan target dari sebuah link. Artinya, ketika user mengklik link, halaman tujuan akan terbuka di dalam iframe, bukan di tab baru atau menggantikan halaman saat ini. Caranya: beri name pada iframe, lalu gunakan nama tersebut sebagai target pada link.

<!DOCTYPE html> <html> <body> <!-- Link yang akan membuka halaman di dalam iframe --> <a href="https://www.w3schools.com" target="frame-saya"> Buka W3Schools di sini </a> <a href="https://www.google.com" target="frame-saya"> Buka Google di sini </a> <br><br> <!-- Iframe sebagai target (diberi nama) --> <iframe name="frame-saya" src="about:blank" width="100%" height="400" style="border: 2px solid #04AA6D;"> </iframe> </body> </html>

5. Menyematkan Video YouTube

Salah satu penggunaan paling populer dari <iframe> adalah untuk menyematkan video YouTube ke dalam halaman web. YouTube menyediakan kode embed yang menggunakan iframe.

Cara Mendapatkan Kode Embed YouTube:

  1. Buka video YouTube yang ingin disematkan.
  2. Klik tombol Bagikan (Share).
  3. Pilih Sematkan (Embed).
  4. Salin kode <iframe> yang diberikan.
<!-- Format URL YouTube untuk embed: --> <!-- https://www.youtube.com/embed/[VIDEO_ID] --> <!-- Contoh menyematkan video YouTube --> <iframe width="560" height="315" src="https://www.youtube.com/embed/dQw4w9WgXcQ" title="Video YouTube" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen> </iframe>

Parameter Embed YouTube

URL embed YouTube bisa ditambahkan parameter untuk mengontrol perilaku video:

<!-- Autoplay (putar otomatis) --> <iframe src="https://www.youtube.com/embed/VIDEO_ID?autoplay=1"></iframe> <!-- Mute (bisukan) --> <iframe src="https://www.youtube.com/embed/VIDEO_ID?mute=1"></iframe> <!-- Loop (putar berulang) --> <iframe src="https://www.youtube.com/embed/VIDEO_ID?loop=1&playlist=VIDEO_ID"></iframe> <!-- Mulai dari detik tertentu (mulai di detik ke-30) --> <iframe src="https://www.youtube.com/embed/VIDEO_ID?start=30"></iframe> <!-- Sembunyikan kontrol pemutar --> <iframe src="https://www.youtube.com/embed/VIDEO_ID?controls=0"></iframe> <!-- Gabungkan beberapa parameter dengan & --> <iframe src="https://www.youtube.com/embed/VIDEO_ID?autoplay=1&mute=1&loop=1"></iframe>

6. Menyematkan Google Maps

Iframe juga bisa digunakan untuk menyematkan Google Maps ke halaman web:

<iframe src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d126748. ...kode_map_Google_Maps..." width="600" height="450" style="border: 0;" allowfullscreen="" loading="lazy" referrerpolicy="no-referrer-when-downgrade"> </iframe>
📌 Cara mendapatkan kode embed Google Maps: Buka Google Maps → Cari lokasi → Klik tombol "Bagikan" → Pilih tab "Sematkan peta" → Salin kode HTML.

7. Semua Atribut <iframe>

Atribut Keterangan
src URL halaman/konten yang ditampilkan di dalam iframe
width Lebar iframe dalam piksel atau persen
height Tinggi iframe dalam piksel atau persen
name Nama iframe, digunakan sebagai target link
title Teks deskriptif untuk aksesibilitas (screen reader)
allow Izin fitur: autoplay, fullscreen, kamera, mikrofon, dll.
allowfullscreen Mengizinkan iframe ditampilkan mode layar penuh
loading lazy = muat saat terlihat; eager = muat langsung
sandbox Membatasi fitur iframe untuk keamanan (menonaktifkan JS, form, dll.)
srcdoc Konten HTML langsung (bukan URL) yang ditampilkan di iframe
referrerpolicy Mengontrol informasi referrer yang dikirim saat memuat iframe

8. Iframe dengan srcdoc

Atribut srcdoc memungkinkan kita menulis konten HTML langsung di dalam atribut, tanpa harus merujuk ke file eksternal.

<iframe srcdoc="<h2 style='color:green'>Halo dari srcdoc!</h2> <p>Ini konten HTML langsung di atribut.</p>" width="400" height="150" style="border: 2px solid #04AA6D;"> </iframe>

9. Keamanan Iframe (sandbox)

Atribut sandbox meningkatkan keamanan iframe dengan membatasi apa yang bisa dilakukan konten di dalamnya. Sangat penting saat menyematkan konten dari sumber yang tidak terpercaya.

<!-- sandbox tanpa nilai: menonaktifkan SEMUA fitur --> <iframe src="halaman-lain.html" sandbox></iframe> <!-- sandbox dengan izin tertentu --> <iframe src="halaman-lain.html" sandbox="allow-scripts allow-same-origin"> </iframe> <!-- Nilai sandbox yang tersedia: --> <!-- allow-scripts : Izinkan JavaScript --> <!-- allow-same-origin : Izinkan same-origin requests --> <!-- allow-forms : Izinkan pengiriman form --> <!-- allow-popups : Izinkan popup/window baru --> <!-- allow-top-navigation: Izinkan navigasi ke halaman induk -->
⚠️ Peringatan Keamanan: Saat menyematkan konten dari sumber eksternal yang tidak terpercaya, selalu gunakan atribut sandbox untuk mencegah serangan XSS (Cross-Site Scripting) dan potensi ancaman keamanan lainnya.

Ringkasan

💡 Poin-poin penting tentang HTML Iframes:
  • <iframe> menyematkan halaman/konten web lain ke dalam halaman saat ini.
  • Gunakan src untuk menentukan URL konten yang akan ditampilkan.
  • Atur ukuran dengan width, height, atau CSS.
  • Hilangkan border dengan style="border: none".
  • Gunakan atribut name untuk menjadikan iframe sebagai target link.
  • Format embed YouTube: https://www.youtube.com/embed/VIDEO_ID.
  • Gunakan sandbox untuk membatasi fitur demi keamanan.
  • Tambahkan title untuk aksesibilitas.
