HTML Favicon

Favicon adalah ikon kecil berukuran 16x16 piksel yang ditampilkan di sebelah judul halaman pada tab browser, bookmark, riwayat, dan hasil pencarian. Kata "favicon" merupakan singkatan dari favorite icon.

1. Apa itu Favicon?

Favicon adalah elemen visual kecil namun penting yang merepresentasikan identitas sebuah website. Setiap kali Anda membuka tab baru di browser, Anda akan melihat ikon kecil di sebelah kiri judul tab — itulah favicon.

Contoh tampilan favicon di tab browser:
W
Tutorial HTML — W3Schools ✕
🔒 www.w3schools.com/html/favicon.html

Ikon kecil "W" di sebelah judul tab adalah favicon

Favicon muncul di mana saja?

  • 🗂️ Tab Browser — Di sebelah judul halaman pada setiap tab
  • ⭐ Bookmark/Favorit — Saat halaman disimpan sebagai favorit
  • 🕐 Riwayat Browser — Di daftar halaman yang pernah dikunjungi
  • 📱 Shortcut di layar HP — Saat website disimpan ke homescreen
  • 🔍 Hasil Pencarian — Di beberapa mesin pencari

2. Cara Menambahkan Favicon

Favicon ditambahkan menggunakan tag <link> di dalam elemen <head> dokumen HTML.

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Judul Halaman Saya</title> <!-- Menambahkan favicon --> <link rel="icon" type="image/x-icon" href="/images/favicon.ico"> </head> <body> <!-- Konten halaman --> </body> </html>
📌 Penjelasan atribut:
  • rel="icon" — Memberitahu browser bahwa ini adalah ikon favorit
  • type="image/x-icon" — Tipe MIME dari file ikon
  • href="/images/favicon.ico" — Path menuju file favicon

3. Langkah-Langkah Menambahkan Favicon

1 Siapkan file favicon

Buat atau unduh gambar favicon. Format yang paling umum adalah .ico (16x16 atau 32x32 piksel). Anda bisa menggunakan tools online seperti favicon.io atau realfavicongenerator.net untuk membuat favicon dari gambar, teks, atau emoji.

2 Simpan file favicon

Simpan file favicon di direktori website Anda. Cara paling mudah adalah meletakkannya di root (folder utama) website dengan nama favicon.ico. Browser modern secara otomatis mencari file favicon.ico di root.

📁 website/ ├── 📄 index.html ├── 🖼️ favicon.ico ← letakkan di sini ├── 📁 css/ └── 📁 images/
3 Tambahkan tag <link> di <head>

Sisipkan tag <link> di dalam elemen <head> pada setiap halaman HTML:

<head> <link rel="icon" type="image/x-icon" href="favicon.ico"> </head>

4. Format Favicon yang Didukung

Browser modern mendukung berbagai format gambar untuk favicon:

.ico
ICO (Icon) — Format paling kompatibel, didukung semua browser.
type="image/x-icon"
Dapat berisi beberapa ukuran gambar dalam satu file (16x16, 32x32, 48x48)
.png
PNG (Portable Network Graphics) — Didukung browser modern, mendukung transparansi.
type="image/png"
Disarankan ukuran 32x32 atau 96x96 piksel
.gif
GIF (Graphics Interchange Format) — Mendukung animasi (favicon animasi).
type="image/gif"
Namun tidak semua browser mendukung favicon animasi GIF
.jpeg
JPEG/JPG — Didukung beberapa browser modern.
type="image/jpeg"
Tidak mendukung transparansi, kurang umum digunakan untuk favicon
.svg
SVG (Scalable Vector Graphics) — Format vektor, dapat diperbesar tanpa pecah.
type="image/svg+xml"
Ideal untuk tampilan layar retina/HiDPI, namun belum didukung semua browser

5. Contoh Penggunaan Berbagai Format

<head> <!-- Format ICO (paling kompatibel) --> <link rel="icon" type="image/x-icon" href="favicon.ico"> <!-- Format PNG --> <link rel="icon" type="image/png" href="favicon.png"> <!-- Format SVG (browser modern) --> <link rel="icon" type="image/svg+xml" href="favicon.svg"> <!-- Format GIF (animasi) --> <link rel="icon" type="image/gif" href="favicon.gif"> <!-- Apple Touch Icon (untuk iOS) --> <link rel="apple-touch-icon" sizes="180x180" href="apple-touch-icon.png"> </head>

6. Favicon untuk Berbagai Perangkat

Untuk kompatibilitas maksimal di berbagai perangkat dan browser, disarankan menyediakan beberapa ukuran favicon:

<head> <!-- Favicon standar --> <link rel="icon" type="image/png" sizes="16x16" href="favicon-16x16.png"> <link rel="icon" type="image/png" sizes="32x32" href="favicon-32x32.png"> <!-- Untuk Android Chrome --> <link rel="icon" type="image/png" sizes="192x192" href="android-chrome-192x192.png"> <!-- Untuk Apple/iOS --> <link rel="apple-touch-icon" sizes="180x180" href="apple-touch-icon.png"> <!-- Untuk Windows tile --> <meta name="msapplication-TileImage" content="mstile-150x150.png"> <meta name="msapplication-TileColor" content="#04AA6D"> </head>
💡 Tips: Gunakan realfavicongenerator.net untuk menghasilkan semua ukuran favicon yang diperlukan sekaligus secara otomatis dari satu gambar.

7. Perbedaan Browser dalam Menampilkan Favicon

Browser Format Direkomendasikan Ukuran
Chrome, Firefox, Edge ICO, PNG, SVG 16x16, 32x32
Safari (macOS) PNG, ICO 32x32
Safari (iOS) PNG (Apple Touch Icon) 180x180
Android Chrome PNG 192x192
IE (lama) ICO saja 16x16

8. Contoh Halaman Lengkap dengan Favicon

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Website Saya</title> <!-- Favicon utama --> <link rel="icon" type="image/x-icon" href="favicon.ico"> <!-- Favicon PNG untuk browser modern --> <link rel="icon" type="image/png" sizes="32x32" href="favicon-32x32.png"> <link rel="icon" type="image/png" sizes="16x16" href="favicon-16x16.png"> <!-- Apple Touch Icon --> <link rel="apple-touch-icon" sizes="180x180" href="apple-touch-icon.png"> </head> <body> <h1>Selamat Datang di Website Saya!</h1> <p>Cek tab browser Anda — favicon sudah muncul!</p> </body> </html>

Ringkasan

Konsep Keterangan
Apa itu favicon Ikon kecil (16x16px) yang mewakili website di tab browser, bookmark, dll.
Tag yang digunakan <link rel="icon" href="favicon.ico"> di dalam <head>
Format terbaik .ico untuk kompatibilitas maksimal; .png atau .svg untuk browser modern
Lokasi file Sebaiknya di root (folder utama) website
Ukuran standar 16x16px, 32x32px (bisa lebih besar untuk perangkat modern)
